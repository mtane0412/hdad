# VRMの演出

配信者がアップロードした VRM のキャラクターを、トリガーで短いあいだだけ出して動かす演出（issue #358）。VRM をオーバーレイに描く3段階（A 演出 #358 → B 出しっぱなしのマスコット #359 → C 配信者自身のアバター #360）の最初で、B へ進むかは A で OBS の負荷を測ってから決める。

## 動きは手で作る（VRMA を使わない）

VRMA（VRM Animation）のファイルを使うと動きは自然になるが、VRMA のアップロードと選択の経路が増え、動きの中身がファイル任せになって種から変えられない。
段階 A は「出てきて、手を振って、お辞儀して、帰る」の決まった長さの演出なので、正規化された骨の回転をコードで書いた（`src/vrm/motion.ts`）。種と経過時間だけから決まる関数にでき、テストも書ける。配信者が着手時に選んだ。

## どのトリガーにも置ける

ペロペロ（相手1人のアイコンを舐める）やツイスター（レイドした配信者と対戦する）と違い、この演出は相手を必要としない。置ける項目を絞る理由が無く、負荷を測るにも試しやすいので、すべての項目に置けるようにした。配信者が着手時に選んだ。

## 出す VRM は全体で1つ

トリガーの行ごとに VRM を選ばせると、動作の設定と検証が増える。ペロペロの効果音と同じく、トリガーのページのカードで1つ選んで KV に持ち、どの行と試し再生も同じ VRM を出す。配信者が着手時に選んだ。

## VRM は素材の種類 `vrm` にし、アラートの素材から外す

VRM はリポジトリに入れられない（再配布できないモデルがある）ので、音声と同じく R2 の素材としてアップロードする。VRM は glTF のバイナリと同じ形なので `model/gltf-binary` で受け取る。`application/octet-stream` はどのファイルにも付きうるので、受け付けると種類の判定が意味を失う。ブラウザは .vrm に種類を付けないため、管理画面が拡張子を見て付ける。
素材の種類はアラートの素材の選択と共有しているので、アラートに VRM を選べないよう Worker の検証と画面の選択肢の両方で外した（Worker は「存在しません」ではなく「VRM なのでアラートには使えません」と返す）。

## SpringBone を使わない

`vrm.update` は髪や服の揺れ（SpringBone）を前のコマの状態から計算するので、描画は経過時間だけから決める約束（`docs/decisions/rendering.md`）の例外になる。段階 A は約束の範囲で作ると決めていたので、`humanoid.update` と `expressionManager.update` だけを呼ぶ。揺れ物は段階 B（#359）で、例外として記録してから足す。

## プレビューは配信者のセッションで VRM を読む

合成ページのプレビュー（`?demo=true`）はオーバーレイ用キーを持たず、Worker の押し出しにつながない（`docs/decisions/overlay-stage.md`）。しかし VRM の演出は VRM が無いと何も映らず、見栄えと置き場所を決められない。
プレビューは管理画面の中で開かれ配信者のセッションがあるので、`GET /api/admin/vrm/model` を1回だけ読み、`/api/media/<ID>`（セッションで読める）から VRM を読み込む。押し出しの接続やポーリングは増やさないので、「配信中のものに加えてもう1組動く」ことは起きない。

## 実物の VRM で向きを確かめた

骨の回転の向き（腕を下ろす・お辞儀を前へ・進む向きを向く）は、three-vrm の VRM 1.0 のサンプル（`VRM1_Constraint_Twist_Sample.vrm`。約10MB）を一時的に置いたページで、手を振る・お辞儀・歩いて出てくる場面を描いて確かめた（2026-10-13。読み込みは手元の開発サーバーで約0.4秒）。VRM 0.x は公開されたサンプルが無く、実物では確かめていない（three-vrm の VRMA の読み込みと同じく、X・Z の回転を反転して当てる）。

## 検証すること（段階 B へ進むかを決める材料）

- OBS のブラウザソースで、VRM の読み込みにかかる時間（User Timing の `vrm-load`）と、流しているあいだの CPU・GPU の負荷
- ペロペロ・ツイスターと同じオーバーレイに置いたときに、WebGL のコンテキストが増えて問題が出ないか
- 手元のモデルの大きさが `MAX_MEDIA_BYTES`（50MB）に収まるか
