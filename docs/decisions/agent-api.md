# エージェント向けAPI

**HDAD に溜まった過去の配信の文脈を、外部の AI エージェント（主に Meta の Muse、ほかに Claude Code）から読めるようにする**（issue #434〜#436）。配信の準備や振り返りを、ブラウザでアプリのページを開かずにエージェントへ頼めるようにするためである。WebMCP（`docs/decisions/webmcp.md`）はアプリのページを開いたブラウザの中でしか動かないので、別の道として作る。

## 段階を分ける

段階1（#434）で Bearer トークンの認証と読み出しの REST（`/api/agent/*`）、段階2（#435）で同じ処理を MCP のツールとして `/mcp` に出し、段階3（#436）で章とあらすじの横断検索を足して Muse に実際につなぐ。REST を先にしたのは、Muse が MCP にどこまでつなげるかが2026-10-29 時点の情報では定まらず（Custom Connector は公開 API を前提にしている）、REST ならどちらの道でも使えるためである。

## 認証は固定の Bearer トークンにする

配信者は1人だけという前提（`TWITCH_BROADCASTER_ID`）なので、エージェントごとにトークンを発行・失効させる管理画面や、MCP の正式な流れである OAuth は作らない。OAuth は Muse が対応しているか分からず、実装も重い。漏れたときはシークレットを差し替えれば済む。

管理画面のログインのセッションでは通さない。外部に渡すのは読み取りだけの道で、守り方を分けておけば、のちに書き込みを足すときも管理画面の道を外へ広げずに済む。トークンのシークレットが無い・空のときは比べる前に503にし、空のトークンで通ってしまわないようにする（Fail-Fast）。任意のシークレットなので、`GITHUB_WEBHOOK_SECRET` と同じく `.dev.vars.example` ではコメントアウトし、Deploy to Cloudflare ボタンの必須の入力欄に出さない。

## 保存期間は変えない

文字起こし（24時間）とチャット全文（最長7日）は延ばさず、長く残る記録（章・あらすじ・作業ログ・タスクの宣言・レイド・意見ボード・視聴者の記録）だけを返す。まず要約で足りるかを試し、足りなければ延ばす。延ばすなら D1 の容量と、視聴者の発言を外部のエージェントに渡すことの扱い（削除の方針）を先に決める必要がある。

## 視聴者由来の文は場所を示して返す

REST には WebMCP の `untrustedContentHint` に当たる仕組みが無いので、応答に `untrustedFields`（信頼できない欄の場所）と `notice`（扱い方）を添える。視聴者が書いた文だけでなく、それを材料に LLM が作った文（章・あらすじ・人物像・意見ボード）も含める理由は WebMCP と同じで、チャットに書かれた指示は要約を通っても残りうるためである。作業ログ（GitHub のコミット・マージ）も含める。マージした PR の題名は、公開リポジトリなら外部の人が書いたものでありうるためである。

## 配信の詳細は1回で返す

`GET /api/agent/streams/:id` は、章・あらすじに加えて作業ログ・タスクの宣言・意見ボードもまとめて返す。エージェントは「この配信で何をしたか」を知りたいことが多く、呼び出しを分けると何度も往復させるためである。視聴者数の時系列は数が多く、文脈を埋めるだけなので返さない（WebMCP の `get_stream` と同じ）。
