# ペロペロ

視聴者の Twitch のアイコンを、3Dの舌が舐め上げるジョーク演出（issue #337〜#340）。チャンネルポイントの交換と、決まった人のその配信で最初の発言で流す。

## キモいほうを選ぶ

配信者が「キモい方がウケるので、できるだけキモくしたい」と決めた。舌は上品な記号（漫画風の舌）にせず、リアル寄りの質感（溝・乳頭のブツブツ・テカリ・唾液）にする。段階を分け、#338 で届く仕組みと仮の舌（つぶした楕円体）を通し、#339 でキモさを作り込み、#340 で効果音を付ける。

## 舌はガラス越しにアイコンを舐める（#339）

舌が実際にアイコン（写真）を舐めるなら、カメラから見えるのは舌の裏で、キモさの中心になる乳頭のブツブツと溝が見えない。
そこで奥から「アイコン → 舌 → ガラス」と置き、画面のガラスを内側から舐めている形にした。舌の表がカメラを向いてガラスに押しつけられて平たく広がり、
舐めた跡（濡れた筋・泡・垂れ）はガラスに残るので舌の手前に重なる。裏の青い血管は、最後のすくう回で舌先を丸めたときに見せる。

舐めた跡と垂れと糸は、フレームごとに状態を積み上げると約束（描画は経過時間だけから決まる）とぶつかる。そこで跡の形（どの回がどこまで舐めたか）と垂れ（どこから・いつから・どの速さで）を舐め方を決めるときに種から決め、
その時刻の様子は経過時間から毎回求め直す（`trailsAt`・`salivaStringAt`）。

## 模様は画像の素材を使わずにコードで作る（#339）

乳頭・溝・苔・血管は、`src/lick/texture.ts` が画素の並びとして作る。画像の素材を持つと出どころと権利を管理することになり、リポジトリに入れない約束の音声と同じ問題が出る。
舌の絵は幅より長さが4倍ほど長く貼られるので、乳頭は絵の上で縦に縮めて押し、舌の上で丸く見せる。

## 効果音は音声1つを、音程を変えて触れるたびに鳴らす（#340）

ジュルジュル・ペチャペチャを何種類も選ばせると設定が増える。ツイスターの BGM と同じく音声1つと音量だけを持ち、舌先が触れはじめるたびに再生の速さ（音程）を種から少し変えて鳴らし、同じ音の繰り返しに聞こえにくくした。
音声はリポジトリに入れず（`docs/decisions/twister.md` と同じ理由）、おすすめは `docs/guide/lick.md` に配布元へのリンクで載せる。
はじめは長い音声を途中で切る処理を持たず、短く切り出した音を使うよう案内していた。しかし長い音声（18秒の舐める音など）を選ぶと、演出が終わったあとも鳴り続けた。
そこで1回の音は、その回で舌を離し終えるまで（`lickSoundCuesOf` の `durationMs`）で音量を下げて止め、演出が終わったときにも鳴っている音をすべて止めるようにした。長い音声もそのまま選べる（頭からその回のぶんだけ鳴る）。

## 実写の動画を使わず three.js でコードから作る

舌の実写の動画を素材にすると、アイコンに当たる位置や押しつぶれ方を合わせられず、毎回同じ動きになる。ツイスターと同じく three.js でコードから作り、舐める回数と位置を種から変える。

## 置けるきっかけを2つに絞る

舐めるのは相手1人のアイコンなので、相手が1人に決まり、その人が「舐められに来た」と言えるきっかけだけに置く。チャンネルポイント（視聴者が自分で交換した）と、決まった人のその配信で最初の発言（配信者が選んだ人への出迎え。#337 で足したトリガー）。フォローやレイドなど、本人が望んでいない出来事では舐めない。

## Worker は種と相手だけを押し出す

ツイスターと同じく、舐め方の中身は合成ページが種から計算し、Worker は種と相手の名前・アイコンだけを押し出す（`docs/decisions/twister.md` の「対戦は合成ページが計算し、Worker は種だけを押し出す」）。舐め方の計算は軽いが、#339 で唾液の跡などを足すときに Workers Free の CPU の上限を気にせずに済む。

## アイコンはログイン名から引く

チャンネルポイントの通知とチャットの通知はどちらもログイン名と表示名を持つので、`getUserByLogin` で1人ずつ引く（ツイスターは2人ぶんをユーザーIDから1回で引くが、ペロペロは1人なので分けない）。その人が Twitch にいなければ頭文字の顔で流し、Twitch を呼べないときだけ失敗として記録する。
