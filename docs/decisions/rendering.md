# 素材の描画（経過時間だけから決める）

`.claude/CLAUDE.md` の「描画は経過時間だけから決まる形にする（フレーム間の状態を持たない）」という約束の理由と、この約束とぶつかった素材がどう合わせてきたかを書く。

## 約束の始まりと理由

この約束は最初のコミット（`37af131`、#1「OBSブラウザソース向けの配信背景とギャラリーを追加」、2026-09-17）で入った。そのときの素材は動く配信背景（aurora・contour・halftone・motes）だけで、約束の理由は文書に残さず、コードのコメントにだけ書いていた（`src/core/background.ts` の冒頭「フレーム落ちやリサイズの影響を受けないようにする」、`src/wallpaper/motes.ts` の冒頭「フレーム落ちしても動きが飛ばない」）。

前のコマの位置に毎コマ少しずつ足して動かす形では、コマが落ちると動きが遅れたり、取り戻そうとして飛んだりする。OBSのブラウザソースは、ソースを隠しているあいだや配信中の負荷が高いときにコマを落とすので、そのたびに動きが乱れる。経過時間から位置を直接求める形なら、何コマ落ちても次に描くコマはその時刻の正しい姿になる。画面の大きさが変わったときも、積み上げた状態を新しい大きさへ読み替える必要がない。

## その後の素材での合わせ方

背景のあとに足した素材も、この約束に合わせて作ってきた。状態を持ちたくなる場面では、約束を外すのではなく、状態にあたるものを「始めるときに種と入力から決めておき、その時刻の様子は経過時間から毎回求め直す」形に置き換えている。

- ツイスターの倒れ込みは物理で作るので、フレームごとに状態を持つ。演出を始めるときに物理を最後まで計算して各時刻の姿勢を記録し、描画は記録を経過時間で引くだけにした（[ツイスター](twister.md)）
- ペロペロの舐めた跡・垂れ・唾液の糸は、どの回がどこまで舐めたかを種から先に決め、その時刻の様子を経過時間から求め直す（[ペロペロ](lick.md)）
- 作業机の作業時間の合計は、読んだときの合計に「読んでからの経過時間 × 作業中の人数」を足して毎コマ求める（[作業机](task-desk.md)）
- 市町村紹介の効果音は「もう鳴らしたか」を覚えないと毎コマ鳴ってしまうので、いつ何を鳴らすかの表を先に作り、合成ページは鳴らした行を覚えるだけにした（[市町村紹介](town-tour.md)）

結果として、各素材は「その時刻に何をどこへ出すか」を決める部分（`motion.ts` など）と、それを描くだけの部分（`view.ts`）に分かれた。前者は時刻を渡せば結果が決まるので、「この時刻にはこの姿」をテストで確かめられる。これは約束を決めたときに挙げた理由ではないが、約束を守ってきたことで得られている性質である。

## 例外を作るときに書き残すこと

約束の目的は「コマが落ちても動きが壊れないこと」である。前のコマの状態を引き継ぐ計算でも、1コマの時間差に上限を設けて、コマが落ちたあとに少し遅れて追いつくだけで済むなら、目的は損なわない。そのような計算を約束の例外として持ち込むときは、その素材の判断の記録に次の2つを書く。

- コマが落ちたときに何が起きるか（遅れて追いつくだけで、配信画面で破綻しないこと）
- その部分は時刻を渡しても結果が決まらないので、テストで時刻ごとの姿を確かめられないこと
