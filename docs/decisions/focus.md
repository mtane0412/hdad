# 注目コメント（`/focus/`）

注目コメント（`/focus/`）は視聴者の発言1件を配信画面に大きく出しっぱなしにする仕組みで、映すのは合成ページの素材の種類 `focus` である（注目コメント専用のオーバーレイ `focus/overlay/index.html` は issue #107 で消した。`docs/decisions/overlay-stage.md`）。`/focus/` のページは取り上げる1件を選ぶだけで、OBS用URLは配らない。

## 人に追従する取り上げ方はやめた

以前は取り上げ方が2通りあった（`viewer` は人に追従し、その人の発言が届くたびに映すものを最新の1件へ差し替える。`message` は発言1件を固定する）。**`viewer` は複雑さに見合わないので消し、発言1件を選んで大きく映す使い方だけを残した。**

追従があるために抱えていたものは次のとおりで、どれも「1件を選んで出す」には要らない。

- 画面に2つのモードを別の場所で選ばせる作り（追従は「誰を追うか」、取り上げは「どの発言を出すか」を決めるので、一覧に混ぜると行ごとに意味が曖昧になった）と、相手を選ぶ選択欄・ログイン名を手で打つ欄（`src/focus/form.ts` の `speakersOf`）
- オーバーレイで匿名IRCの発言を絞って差し替える判断（`withMessage`）と、「切り替えた直後は何も映さず次の発言から映す」という説明の要る振る舞い
- 保存の形の分岐（`type` で2つの形を持つ `FocusTarget`）

保存先のKVのキーは `focus-target` から `focus-comment` へ変えた。追従の指定（ログイン名だけ）は映す本文を持たないので、古いキーに残っていても読まない。古い形を読んで捨てる分岐を持ち続けるより、キーを分けて読まないほうが単純だからである。

## 取り上げる1件の持ち方

**取り上げている1件は1つの保存先で表す**（`worker/focus-config.ts` の `FocusTarget`。KVのキーは `focus-comment`）。選んだ時点の本文を写して持つのは、発言の記録（`stream_chat_messages`）が人物像を作り終えた時点で消えるためである。

**取り上げる1件をURLに入れない**（配信中に選び直すたびにOBSのURLを貼り替えることになるため。読み上げの設定をURLから移した issue #86 と同じ考え方である）ので、配送はポーリング（`GET /api/overlay/focus`。10秒）で行う。サイドスーパーの30秒より短いのは、配信者が選んでから映るまでの待ちを短くするためで、読むのはKVの1件だけである。

## アイコンは取り上げたときに Worker が引く

表示をアイコン・名前・本文の箱にしたので、発言した人のアイコンのURLが要る。発言の記録（`stream_chat_messages`・`viewers`）はアイコンを持っていない。

**アイコンのURLは、取り上げたとき（`PUT /api/admin/focus`）に Worker が Twitch の `GET /helix/users?login=` から引き、選んだ1件に添えて保存する**（`worker/focus-routes.ts` の `putFocus`・`worker/twitch.ts` の `getProfileImageUrl`。アプリアクセストークンで読める）。

- 画面からは受け取らない（`parseFocusPick` が捨てる）。配信画面に映る画像を Twitch のものに限るためである
- 視聴者の記録にアイコンを貯める案は採らなかった。すべての発言者のぶんを取りに行くことになり、使うのは取り上げた1人だけだからである
- オーバーレイが読むたびに引く案も採らなかった。10秒ごとに Twitch を呼ぶことになり、失敗の扱いも配信中の画面に持ち込むことになる
- **引けなければ保存しない**（名前を変えた・消えた人。Twitch の失敗として502を返し、画面に理由が出る）。アイコンの欠けた箱を映すより、選び直してもらうほうがよい（Fail-Fast）

## 何を映すかの判断は1か所に持つ

**何を映すかの判断は `src/focus/focused.ts` だけが持つ**（通信もDOMも持ち込まない形に切り出し、`withTarget`・`withRemoval` の2つで表す）。

- **同じ1件を読み直したときは状態を据え置く**（読み直しのたびに作り直すと、モデレーターに消された発言が次の読み直しで復活する）
- **モデレーターの操作（発言の削除・BAN・タイムアウト・全消去）で映しているものが消えたら映すのをやめる**（配信画面に残すと取り返しがつかない。そのため発言そのものは使わなくてもIRCにつなぐ）

取り上げる発言を選ぶ一覧は `worker/stream-chat-store.ts` の `readRecentChatToPick` が読む（いま進んでいる配信の直近の発言を新しい順に、発言者の名前を `viewers` から添えて読む。あらすじ・サイドスーパーの材料が名前を返さないのと意識して違える＝配信者が人を見て選ぶためである。記録が無い人の発言は返さない）。

経路は `worker/focus-routes.ts`（`GET`/`PUT /api/admin/focus`・`GET /api/admin/focus/messages`）とオーバーレイ側（`overlay-routes.ts` の `getFocus`）で、値の検証は `focus-config.ts` だけが持つ。

## 見た目

**アイコン・名前・本文を1つの箱にまとめ、素材の枠の中央に出す**（`src/focus/view.ts`・`src/focus/focus.css`）。以前は名前の札と本文の板を分けて枠の左下に寄せていたが、取り上げた発言を配信の題として大きく見せる使い方に絞ったので、「誰が」「何を言ったか」を一目で結びつける箱にして中央に置いた。

サイドスーパーと違って**箱に半透明の板を敷く**（取り上げるのは語りや質問そのもので読ませる量が多く、袋文字では読みにくいため）。本文は文字だけを出す（記録に本文しか残らないので、エモートの絵は持たない）。長い発言ほど字を小さくして全文を収める（区分は `view.ts` が `data-length` に入れる）。
