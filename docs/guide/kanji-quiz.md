# 漢字クイズ

視聴者がチャンネルポイントを交換すると、熟語の読みを問う漢字クイズを配信画面に流します。級（漢検の10級〜1級）ごとに出題の重みを決めておくと、重みの割合で級を選び、その級の問題を問題集から1問選んで出します。

配信者と視聴者はチャットに読みを書いて答えます。制限時間のうちに最初に正解した人の名前を出します。**制限時間のうちに誰も正解しない時間切れが、同じ配信で決めた回数（既定は1回）になったら、10秒の猶予のあと予告なしに OBS の配信を止めます**（猶予のあいだは下部バーから取り消せます。視聴者の画面には猶予を出しません）。

## 使い方

1. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「漢字クイズ」を置きます。熟語を画面の真ん中に大きく出すので、大きさはオーバーレイいっぱい（1920×1080）から始まります
2. [チャンネルポイント報酬](./rewards.md)（`/rewards/`）で、出題させるための報酬を作ります
3. [トリガーの管理画面](./alerts.md)（`/triggers/`）で「チャンネルポイントが交換された」に設定を追加し、対象の報酬を選んで「漢字クイズを出題する」に印を付け、「級ごとの出題の重み」を入れて保存します。級が選ばれる確率は「その級の重み ÷ 重みの合計」で、入力欄の横に%で出ます（0の級は出しません。たとえば3級を3、準2級を1にすると、3級が75%、準2級が25%）。ほかの出来事の行には出ません
4. 時間切れで配信を止めるには、[コネクター](./backstage.md)（`/connectors/`）の「OBS用のURL」で「OBS（配信の停止）」に印を付け、出てきたURLを OBS の裏方のブラウザソースに貼り直します。OBS のつなぎ先は同じページの「Gyazo」の区画（ホスト・ポート・パスワード）で決めます。裏方のブラウザソースを置いていないと、時間切れでも配信は止まらず、失敗として記録されます
5. トリガー画面の「演出の設定」のタブにある「漢字クイズ」のカードの「配信を終える時間切れの回数（1配信あたり）」で、何回の時間切れで配信を止めるかを1〜10回から選びます（選んだらすぐ保存されます。既定は1回）。どの報酬から出した問題も、同じ配信のうちは通しで数えます（試し再生の時間切れは数えません）
6. 同じカードで級を選び、「漢字クイズを試しに流す」を押すと、交換を待たずに1問流せます（試し再生では配信を止めません）

## 音

トリガー画面の「演出の設定」のタブにある「漢字クイズ」のカードで、場面ごとに鳴らす音を選べます。選べるのは[アップロードのページ](./alerts.md)で上げた音声だけで、どの場面も最初は「鳴らさない」です。選んだら「漢字クイズの音を保存する」を押します。

| 場面 | 鳴るとき |
|---|---|
| BGM | 級が出てから、正解が出るか時間切れになるまでくり返し流します。そこで短く小さくして止めます（解説のあいだは流しません） |
| 出題 | 級が出たとき |
| 直前の回答 | 不正解の回答がチャットに届くたび（下の「答え方」） |
| カウントダウン | 最後の5秒、大きな数字が切り替わるたび（5回）。正解が出たら、その後は鳴らしません |
| 正解 | 正解者が出たとき |
| 時間切れ | 残り0秒のあと、時間切れと決まったとき |
| 解説 | 正解・時間切れを見せたあと（1.5秒後）、解説の帯を出したとき |

- 音量は BGM と効果音（BGM 以外のすべて）の2つです
- クイズの BGM を流しているあいだ、[BGM](./bgm.md) で流している配信の曲を小さくし、クイズの BGM を止め終えたら戻します（裏方のブラウザソースで BGM を流しているときだけ）
- 試し再生でも保存した音が鳴ります。未保存の変更があるあいだは「漢字クイズを試しに流す」を押せません。オーバーレイの構成のプレビューでは鳴りません
- 音に選んでいる音声は、アップロードのページから削除できません。先にこのカードで外してください

## 流れ

1回はおよそ74秒です。

1. 「漢検○級」と、交換した人の名前（「○○さんからの出題」）と、「60秒以内に誰も正解できなければ配信終了」を出します（2秒）。配信を止めるまでに時間切れがまだ2回以上あるときは、「60秒以内に誰も正解できなければ時間切れ（あと3回で配信終了）」のように残りの回数を出します（出題した時点の回数です）
2. 熟語が奥から近づいてきます。熟語は読める大きさ（最後の5分の1）で出て、制限時間60秒を数えるあいだ時間切れまで近づきつづけます。上の帯に残り秒数を出し、帯のすぐ下に級の場面と同じ一文を出しつづけます。最後の5秒は残り秒数を熟語の下に大きく赤で出します。不正解の回答が届いたら、近づいてくる熟語のすぐ下に「直前の回答：○○（○○さん）」を出します（最後の1件だけ）
3. 制限時間のうちに正解が届いたら、その時点でカウントダウンを止め、「○○さん 正解！」を大きく出します。誰も正解しないまま残り0秒になったら、0を出したまま Worker の判定を待ち（ふつう1秒ほど）、時間切れと決まったら「時間切れ！」を大きく出します。どちらも1.5秒後に画面の真ん中に横帯を出します。帯は左に熟語、右に正解の読み（読みが複数ある問題はすべて）と解説を並べ、結果は帯の上に小さく残します（あわせて12秒）。締め切りは画面の残り0秒が目安です（実際の締め切りは、合成ページが出題を開いた要求を Worker が受けた時刻から数えるので、その要求の遅れのぶん画面の0秒より少し遅くなります）。チャットは数秒遅れて届くので、残り0秒の直前に書いた回答は間に合わないことがあります。「時間切れ！」を出したあとに「正解！」へ切り替わることはありません
4. 配信を止める回数に届かない時間切れのときは、「時間切れ！」の下に「あと2回 時間切れになると配信終了」（あと1回なら「次に時間切れになると配信終了」）を出し、解説の帯の上にも残します。配信は止めません
5. 配信を止める回数に届いた時間切れのときは、解説を出したまま10秒待ち、予告なしに裏方のブラウザソースが OBS の配信を止めます。画面に残り秒数や「配信を終了します」は出しません。猶予のあいだに取り消したときも、画面には何も出しません

## 配信の停止と取り消し

- 時間切れを決めるのは Worker です（合成ページの数え方では止めません）。画面の残り0秒を目安に締め切り（合成ページが出題を開いた要求を受けた時刻から数えるので、その要求の遅れのぶん画面の0秒より少し遅くなります。チャットの遅れのぶんの余裕は足しません）、正解者がいなければ時間切れを記録します。同じ配信の時間切れ（この問題を含む）が決めた回数に届いたら猶予に入り、届かなければ残りの回数を画面に出すだけで止めません
- 時間切れの回数は配信ごとに数え直します。配信していないときに出した問題は、その1回だけを数えます（回数を1回にしていれば止める流れに入ります）
- 猶予のあいだに取り消しても、時間切れの回数は減りません。同じ配信でもう一度時間切れになると、また猶予に入ります
- 猶予のあいだ、アプリの下部バーに「配信の停止を取り消す（残り ○秒）」が出ます。押すと止めません。どのページを見ていても押せます
- 試し再生で出した問題は、本番の時間切れの回数に1回足したときにどうなるかを出します。配信を止める回数に届くなら、本来なら配信を止める時刻に「試し再生なので配信は止めません」と出し（下部バーのボタンにも「試し再生」と出ます）、届かないなら残りの回数を出します。試し再生の時間切れは本番の回数に数えません
- 同じ出題で2回止めることはありません

続けて交換されたときは、届いた順に1問ずつ流します。同じ配信では、一度出した問題をもう出しません（試し再生で出した問題も数えます）。ある級の問題を出しきったら、その級を外して残りの級の重みで選びます。重みのある級をすべて出しきったら、最初から選び直します（同じ問題がもう一度出ることがあります）。

## 答え方

- チャットに読みだけを書きます。ひらがなでもカタカナでもかまいません（前後の空白は無視します）
- 問題集の読みのどれかと完全に一致したときだけ正解です。ほかの言葉を添えた発言（「けいだいかな」）・ローマ字・漢字は正解になりません
- 熟語が出てから制限時間のあいだだけ受け付けます。最初に正解した1人だけを出します
- 「漢字クイズ」のカードの「正解者に渡す人形」を選んでおくと、最初に正解した人にいまの[人形](./dolls.md)を1つ渡します（最初は「渡さない」。試し再生では渡しません）
- 配信者の発言も回答として受け付けます。bot の発言と、自動モデレーションで処分した発言は回答になりません
- ひらがな・カタカナ（と長音符「ー」）だけの20文字までの発言を回答とみなし、正解でなければ「直前の回答」として合成ページに出します。前後の空白は除いて判定します。漢字・英数字・記号・エモートを含む発言と、途中に空白を含む発言は雑談とみなして出しません。正解者が出た後と時間切れの後は出しません
- モデレーターが消した発言（BAN・タイムアウトを含む）は、「直前の回答」から消します

## 問題集

問題はリポジトリの `src/kanji-quiz/problems.json` にあり、その場で作りません（あとの段階で、正答の判定が配信の強制終了につながるため、読みの誤りを事前に人の目で潰します）。1問は次の4つを持ちます。

| 項目 | 内容 |
|---|---|
| `word` | 出題する熟語 |
| `readings` | 正解の読み（ひらがなだけ。複数書けば、どれでも正解）。先頭に想定する読みを書き、2つ目以降にほかの読みを書く |
| `grade` | 漢検の級（`10`〜`3`・`pre2`（準2級）・`2`・`pre1`（準1級）・`1`） |
| `explanation` | 時間切れのあとに出す解説 |

級は問題ごとに手で付けます（漢検の級別の漢字表は機械で読める形で公開されていないため）。熟語の中で最も上の級の字だけでなく、先頭の読みの級も見てください（中学で習う読みは4級以上、高校で習う読みは準2級以上でしか出題されません。たとえば「境内（けいだい）」は字は6級でも4級の問題です）。2つ目以降には、辞書の見出しにあるほかの読みをすべて入れてください。こちらは級より上で習う読みでもかまいません（正しく答えた人を不正解にしないためのもので、級は決めません）。漢検協会の[漢字ペディア](https://www.kanjipedia.jp/)で、字ごとの級と、読みに付いた「中」「高」の印を確かめられます。下書きを LLM に作らせてもかまいませんが、入れる前に読みと級を確かめてください。形の誤り（読みにカタカナが混じる・知らない級・同じ熟語が2問・問題の無い級がある）は `npm test` で見つかります。

## 失敗したとき

- 配送先へ送れなかったときは、ダッシュボードの失敗の記録に `kanji-quiz-push-failed` として残ります（試し再生では画面に理由を出します）
- 回答を照らせなかったとき（データベースの失敗など）は、黙って不正解にせず、失敗の記録に `kanji-quiz-answer-failed` として残ります
- 合成ページが出題を開けなかったときは、素材の箱に理由を出します（その出題は回答を受け付けず、時間切れまで流れます）
- 合成ページを開いていないあいだの交換は、あとから流れません（貯めずに落とします）
- 時間切れの判定を予約できなかったときは、合成ページの素材の箱に理由を出します（その出題では配信を止めません）
- 残り0秒から10秒待っても正解も時間切れの判定も届かなかったときは、結果を出さずに出題を終え、素材の箱に理由を出します。ふつうは Worker が時間切れの知らせを送れなかったときで、その出題では配信は止まりません。合成ページの接続が切れて知らせを取りこぼしただけのときは配信が止まります。猶予中なら、下部バーの取り消しボタンで取り消せます
- 配信を止められなかったとき（裏方のブラウザソースがつながっていない・OBS につながらない・OBS が配信していない・猶予を合成ページへ知らせられなかった）は、失敗の記録に `kanji-quiz-stop-failed` として残ります。猶予を知らせられなかったときは、取り消せないまま止めないよう、止めずに記録だけします
- 下部バーが漢字クイズの知らせを受け取れていないときは、下部バーに理由を出します（そのあいだは取り消しボタンが出ません）

この機能を入れたあとは、マイグレーション `0031_kanji_quizzes.sql` と `0032_kanji_quiz_stop.sql` を適用してください（適用方法は[配信の記録](./stats.md)を参照）。適用していないと、出題も回答の判定も失敗として記録されます。

経緯は [docs/decisions/kanji-quiz.md](../decisions/kanji-quiz.md) にあります。
