# 漢字クイズ

視聴者がチャンネルポイントを交換すると、熟語の読みを問う漢字クイズを配信画面に流します。級（漢検の10級〜1級）を選んでおくと、その級の問題を問題集から1問選んで出します。

いまは出題から正解の発表までの演出だけです。チャットでの回答の判定（[#301](https://github.com/mtane0412/hdad/issues/301)）と、時間切れで配信を止める仕掛け（[#302](https://github.com/mtane0412/hdad/issues/302)）は次の段階で足します。

## 使い方

1. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「漢字クイズ」を置きます。熟語を画面の真ん中に大きく出すので、大きさはオーバーレイいっぱい（1920×1080）から始まります
2. [チャンネルポイント報酬](./rewards.md)（`/rewards/`）で、出題させるための報酬を作ります
3. [トリガーの管理画面](./alerts.md)（`/triggers/`）で「チャンネルポイントが交換された」に設定を追加し、対象の報酬を選んで「漢字クイズを出題する」に印を付け、「出題する級」を選んで保存します。ほかの出来事の行には出ません
4. トリガー画面の「漢字クイズ」のカードで級を選び、「漢字クイズを試しに流す」を押すと、交換を待たずに1問流せます

## 流れ

1回はおよそ44秒です。

1. 「漢検○級」と、交換した人の名前（「○○さんからの出題」）を出します（2秒）
2. 熟語が奥から近づいてきます。熟語が出たときから制限時間30秒を数え、上の帯に残り秒数を出します。最後の5秒は残り秒数を熟語の下に大きく赤で出します
3. 時間切れで「時間切れ！ 正解は…」と、正解の読み（読みが複数ある問題はすべて）と解説を出します（12秒）

続けて交換されたときは、届いた順に1問ずつ流します。

## 問題集

問題はリポジトリの `src/kanji-quiz/problems.json` にあり、その場で作りません（あとの段階で、正答の判定が配信の強制終了につながるため、読みの誤りを事前に人の目で潰します）。1問は次の4つを持ちます。

| 項目 | 内容 |
|---|---|
| `word` | 出題する熟語 |
| `readings` | 正解の読み（ひらがなだけ。複数書けば、どれでも正解） |
| `grade` | 漢検の級（`10`〜`3`・`pre2`（準2級）・`2`・`pre1`（準1級）・`1`） |
| `explanation` | 時間切れのあとに出す解説 |

級は問題ごとに手で付けます（漢検の級別の漢字表は機械で読める形で公開されていないため）。下書きを LLM に作らせてもかまいませんが、入れる前に読みと級を確かめてください。形の誤り（読みにカタカナが混じる・知らない級・同じ熟語が2問・問題の無い級がある）は `npm test` で見つかります。

## 失敗したとき

- 配送先へ送れなかったときは、ダッシュボードの失敗の記録に `kanji-quiz-push-failed` として残ります（試し再生では画面に理由を出します）
- 合成ページを開いていないあいだの交換は、あとから流れません（貯めずに落とします）
