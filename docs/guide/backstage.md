# 裏方（`overlay/backstage/`）

チャットの読み上げ（`speech/reader/`）・[配信画面の取り込み](./screen.md)・[BGM](./bgm.md)・[漢字クイズ](./kanji-quiz.md)の時間切れでの配信の停止を1つのブラウザソースにまとめます。どれも**映すものを持たない**裏方で、合成オーバーレイ（`overlay/stage/`）が重ねる素材とは性質が違うため、合成ページの素材にはせず裏方だけの1枚にしています。URLはアプリの「コネクター」のページ（`/connectors/`）の「OBS用のURL」でコピーします。コネクターのページでは、動かすものをサービスの名前（VOICEVOX・Gyazo・BGM・OBS（配信の停止））で選びます。配信中の文字起こしは裏方ではなく、HDAD のアプリのページが Chrome で行います（[配信中の文字起こし](./transcript.md)）。

```text
https://hdad.<サブドメイン>.workers.dev/overlay/backstage/?key=<オーバーレイ用キー>
```

| パラメータ | 内容 |
| --- | --- |
| `key` | オーバーレイ用キー（必須）。ほかのオーバーレイと同じキーです |
| `speech` | チャットの読み上げを動かすか（既定は `true`）。`false` にすると VOICEVOX にはつなぎません。合成オーバーレイに[ワイプ](./wipe.md)を置いたときは、ワイプが読み上げるので `false` にします（`true` のままだと理由を出して読み上げません） |
| `screen` | 配信画面の取り込みを動かすか（**既定は `false`**）。`true` にしたときだけ OBS（obs-websocket）につなぎます |
| `bgm` | BGMを鳴らすか（**既定は `false`**）。`true` にしたときだけ、「BGM」のページで選んだ曲を鳴らします |
| `stop` | 漢字クイズが時間切れになったときに OBS の配信を止めるか（**既定は `false`**）。`true` にしたときだけ OBS（obs-websocket）につなぎます |

- **どれも同じPCのループバック（VOICEVOX ENGINE・OBS）につなぐ**ので、OBSと同じPCで開く必要があります。配信画面には映らないので、見えない位置に置いて構いません
- **1つの裏方が失敗しても、ほかは動き続けます**（失敗はその裏方の枠の中に表示します）。1枚にまとめたせいで、1つの失敗がほかを巻き込まないためです
- **配信画面の取り込みは既定で外れています**。動かすにはOBSのWebSocketサーバーと、Worker側の Gyazo のアクセストークンが要ります（[配信画面の取り込み](./screen.md)）
- **BGMは既定で外れています**。貼ってあるブラウザソースが、曲を選んだ途端に黙って鳴り出さないようにするためです。鳴らすならソースのプロパティで「OBSで音声を制御する」を有効にします（[BGM](./bgm.md)）
- **配信の停止は既定で外れています**。OBSのWebSocketサーバーの用意が要るうえ、配信を止める力を持つためです。OBS のつなぎ先（ホスト・ポート・パスワード）は「Gyazo」の区画の設定を使います（[漢字クイズ](./kanji-quiz.md)）
- 読み上げの設定（話者・速度・音量など）は同じコネクターのページの「VOICEVOX」で、画面の取り込みの設定は「Gyazo」で、流すBGMは `/bgm/` の画面で変えます。URLに入るのは「このブラウザソースが何をするか」だけです
- **以前コピーしたURLに `transcript=` か `port=` が入っていると、ページ全体にエラーが出ます**（ゆかコネNEO の中継は issue #192 で消しました）。コネクターのページでURLをコピーし直して貼り替えてください
- **単独のページ（`speech/reader/`）も、貼ってあるブラウザソースのためにそのまま動きます**。ただしアプリはそのURLを出さなくなりました（新しく貼るときは裏方の1枚を使います）
