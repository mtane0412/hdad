# 裏方（`overlay/backstage/`）

チャットの読み上げ（`speech/reader/`）・文字起こしの中継（`transcript/relay/`）・[配信画面の取り込み](./screen.md)・[BGM](./bgm.md)を1つのブラウザソースにまとめます。どれも**映すものを持たない**裏方で、合成オーバーレイ（`overlay/stage/`）が重ねる素材とは性質が違うため、合成ページの素材にはせず裏方だけの1枚にしています。URLは `/backstage/` の画面でコピーします。

```text
https://hdad.<サブドメイン>.workers.dev/overlay/backstage/?key=<オーバーレイ用キー>
```

| パラメータ | 内容 |
| --- | --- |
| `key` | オーバーレイ用キー（必須）。ほかのオーバーレイと同じキーです |
| `speech` | チャットの読み上げを動かすか（既定は `true`）。`false` にすると VOICEVOX にはつなぎません |
| `transcript` | 文字起こしの中継を動かすか（既定は `true`）。`false` にすると ゆかコネNEO にはつなぎません |
| `screen` | 配信画面の取り込みを動かすか（**既定は `false`**）。`true` にしたときだけ OBS（obs-websocket）につなぎます |
| `bgm` | BGMを鳴らすか（**既定は `false`**）。`true` にしたときだけ、「BGM」のページで選んだ曲を鳴らします |
| `port` | ゆかコネNEO の WebSocket のポート番号（既定は `11901`）。`transcript=false` のときは使いません |

- **どれも同じPCのループバック（VOICEVOX ENGINE・ゆかコネNEO・OBS）につなぐ**ので、OBSと同じPCで開く必要があります。配信画面には映らないので、見えない位置に置いて構いません
- **1つの裏方が失敗しても、ほかは動き続けます**（失敗はその裏方の枠の中に表示します）。1枚にまとめたせいで、1つの失敗がほかを巻き込まないためです
- **配信画面の取り込みは既定で外れています**。動かすにはOBSのWebSocketサーバーと、Worker側の Gyazo のアクセストークンが要ります（[配信画面の取り込み](./screen.md)）
- **BGMは既定で外れています**。貼ってあるブラウザソースが、曲を選んだ途端に黙って鳴り出さないようにするためです。鳴らすならソースのプロパティで「OBSで音声を制御する」を有効にします（[BGM](./bgm.md)）
- 読み上げの設定（話者・速度・音量など）は今までどおり `/speech/` の画面で、画面の取り込みの設定は `/screen/` の画面で、流すBGMは `/bgm/` の画面で変えます。URLに入るのは「このブラウザソースが何をするか」だけです
- **単独のページ（`speech/reader/`・`transcript/relay/`）もそのまま使えます**
