# 裏方（`overlay/backstage/`）

チャットの読み上げ（`speech/reader/`）と文字起こしの中継（`transcript/relay/`）を1つのブラウザソースにまとめます。どちらも**映すものを持たない**ページで、合成オーバーレイ（`overlay/stage/`）が重ねる素材とは性質が違うため、合成ページの素材にはせず裏方だけの1枚にしています。URLは `/backstage/` の画面でコピーします。

```text
https://hdad.<サブドメイン>.workers.dev/overlay/backstage/?key=<オーバーレイ用キー>
```

| パラメータ | 内容 |
| --- | --- |
| `key` | オーバーレイ用キー（必須）。ほかのオーバーレイと同じキーです |
| `speech` | チャットの読み上げを動かすか（既定は `true`）。`false` にすると VOICEVOX にはつなぎません |
| `transcript` | 文字起こしの中継を動かすか（既定は `true`）。`false` にすると ゆかコネNEO にはつなぎません |
| `port` | ゆかコネNEO の WebSocket のポート番号（既定は `11901`）。`transcript=false` のときは使いません |

- **どちらも同じPCのループバック（VOICEVOX ENGINE・ゆかコネNEO）につなぐ**ので、OBSと同じPCで開く必要があります。配信画面には映らないので、見えない位置に置いて構いません
- **1つの裏方が失敗しても、もう一方は動き続けます**（失敗はその裏方の枠の中に表示します）。1枚にまとめたせいで、片方の失敗がもう一方を巻き込まないためです
- 読み上げの設定（話者・速度・音量など）は今までどおり `/speech/` の画面で変えます。URLに入るのは「このブラウザソースが何をするか」だけです
- **単独のページ（`speech/reader/`・`transcript/relay/`）もそのまま使えます**
