# タブの映像

Chrome のタブ1枚の映像と音を、配信画面に出す素材です。資料のスライドや見せたい Web ページを、OBS のウィンドウキャプチャを使わずに映せます。

ウィンドウキャプチャでは、Chrome を起動し直すたびにソースを指定し直したり、見せたくないタブまで映らないよう気を配ったりする必要がありました。この素材は**タブ1枚だけ**を取り込むので、ほかのタブは映りません。映すタブは、映したいタブで拡張のショートカットを押して切り替えます。映しているタブでもう一度押すと止まります。

## しくみ

| 役割 | どこで | すること |
| --- | --- | --- |
| 映すタブを選び、取り込んで送る | Chrome 拡張「HDAD タブの映像」 | 映したいタブでショートカットが押されたら、そのタブの映像と音を取り込み、合成ページへ送る |
| 映す範囲を選ぶ | Chrome 拡張「HDAD タブの映像」 | 右クリックで、映しているタブの上で範囲をドラッグして選ばせ、合成ページへ伝える |
| 映す | 合成オーバーレイの素材「タブの映像」 | 届いた映像を（範囲が選ばれていればその部分だけ）映し、音を鳴らす |

映像と音は同じPCの中を直接流れ、HDAD の Worker（Cloudflare）は通りません。Worker を通るのは、つなぐための短い連絡だけです。

## はじめに一度だけすること

### 拡張を入れる

拡張は Chrome ウェブストアには出していません。HDAD からダウンロードして読み込みます。リポジトリもビルドも要りません。

1. HDAD の「コネクター」のページ（`/connectors/`）を開き、「HDAD-tab」の「拡張をダウンロード」を押します。`hdad-tab.zip` が保存されます。前の版を入れていたときは、`chrome://extensions` で前の版を削除してから読み込んでください
2. zip を展開します。`hdad-tab` というフォルダができます。読み込んだあとも Chrome はこのフォルダを使い続けるので、消さない場所に置いてください
3. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」を有効にします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`hdad-tab` フォルダを選びます。拡張は、ダウンロードした HDAD のサイトへのアクセスと Cookie の読み取りを使います。拡張はこれで、配信者としてログインした状態のまま HDAD へつなぎます
5. `chrome://extensions/shortcuts` で、「HDAD タブの映像」のショートカットを確かめます。既定は **Alt+Shift+T**（Mac では ⌥⇧T）です。ほかの拡張と重なって空欄になっていたら、好きなキーを割り当ててください

拡張は、ログイン情報も鍵も持ちません。Chrome で HDAD にログインしているときのクッキーを、映し始めるたびに読んでつなぎます。ログインが切れたら HDAD を開いてログインし直してください。

拡張は、**ダウンロードしたときの HDAD にだけ**タブの映像を送ります。HDAD の置き場所（URL）を変えたときや、開発サーバー（`localhost`）で使うときは、その HDAD のコネクターのページからダウンロードし直して読み込んでください。拡張のIDは固定してあるので、**同時に入れておけるのは1つの HDAD 向けだけ**です（別の HDAD 向けを読み込むときは、入れてある方を削除してください）。

### 合成オーバーレイに置く

1. `/overlay/` を開き、映したいオーバーレイに素材「タブの映像」を置きます。大きさは配信画面と同じ（初期値のまま）を勧めます
2. そのオーバーレイのブラウザソースのプロパティで、**「OBSで音声を制御する」を有効にします**。タブの音はこのブラウザソースから鳴ります
3. 配信者がタブの音を聞くには、OBS の音声ミキサーでそのブラウザソースの「オーディオの詳細プロパティ」を開き、音声モニタリングを「モニターと出力」にします

## 配信のたびにすること

1. Chrome で HDAD にログインしていることを確かめます（コネクターのページを開いておく必要はありません）
2. 映したいタブを開き、ショートカットを押します（ツールバーの拡張のボタンを押しても同じです）
3. 拡張のボタンに緑の「ON」が出て、ボタンにマウスを載せると「映しています（合成ページ 1 か所）」と出れば、配信画面に映っています

別のタブを映したくなったら、そのタブでショートカットを押します。映すタブは1枚ずつで、押したタブに切り替わります。**映すのをやめるときは、映しているタブでもう一度ショートカットを押します。**

## 映さないサイトを登録する

映しているタブの中で、メールや銀行など映してはいけないページへ移ってしまったときの保険です。登録したサイトのページへ移ると、拡張は配信画面へ送るのを止め（合成ページは透明になります）、ボタンに橙色の「止」が出ます。映してよいページへ戻ると、押し直さなくても自動で映り直します。

1. 映したくないサイト（例: Gmail）を Chrome で開きます
2. ツールバーの拡張のボタンを**右クリック**し、「このサイト（mail.google.com）を映さない」を選びます。ボタンにマウスを載せると「mail.google.com を映さないサイトに登録しました」と出ます

登録したサイトを映せるように戻すときは、そのサイトを開いて同じ場所を右クリックします。項目が「このサイト（mail.google.com）を映す」に変わっているので、それを選びます。

まだ開いていないサイト（銀行など）を前もって登録するときや、登録したサイトをまとめて見たいときは、拡張のボタンを右クリックして「オプション」を選び、拡張の設定を開きます。ホスト名（`bank.example.jp` のように、`https://` やパスを付けない形）を入力して「登録する」を押すと加わり、×で消せます。

- 登録はホスト名（`mail.google.com` など）ごとです。同じドメインでも別のホスト名（`www.google.com` など）は映ります
- 登録したサイトのタブでショートカットを押しても、映し始めません
- 映しているあいだに登録・解除しても、すぐに反映されます（映しているページが登録したサイトなら止まり、外したサイトで止めていたなら映り直します）
- **拡張が一覧を読めないとき（HDAD にログインしていないときなど）は、映し始めません。** ボタンに「!」が出て、理由が出ます

## 映す範囲を絞る

タブ全体ではなく、一部分（動画の部分だけ・スライドの本文だけなど）を映せます。選んだ範囲は、合成オーバーレイに置いた箱に収まる大きさまで拡大して映ります。

1. 映しているタブを開いたまま、ツールバーの拡張のボタンを**右クリック**し、「映す範囲を選ぶ」を選びます
2. ページが暗くなります。映したい範囲をドラッグで囲みます（囲み直せます）
3. **Enter** を押すと決まり、配信画面がその範囲に切り替わります。やめるときは **Esc** を押します

タブ全体に戻すときは、拡張のボタンを右クリックして「範囲を外す（タブ全体を映す）」を選びます。

- 範囲は、そのとき見えている部分（表示領域）に対する位置で決まります。**ページをスクロールすると、映る中身も一緒に動きます**（範囲は画面の上の位置に留まります）
- 範囲は割合で覚えるので、Chrome のウィンドウの大きさを変えても、同じ割合の位置が映ります
- **範囲は1つだけです。別のタブに切り替えたり、映すのをやめたりすると、タブ全体に戻ります**
- **選んでいるあいだの暗い膜と枠も、配信画面に映ります。** すぐに選び終えるか、気になるときは選ぶ前に OBS でシーンを切り替えてください
- 映しているタブでないと選べません。ほかのタブで選ぼうとすると、ボタンに「!」が出ます
- Chrome の設定画面（`chrome://` で始まるページ）やウェブストアのページでは選べません
- 範囲の縦横比が箱と違うときの余白は、タブ全体のときと同じく透明です
- 範囲を選ぶには版 0.5.0 以降の拡張が要ります。前の版を入れているときは、コネクターのページからダウンロードし直して入れ替えてください（ページに画面を差し込む許可が新しく加わります）

## 気をつけること

- **ショートカットを押したタブは、そのまま配信に映ります。** 映したくない内容（メールやパスワード管理など）のタブで押さないでください。誤って押したときは、そのタブでもう一度押すと止まります。よく開くサイトは「映さないサイト」に登録しておくと安心です
- **映さないサイトの保険は、ページの移り方によっては一瞬遅れることがあります。** 別のサイトから転送されて着いた場合や、ページの中の画面遷移（URL だけが変わる）で着いた場合は、URL が変わってから止めるためです
- **映しているタブを閉じると、何も映らなくなります。** 失敗の表示も出ません（配信中に普通に起こる操作のためです）。続けて映すときは、別のタブでショートカットを押してください
- **映しているあいだ、そのタブの音は Chrome からは聞こえません。** 配信者は OBS のモニターで聞いてください。音は映像と同じだけ遅れて聞こえます（同じPCの中なので、0.1秒ほどです）
- **映しているタブを裏に回しても、映像は止まりません。** ほかのタブで作業しながら映せます
- **ショートカットを押してから取り込むまでに時間がかかると、失敗します。** 拡張がタブを渡すときの合図は数秒で使えなくなるためです。ボタンに「!」が出たら、もう一度押してください
- **拡張のボタンに「!」が出たときは、うまく映せていません。** ボタンにマウスを載せると理由が出ます（取り込めなかった・中継先につながらない、など）。「中継先につながりません」と出るときは、Chrome で HDAD にログインしているか、拡張をダウンロードした HDAD と同じ URL か確かめてください
- **Chrome の設定画面（`chrome://` で始まるページ）などは映せません。**
- 映像はタブの縦横比のまま、置いた箱に収まる大きさで映ります。箱と縦横比が違うときの余白は透明で、後ろのソースが見えます
- 映像は 1920×1080・30fps までです。Mac では映像をハードウェアで圧縮するので、配信中の負担は小さく抑えられます
