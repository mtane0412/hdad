# タブの映像

Chrome のタブ1枚の映像と音を、配信画面に出す素材です。資料のスライドや見せたい Web ページを、OBS のウィンドウキャプチャを使わずに映せます。

ウィンドウキャプチャでは、Chrome を起動し直すたびにソースを指定し直したり、見せたくないタブまで映らないよう気を配ったりする必要がありました。この素材は**タブ1枚だけ**を取り込むので、ほかのタブは映りません。映すタブは、映したいタブで拡張のショートカットを押して切り替えます。

## しくみ

| 役割 | どこで | すること |
| --- | --- | --- |
| 映すタブを選ぶ | Chrome 拡張「HDAD タブの映像」 | 映したいタブでショートカットが押されたら、そのタブを `/tab/` のページへ渡す |
| 取り込んで送る | `/tab/`（Chrome で開いたままにする） | 渡されたタブの映像と音を取り込み、合成ページへ送る |
| 映す | 合成オーバーレイの素材「タブの映像」 | 届いた映像を映し、音を鳴らす |

映像と音は同じPCの中を直接流れ、HDAD の Worker（Cloudflare）は通りません。Worker を通るのは、つなぐための短い連絡だけです。

## はじめに一度だけすること

### 拡張を入れる

拡張は Chrome ウェブストアには出していません。リポジトリからビルドして読み込みます。

1. リポジトリで `npm install` と `npm run build:extension` を実行します。`extension/dist/` ができます
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」を有効にします
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension/dist/` フォルダを選びます
4. `chrome://extensions/shortcuts` で、「HDAD タブの映像」のショートカットを確かめます。既定は **Alt+Shift+T**（Mac では ⌥⇧T）です。ほかの拡張と重なって空欄になっていたら、好きなキーを割り当ててください

拡張は、ログイン情報も鍵も持ちません。開いているタブの URL を読むのは、`/tab/` のページを探すためです。

### 合成オーバーレイに置く

1. `/overlay/` を開き、映したいオーバーレイに素材「タブの映像」を置きます。大きさは配信画面と同じ（初期値のまま）を勧めます
2. そのオーバーレイのブラウザソースのプロパティで、**「OBSで音声を制御する」を有効にします**。タブの音はこのブラウザソースから鳴ります
3. 配信者がタブの音を聞くには、OBS の音声ミキサーでそのブラウザソースの「オーディオの詳細プロパティ」を開き、音声モニタリングを「モニターと出力」にします

## 配信のたびにすること

1. Chrome で `/tab/` を開きます。**配信中はこのタブを閉じないでください**（閉じると何も映らなくなります）
2. 映したいタブを開き、ショートカットを押します（ツールバーの拡張のボタンを押しても同じです）
3. `/tab/` に「映しています」とタブの題名、「合成ページ 1 か所に映しています」が出れば、配信画面に映っています

別のタブを映したくなったら、そのタブでもう一度ショートカットを押します。映すタブは1枚ずつで、押したタブに切り替わります。映すのをやめるときは、`/tab/` の「止める」を押します。

## 気をつけること

- **ショートカットを押したタブは、そのまま配信に映ります。** 映したくない内容（メールやパスワード管理など）のタブで押さないでください。誤って押したときは、`/tab/` の「止める」を押してください
- **映しているタブを閉じると、何も映らなくなります。** 失敗の表示も出ません（配信中に普通に起こる操作のためです）。続けて映すときは、別のタブでショートカットを押してください
- **映しているあいだ、そのタブの音は Chrome からは聞こえません。** 配信者は OBS のモニターで聞いてください。音は映像と同じだけ遅れて聞こえます（同じPCの中なので、0.1秒ほどです）
- **映しているタブを裏に回しても、映像は止まりません。** ほかのタブで作業しながら映せます
- **ショートカットを押してから取り込むまでに時間がかかると、失敗します。** 拡張がタブを渡すときの合図は数秒で使えなくなるためです。`/tab/` に理由が出たら、もう一度押してください
- **拡張のボタンに「!」が出たときは、うまく渡せていません。** ボタンにマウスを載せると理由が出ます（`/tab/` が開かれていない・2つ以上開かれている、など）
- **Chrome の設定画面（`chrome://` で始まるページ）などは映せません。**
- 映像は 1920×1080・30fps までです。Mac では映像をハードウェアで圧縮するので、配信中の負担は小さく抑えられます
