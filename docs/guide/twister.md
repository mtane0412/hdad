# ツイスター

レイドを受けたときに、レイドしてきた配信者と自分が、3Dの人形でツイスターゲームをするネタ機能です。人形の顔には2人の Twitch のアイコンが貼られます。スピナーを2〜3回回してできるだけ絡み合わせ、最後の指示で手を伸ばしきれずに倒れ込み、先にマットに着いた人の負けとして勝者を出します。

## 使い方

1. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「ツイスター」を置きます。マットを画面の真ん中に、スピナーを右下に出すので、大きさはオーバーレイいっぱい（1920×1080）から始まります
2. [トリガーの管理画面](./alerts.md)（`/triggers/`）で「レイドされた」の行を開き、「ツイスターで対戦する」に印を付けて保存します。ほかの出来事の行には出ません（対戦する相手が配信者とは限らないため）
3. トリガー画面の「ツイスター」のカードにある「ツイスターを試しに流す」で、レイドを待たずに1回流せます。相手は「レイドした人（試し）」（アイコンなし）で、自分は自分のアイコンで出ます

## 流れ

1回はおよそ25〜30秒です。

1. 2人が四つんばいで、マットの両端から向かい合って登場します（「○○ vs △△」）
2. スピナーを回し、「右手を赤へ」のような指示を出します。指された円が光り、指された手足が運ばれます。これを2回か3回くり返します（手番はレイドした人から交互）
3. 最後の指示は届かない円を指します。指された人は手を伸ばしきれずに倒れ込みます（スローモーション）
4. 先に手足の先のほか（ひざ・ひじ・胴・頭）がマットに着いた人の負けで、「○○の勝ち！」「△△のひざがマットに着きました」と出します

指示と倒れ方と勝敗は、Worker が引いた種（乱数）だけから決まり、毎回変わります。指示は純粋な乱数ではなく、2人が絡み合うように相手の体に近い円を選びます。

## 失敗したとき

- Twitch からアイコンを引けなかったときは、流さずにダッシュボードの失敗の記録に `twister-push-failed` として残ります（試し再生では画面に理由を出します）
- 合成ページでアイコンを読み込めなかったときは、素材の箱に理由を出し、名前の頭文字の顔で対戦を流します
- 合成ページを開いていないあいだのレイドは、あとから流れません（貯めずに落とします）

設定の項目はありません。指示の選び方・倒れ方・長さを変えたいときは、`src/twister/` を直してください（経緯は [docs/decisions/twister.md](../decisions/twister.md)）。
