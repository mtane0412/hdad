# 手書き

配信中に「ここです」と画面を指したり、簡単な図を描いて説明したりするための素材です。ブラウザで描いた線が、OBSに載せた配信画面へその場で現れます。

別の描画アプリを開いてウィンドウキャプチャで取り込む必要はありません。貼るURLは合成オーバーレイの1本だけで、位置も大きさもOBS側の設定として固定できます。

## 使い方

1. `/overlay/` を開き、映したいオーバーレイに素材「手書き」を置きます。大きさは配信画面と同じ（初期値のまま）にしてください
2. そのオーバーレイのURLを、いつもどおりOBSのブラウザソースに貼ります
3. `/draw/` を開きます。黒いキャンバスが出るので、マウスかペンタブレットで描きます

描いた線は、描いたそばから配信画面に出ます。描いたものは保存されるので、OBSのブラウザソースを作り直したり、`/draw/` を開き直したりしても残ります。

## 道具

- **色** — 白・黄・赤・青・緑から選びます。線には黒い縁取りが付くので、明るい画面でも暗い画面でも沈みません
- **太さ** — 細い・ふつう・太いから選びます
- **ペン・消しゴム** — 持ち替えます。消しゴムは、なぞった範囲だけを削るのではなく、**触れた線を1本まるごと消します**。消した線は配信画面からもすぐに消えます
- **全部消す** — 描いたものをすべて消します。**確認は出ません**（配信中に確認を挟むほうが事故のもとになるためです）

色と太さは、線を引き始めた時点のものがその線に残ります。描いている途中で変えても、その線の色は変わりません。

ひとつ戻すはまだありません。

## 背景に配信画面を敷く

「配信画面を背景に敷く」のスイッチを入れると、キャンバスの下に配信画面が薄く出ます。画面のどこに描けばよいかの目安にしてください。

- 背景の画像は、[配信画面の取り込み](./screen.md)が撮った最新の1枚です。**取り込みを動かしていないと背景は出ません**
- **背景は撮る間隔（既定60秒、最短15秒）のぶん古い画面です。** 画面の構成を見て「このあたり」と指すのには足りますが、動いているものを追って描くのには向きません
- 撮った画面が置き換わるのは**配信中だけ**です。配信していないあいだは、最後に配信したときの画面が出ます
- 撮った画面には手書きの線も映っているので、消しゴムで消した線が次に撮られるまで背景に残って見えることがあります
- 「背景の濃さ」で濃さを変えられます（初めは60%）。背景はこの画面にだけ出るもので、配信画面には出ません
- スイッチは開くたびに切れた状態から始まります

## 気をつけること

- **描いた図は、全部消すまで残ります。** 配信をまたいでも消えないので、前の配信の図を出したくないときは全消しを押してください
- **描いた直後に合成ページを読み込み直すと、最後の数本が出ないことがあります。** 描いたものは線を1本引き終えてから数秒あとに保存され、保存先への反映にも時間がかかるためです。欠けたときは描き直してください
- **`/draw/` のキャンバスは配信画面と同じ縦横比（16:9）です。** 手書きの素材を配信画面と違う縦横比の箱に置くと、図が歪みます
- **描けるのはログインしている配信者だけです。** オーバーレイ用キーを知っているだけでは描けません（キーは配信画面に映り込むことがあるためです）
