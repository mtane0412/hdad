# ペロペロ

視聴者の Twitch のアイコンを、3Dの舌が下から何度も舐め上げるジョーク演出です。チャンネルポイントの交換と、決まった人のその配信で最初の発言で流せます。

## 使い方

1. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「ペロペロ」を置きます。アイコンを画面の真ん中に大きく出すので、大きさはオーバーレイいっぱい（1920×1080）から始まります
2. [トリガーの管理画面](./alerts.md)（`/triggers/`）で、「チャンネルポイントが交換された」か「決まった人のその配信で最初の発言」の行を開き、「ペロペロする」に印を付けて保存します。ほかの出来事の行には出ません（舐める相手が1人に決まらないため）
3. （任意）トリガー画面の「ペロペロ」のカードで、舌がアイコンに触れるたびに鳴らす効果音を選んで「効果音を保存」を押します。選べるのは[素材のページ](./alerts.md)（`/media/`）でアップロードした音声で、音量も決められます。既定は「鳴らさない」です
4. トリガー画面の「ペロペロ」のカードにある「ペロペロを試しに流す」で、トリガーを待たずに1回流せます。ボタンの上の欄に Twitch のログイン名を入れると、その人のアイコンを舐めます。空なら「視聴者（試し）」（アイコンなし）を舐めます（いないログイン名なら流さずに理由を出します）。効果音は保存したものが鳴るので、未保存の変更があるあいだは押せません

## 効果音

舌がアイコンに触れはじめるたびに（1回の舐め上げにつき1回）、選んだ効果音を鳴らします。音程（再生の速さ）を毎回少し変えるので、同じ音でも繰り返しに聞こえにくくなります。前の音が鳴り終わる前に次が来たら重ねて鳴らすので、1〜3秒ほどの短い音が向いています。

音声はリポジトリに含めていません。たとえば次の音（どちらも [Freesound](https://freesound.org/) の CC0。ダウンロードには Freesound へのログインが要ります）を使えます。

- [Cartoon Licking, Big Tongue](https://freesound.org/people/MELIS12-Creator/sounds/819128/)（約3秒。漫画っぽいペロッという音）
- [Dog licking feet](https://freesound.org/people/janbezouska/sounds/494078/)（約18秒。犬が足を舐める濡れた音。リアルにキモくしたいとき向け。長いので、音声編集ソフトで1〜2秒ずつ切り出して使ってください）

## 流れ

1回はおよそ11〜14秒です。

1. 相手のアイコンと「○○ さんをペロペロ」が出てきます
2. 舌が下から伸びてきて、画面のガラスに押しつけられて平たく広がりながら、アイコンをねっとり舐め上げます。これを5〜7回くり返し、回を重ねるごとに速く、しつこくなります
3. 舐めた跡は濡れた筋と泡としてガラスに残り、ゆっくり垂れていきます。舌を離すたびに唾液の糸が伸び、細くなって切れます
4. 最後の1回は舌先を丸めてアイコンをすくい上げ、舌の裏の血管が見えます
5. 跡が垂れていくのを少し見せてから、アイコンが消えて終わります

舌の表には中央の溝と乳頭のブツブツ、奥には白っぽい苔があり、濡れたテカリを持ちます（キモいほうがウケるので、わざとリアル寄りにしています）。

舐める回数・位置・傾きは Worker が引いた種（乱数）だけから決まり、毎回変わります。続けて届いたときは、届いた順に1件ずつ流します。

## 失敗したとき

- 効果音を選んでいるのにオーバーレイ用キーが未発行のときは、流さずに `lick-push-failed` として残ります（試し再生では画面に理由を出します）。管理画面にログインすればキーが発行されます
- 合成ページで効果音を鳴らせなかった（音声を読めない・ブラウザが自動再生を拒んだ）ときは、素材の箱に理由を出し、効果音なしで流します
- Twitch を呼べなかったときは、流さずにダッシュボードの失敗の記録に `lick-push-failed` として残ります（試し再生では画面に理由を出します）
- その人が Twitch にいない（アカウントが消えたなど）ときや、合成ページでアイコンを読み込めなかったときは、名前の頭文字の顔を舐めます（読み込めなかったときは素材の箱に理由を出します）
