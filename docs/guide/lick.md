# ペロペロ

視聴者の Twitch のアイコンを、3Dの舌が下から何度も舐め上げるジョーク演出です。チャンネルポイントの交換と、決まった人のその配信で最初の発言で流せます。

## 使い方

1. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「ペロペロ」を置きます。アイコンを画面の真ん中に大きく出すので、大きさはオーバーレイいっぱい（1920×1080）から始まります
2. [トリガーの管理画面](./alerts.md)（`/triggers/`）で、「チャンネルポイントが交換された」か「決まった人のその配信で最初の発言」の行を開き、「ペロペロする」に印を付けて保存します。ほかの出来事の行には出ません（舐める相手が1人に決まらないため）
3. トリガー画面の「ペロペロ」のカードにある「ペロペロを試しに流す」で、トリガーを待たずに1回流せます。ボタンの上の欄に Twitch のログイン名を入れると、その人のアイコンを舐めます。空なら「視聴者（試し）」（アイコンなし）を舐めます（いないログイン名なら流さずに理由を出します）

## 流れ

1回はおよそ11〜14秒です。

1. 相手のアイコンと「○○ さんをペロペロ」が出てきます
2. 舌が下から伸びてきて、画面のガラスに押しつけられて平たく広がりながら、アイコンをねっとり舐め上げます。これを5〜7回くり返し、回を重ねるごとに速く、しつこくなります
3. 舐めた跡は濡れた筋と泡としてガラスに残り、ゆっくり垂れていきます。舌を離すたびに唾液の糸が伸び、細くなって切れます
4. 最後の1回は舌先を丸めてアイコンをすくい上げ、舌の裏の血管が見えます
5. 跡が垂れていくのを少し見せてから、アイコンが消えて終わります

舌の表には中央の溝と乳頭のブツブツ、奥には白っぽい苔があり、濡れたテカリを持ちます（キモいほうがウケるので、わざとリアル寄りにしています）。

舐める回数・位置・傾きは Worker が引いた種（乱数）だけから決まり、毎回変わります。続けて届いたときは、届いた順に1件ずつ流します。

## 失敗したとき

- Twitch を呼べなかったときは、流さずにダッシュボードの失敗の記録に `lick-push-failed` として残ります（試し再生では画面に理由を出します）
- その人が Twitch にいない（アカウントが消えたなど）ときや、合成ページでアイコンを読み込めなかったときは、名前の頭文字の顔を舐めます（読み込めなかったときは素材の箱に理由を出します）
