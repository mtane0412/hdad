# BGM（`/bgm/`）

配信で流すBGMの曲を管理し、配信中に流す曲をその場で切り替えます。曲ごとに**クレジット表記・クレジット先のURL・曲調・流したい場面**を控えておけます。鳴らすのは[裏方](./backstage.md)のページで、OBSのブラウザソースの音声として配信に乗せます。

## 使いはじめ方

1. 「アップロード」（`/media/`）のページで、曲の音声（mp3 など。1つ50MBまで）を上げる
2. 「BGM」（`/bgm/`）のページで、上げた音声を選んで ＋（曲を追加する）を押し、曲名・クレジット表記などを書いて「曲の一覧を保存」を押す
3. 「裏方」（`/backstage/`）のページで **BGM** に印を付け、コピーしたURLをOBSのブラウザソースに貼る（すでに裏方を貼っているなら、そのURLを貼り替える）。ソースのプロパティで**「OBSで音声を制御する」を有効にする**
4. 「BGM」のページで曲の「流す」ボタンを押すと、その曲が流れ始める

## 曲の項目

| 項目 | 内容 |
| --- | --- |
| 曲名 | 必須。60文字まで。追加したときはファイル名から拡張子を落としたものが入ります |
| クレジット表記 | 必須。100文字まで。配布元が求める書き方のまま書きます |
| クレジット先のURL | 任意。200文字まで。`http://` か `https://` で始まるURL。視聴者に紹介するための出典で、音声の読み先ではありません |
| 曲調 | 任意。200文字まで（例: ゆったりしたアコースティック） |
| 流したい場面 | 任意。200文字まで（例: 雑談・作業配信） |

## 流す・止める・音量

- **曲の「流す」を押すと、すぐに切り替わります**（OBSの再読み込みは要りません）。前の曲は2秒かけて下がり、次の曲が上がってつながります
- **曲はループで流れ続けます**。止めるときは「止める」を押します
- 音量のつまみは、離したときに効きます
- 曲の情報（曲名など）を直しても、流している曲が頭から流れ直すことはありません
- **まだ保存していない曲は流せません**。「曲の一覧を保存」を押してから流してください
- **流している曲は一覧から外せません**。先に止めるか、別の曲に切り替えてください。BGMの曲に使っている音声は「アップロード」のページからも消せません

曲名・クレジット表記・クレジット先のURLの長さの上限は、3つを並べた文がチャットの1通（500文字）に収まるように決めてあります（下の `{bgm}` を参照）。

## 配信の話題に合う曲へ自動で切り替える（Jev）

「BGM」のページで **「配信の話題に合う曲へ自動で切り替える（Jev）」** に印を付けると、判定用のモデル Jev が配信の話題や雰囲気に合う曲を選んで切り替えます。**既定はオフ**です。

- 選ぶ手がかりは曲ごとの **曲調** と **流したい場面** です。どちらも書いていない曲は選ばれません
- 配信中に、これまでのあらすじを作り直すたび（5分おき。喋っていない間は作り直しません）に、あらすじと直近の発話から1曲を選びます。そのため切り替わるのは話題が変わってから数分後です
- **迷ったときは切り替えません。** いまの曲が合っていると判断したときも、そのままにします
- **曲を切り替えてから10分は、次の切り替えをしません。** 手で切り替えたときも同じなので、手で選んだ直後に Jev が上書きすることはありません（音量だけを変えたときは数えません）
- **BGMを止めているあいだは、Jev が勝手に流し始めることはありません**
- Jev が切り替えた曲は配信（裏方のページ）と素材「再生中の曲」にはすぐ反映されますが、「BGM」のページの「いま流している曲」はページを開き直すまで変わりません
- Jev は OpenRouter から呼ぶので、`OPENROUTER_API_KEY` と残高が要ります。呼んだ回数は「LLM」のページの「BGMの選択（Jev）」に出ます。判定に失敗したときは曲を変えず、ダッシュボードの失敗の記録に `bgm-choice-failed` として残ります

## クレジットを視聴者に見せる

- **配信画面**: 構成の管理画面（`/overlay/`）で素材「再生中の曲」を置くと、流している曲の曲名とクレジット表記が画面の左下に出ます。曲を切り替えるとすぐに変わり、止めているあいだは何も出ません。クレジット先のURLは配信画面では押せないので出しません
- **チャット**: [チャットボット](./bot.md)のコマンドの応答文に `{bgm}` を書くと、流している曲の曲名・クレジット表記・クレジット先のURLに置き換わります（例: `!bgm` に「いまの曲: {bgm}」）。止めているときは「いまはBGMを流していません」に置き換わります

## うまく鳴らないとき

- 裏方のページのURLに `bgm=true` が入っているか確かめてください（BGMは既定では鳴らしません。貼ってあるブラウザソースが、曲を選んだ途端に黙って鳴り出さないようにするためです）
- 裏方のページの **BGM** の枠に、いま流している曲か失敗の理由が出ます。OBSでソースを右クリックして「対話」を開くと見られます
- 普通のブラウザのタブで裏方のページを開くと、ブラウザが操作前の音の再生を拒むことがあります。OBSのブラウザソースでは拒まれません
