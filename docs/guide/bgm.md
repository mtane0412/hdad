# BGM（`/bgm/`）

配信で流すBGMの曲を管理し、配信中に流す曲をその場で切り替えます。曲ごとに**クレジット表記・クレジット先のURL・曲調・流したい場面**を控えておけます。鳴らすのは[裏方](./backstage.md)のページで、OBSのブラウザソースの音声として配信に乗せます。

## 使いはじめ方

1. 「アップロード」（`/media/`）のページで、曲の音声（mp3 など。1つ50MBまで）を上げる
2. 「BGM」（`/bgm/`）のページで、上げた音声を選んで ＋（曲を追加する）を押し、曲の一覧（表）の行に曲名・クレジット表記などを書いて「曲の一覧を保存」を押す。🎧 で曲をこの画面だけで試し聴きできます
3. 「コネクター」（`/connectors/`）のページの「OBS用のURL」で **BGM** に印を付け、コピーしたURLをOBSのブラウザソースに貼る（すでに裏方を貼っているなら、そのURLを貼り替える）。ソースのプロパティで**「OBSで音声を制御する」を有効にする**
4. 「BGM」のページのプレーヤーで ▶（再生）を押すと一覧の最初の曲から、曲の一覧の ▶（流す）を押すとその曲から流れ始める

## 曲の項目

| 項目 | 内容 |
| --- | --- |
| 曲名 | 必須。60文字まで。追加したときはファイル名から拡張子を落としたものが入ります |
| クレジット表記 | 必須。100文字まで。配布元が求める書き方のまま書きます |
| クレジット先のURL | 任意。200文字まで。`http://` か `https://` で始まるURL。視聴者に紹介するための出典で、音声の読み先ではありません |
| 曲調 | 任意。200文字まで（例: ゆったりしたアコースティック） |
| 流したい場面 | 任意。200文字まで（例: 雑談・作業配信） |

## プレーヤー（流す・止める・次の曲・リピート・シャッフル・音量）

「BGM」のページの上にあるプレーヤーで、配信で流している曲を操作します。押したらすぐに切り替わります（OBSの再読み込みは要りません）。曲を切り替えると、前の曲は2秒かけて下がり、次の曲が上がってつながります。

| ボタン | 動き |
| --- | --- |
| ▶ 再生 / ⏸ 停止 | 止めているときは一覧の最初の曲（シャッフル中はでたらめに選んだ曲）から流し始めます。流しているときは止めます |
| ⏮ 前の曲 / ⏭ 次の曲 | 一覧の順に1曲戻す・進めます。シャッフル中の「次の曲」はでたらめに選びます（「前の曲」はシャッフル中も一覧の順に戻ります） |
| リピート | 入れると、流している曲を繰り返します |
| シャッフル | 入れると、次の曲を一覧の順ではなく、いま流している曲以外からでたらめに選びます |
| ✨ Jev | 入れると、配信の話題に合う曲へ Jev が自動で切り替えます（下の「配信の話題に合う曲へ自動で切り替える」） |

- **リピートを切っているあいだは、曲が終わると次の曲へ進みます（通常の再生）。** 一覧の順に進み、最後の曲の次は最初の曲に戻るので、BGMが途切れることはありません。曲が1つだけなら同じ曲をもう一度流します
- 曲の一覧の ▶（流す）を押すと、その曲へ切り替わります
- 曲の終わりで進んだ曲や Jev が切り替えた曲も、プレーヤーと曲の一覧にすぐ映ります
- 音量のつまみは、離したときに効きます
- **どのページを見ていても、画面の下端のバー（配信中の操作）から BGM を操作できます。** バーには流している曲名・⏮ 前の曲・▶ 再生 / ⏸ 停止・⏭ 次の曲・音量（狭い画面では音量を除く）があり、曲名を押すと「BGM」のページへ移ります。リピート・シャッフル・✨ Jev は「BGM」のページのプレーヤーだけにあります。バーとページのプレーヤーはいつも同じ曲・音量を映します
- オーバーレイ用キーが未発行のときや、切り替えの知らせを受け取れていないとき、操作に失敗したときは、バーの曲名の下に理由が赤字で出ます
- 曲の情報（曲名など）を直しても、流している曲が頭から流れ直すことはありません
- **まだ保存していない曲は流せません**。「曲の一覧を保存」を押してから流してください
- **流している曲は一覧から外せません**。先に止めるか、別の曲に切り替えてください。BGMの曲に使っている音声は「アップロード」のページからも消せません

曲名・クレジット表記・クレジット先のURLの長さの上限は、3つを並べた文がチャットの1通（500文字）に収まるように決めてあります（下の `{bgm}` を参照）。

## 配信の話題に合う曲へ自動で切り替える（Jev）

「BGM」のページのプレーヤーで ✨（配信の話題に合う曲へ自動で切り替える（Jev））を押して入れると、判定用のモデル Jev が配信の話題や雰囲気に合う曲を選んで切り替えます。**既定はオフ**です。

- 選ぶ手がかりは曲ごとの **曲調** と **流したい場面** です。どちらも書いていない曲は選ばれません
- 配信中に、これまでのあらすじを作り直すたび（5分おき。喋っていない間は作り直しません）に、あらすじと直近の発話から1曲を選びます。そのため切り替わるのは話題が変わってから数分後です
- **迷ったときは切り替えません。** いまの曲が合っていると判断したときも、そのままにします
- **曲を切り替えてから10分は、次の切り替えをしません。** 手で切り替えたときも同じなので、手で選んだ直後に Jev が上書きすることはありません（音量だけを変えたときは数えません）
- **BGMを止めているあいだは、Jev が勝手に流し始めることはありません**
- [ポモドーロ](./pomodoro.md)の休憩中は、休憩の曲へ切り替えた時刻から10分を数えるので、5分の休憩のあいだは Jev が曲を変えません。休憩中に長く一時停止すると、Jev が曲を切り替えることがあります（休憩が明ければ休憩の前の曲へ戻ります）
- Jev は OpenRouter から呼ぶので、`OPENROUTER_API_KEY` と残高が要ります。呼んだ回数は「LLM」のページの「BGMの選択（Jev）」に出ます。判定に失敗したときは曲を変えず、ダッシュボードの失敗の記録に `bgm-choice-failed` として残ります

## 市町村紹介とツイスターのあいだは下がる

[市町村紹介](./town-tour.md)で BGM の枠に音声を選んでいると、紹介の BGM が鳴るあいだ、配信の BGM は自動で4分の1の音量まで下がり、紹介が終わると元の音量へ戻ります。[ツイスター](./twister.md)で BGM を選んでいるときも、対戦のあいだ同じように下がり、対戦が終わると戻ります。下げる量は決まっていて、変えられません。

- 紹介を作れなかったときは、すぐ元の音量へ戻ります
- 合成ページを閉じた・再読み込みした・知らせが届かなかったときも、遅くとも紹介・対戦が終わるはずだった時刻（紹介を待っているあいだなら30秒後）には戻ります
- 下がっているあいだに曲や音量を変えても、下がったままの割合で鳴ります
- 裏方のページで BGM を鳴らしていないときは、何も起きません（紹介・対戦はそのまま流れます）

## クレジットを視聴者に見せる

- **配信画面**: 構成の管理画面（`/overlay/`）で素材「再生中の曲」を置くと、流している曲の曲名とクレジット表記が画面の左下に出ます。曲を切り替えるとすぐに変わり、止めているあいだは何も出ません。クレジット先のURLは配信画面では押せないので出しません
- **チャット**: [チャットボット](./bot.md)のコマンドの応答文に `{bgm}` を書くと、流している曲の曲名・クレジット表記・クレジット先のURLに置き換わります（例: `!bgm` に「いまの曲: {bgm}」）。止めているときは「いまはBGMを流していません」に置き換わります

## うまく鳴らないとき

- 裏方のページのURLに `bgm=true` が入っているか確かめてください（BGMは既定では鳴らしません。貼ってあるブラウザソースが、曲を選んだ途端に黙って鳴り出さないようにするためです）
- 裏方のページの **BGM** の枠に、いま流している曲か失敗の理由が出ます。OBSでソースを右クリックして「対話」を開くと見られます
- 普通のブラウザのタブで裏方のページを開くと、ブラウザが操作前の音の再生を拒むことがあります。OBSのブラウザソースでは拒まれません
