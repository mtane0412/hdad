# 人形（`/dolls/`）

視聴者に人形を渡し、持たせておけます。人形は「ふつうの人形」と、ふつうの人形3つ分の価値を持つ「スーパー人形」の2種類を1組として登録し、配信ごとに使う組を「いまの人形」に選びます。渡した人形は配信をまたいで残り、過去の配信の人形も集めたものとして数が見えます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

## 人形を登録する

1. [アラート](./alerts.md)と同じアップロードのページ（`/media/`）で、ふつうの人形とスーパー人形の画像を追加します
2. サイドバーの「人形」（`/dolls/`）の「人形を追加」で、それぞれの名前（20文字まで）と画像を選んで「追加する」を押します
3. 一覧の行を押して開き、「いまの人形にする」を押します。押したその場で保存されます

- いまの人形に選べるのは1組だけです。別の組を選ぶと、前の組は外れます。「いまの人形から外す」で、どの組も選ばない状態にもできます
- 名前と画像はあとから書き換えられます（持っている人の数はそのまま残ります）
- **一度でも視聴者に渡したことのある組は消せません**（集めた記録が残っているためです）
- 人形の画像に使っている素材は、アップロードのページから消せません

## 視聴者に渡す・取り上げる

[視聴者の記録](./viewers.md)（`/viewers/`）で人の行を押して開くと、その人がいまの人形を種類ごとにいくつ持っているかが出ます。＋で1つ渡し、−で1つ取り上げます。前に使った人形を持っていれば、「これまでの人形」として数が出ます。

- 渡せる・取り上げられるのは、いまの人形だけです。いまの人形を選んでいないと、渡すボタンは出ません
- 持っていない種類は取り上げられません（数が負になることはありません）
- 視聴者の記録を削除すると、その人が持っている人形の記録も消えます

## トリガーで渡す

[トリガー](./alerts.md)（`/triggers/`）の行で「人形を渡す」を選ぶと、その出来事を起こした人に、いまの人形を選んだ種類と個数（1〜10）だけ渡せます。たとえばチャンネルポイントの報酬「人形をもらう」の行に付ければ、交換した人にふつうの人形が渡ります。

- 選べるのは、出来事を起こした人が視聴者に決まる行だけです（チャットの発言・チャンネルポイント・フォロー・サブスク・レイド）。レイドでは、レイドしてきた配信者に渡ります
- botを接続していなくても渡せます
- Twitch から同じ通知が送り直されても、二重には渡しません
- いまの人形が選ばれていないときは渡さず、[配信の記録](./stats.md)の失敗の一覧に `doll-grant-failed` を残します。交換されたポイントは返しません

## ゲームの正解者に渡す

[チャットで推理](./chat-deduction.md)と[漢字クイズ](./kanji-quiz.md)では、正解した人にいまの人形を1つ渡せます。渡す人形はゲームごとに「正解者に渡す人形」の欄で選びます（渡さない・ふつうの人形・スーパー人形。選んだその場で保存されます）。最初は「渡さない」です。

- チャットで推理は `/chat-deduction/` の「ゲーム」の区画、漢字クイズはトリガーのページ（`/triggers/`）の「演出の設定」のタブにある「漢字クイズ」のカードに欄があります
- 渡すのは、チャットで推理ならゲームを終わらせた正解者、漢字クイズなら最初の正解者の1人だけです。1つのゲーム（1問）で渡すのは1回だけで、Twitch から同じ通知が送り直されても二重には渡しません
- 漢字クイズの試し再生で正解した人には渡しません
- いまの人形が選ばれていないときなど、渡せなかったときも、ゲームはそのまま終わり、解説も出ます。渡せなかったことは[配信の記録](./stats.md)の失敗の一覧に `doll-grant-failed` として残ります

## 渡したことを配信の画面に出す

[合成オーバーレイ](./overlay.md)（`/overlay/`）に素材「人形の獲得」を置くと、トリガーやゲームの正解で人形を渡したときに、人形の画像と「◯◯さんが クマ人形 を獲得！」を画面の真ん中に6秒ほど出します。2つ以上渡したときは「×3」のように個数を添え、スーパー人形は後ろに金色の光を回して見分けられるようにします。

- 出すのは、トリガーとゲームの正解者で渡したときだけです。`/viewers/` から手で渡した・取り上げたときは出しません
- 素材の箱を小さくすると、人形と文言も同じ割合で小さくなります。漢字クイズの正解などの演出と重なるときは、`/overlay/` で箱を小さくして画面の隅に置いてください（推奨の大きさは配信画面いっぱいです）
- 続けて渡したときは、届いた順に1件ずつ出します。下部バーの「演出を消す」で、出している1件を消せます
- 合成ページを開いていないあいだに渡したものは、あとから出しません（人形は渡したままです）
- 人形の画像を読めなかったときや、オーバーレイ用キーが未発行のときは演出を出さず、素材の箱か[配信の記録](./stats.md)の失敗の一覧（`doll-award-failed`）に理由を残します。渡した人形はそのまま残ります
