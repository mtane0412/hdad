# ポモドーロ（`/pomodoro/`・素材の種類「ポモドーロ」）

作業配信で「みんなで同じリズムで作業している」感覚を出すため、**25分の作業と5分の休憩**を繰り返すタイマーを配信画面に出します。区切り（作業の開始・休憩の開始）でトリガーを動かせるので、休憩に入ったら bot に「進捗どうでした？」と書き込ませる、といった使い方ができます。休憩中は BGM を休憩用の曲に切り替えられます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

## タイマーを動かす

アプリのサイドバーの「ポモドーロ」（`/pomodoro/`）で操作します。押したらすぐに配信画面へ反映されます（OBSの再読み込みは要りません）。

| ボタン | 出るとき | すること |
| --- | --- | --- |
| 始める | 止めているとき | 1本目の作業から始めます |
| 一時停止 | 動いているとき | 残り時間をそのままにして止めます。区切りは来ません |
| 再開 | 一時停止しているとき | 止めていた時間を飛ばして、続きから進めます |
| 止める | 動いている・一時停止しているとき | タイマーを消します。休憩中に止めたときは、休憩の前の曲へ戻します |

- 作業と休憩の長さは25分・5分で決まっています（長い休憩はありません）。変えたいときは `src/pomodoro/phase.ts` の定数を直してください
- 「何本目か」は作業ごとに1つ増えます。休憩は直前の作業と同じ番号です
- 別の窓で操作したあとなどに、画面の状態と合わない操作をすると断られて理由が出ます。そのときは画面が今の状態に読み直されます

## 休憩中の BGM

「ポモドーロ」のページの「休憩中に流す曲」で、[BGM](./bgm.md)の一覧から1曲選びます。選んだらすぐ保存されます。

- 休憩に入ると選んだ曲に切り替え、休憩のあいだは繰り返して流します。休憩が明けたら、休憩の前に流していた曲（止めていたなら止めた状態）と繰り返しの設定へ戻します
- 休憩中に変えた音量とシャッフルは、休憩が明けてもそのままです
- 「曲を変えない」を選んでいると、休憩に入っても BGM は変わりません
- 休憩に入ってから10分は、Jev による自動の切り替えは起きません（5分の休憩ならその間ずっと休憩の曲のままです）。休憩中に長く一時停止すると、Jev が曲を切り替えることがあります。その場合も、休憩が明けたら休憩の前の曲へ戻します
- 休憩の曲を BGM の一覧から外してしまうと、休憩に入っても曲は変わらず、ダッシュボードの失敗の記録に `pomodoro-bgm-failed` が残ります

## 配信画面に出す

[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「ポモドーロ」を追加します。配信者が決めるパラメータはありません。

- 「作業中」「休憩中」「一時停止中」・何本目か・残り時間・進み具合の棒を、小さな札に出します。作業中は赤、休憩中は緑で色分けし、一時停止中は全体を淡くします
- 止めているあいだは何も映しません
- 追加したときの大きさは 420×200px です
- 残り時間は配信画面のPCの時計で数えるので、OBSを開き直しても表示はずれません
- 始めた・一時停止・再開・止めたことは、アラートと同じ接続ですぐに届きます。開き直したとき・つなぎ直したとき・5分おきにも Worker から読み直します
- 見栄えを確かめるには `/overlay/` のプレビューを開きます（作業中・休憩中・一時停止中の札を順に流します）

## 区切りでトリガーを動かす

[トリガー](./alerts.md)のページ（`/triggers/`）の区分「ポモドーロ」に、2つの項目が並んでいます。

| 項目 | 動くとき |
| --- | --- |
| 作業が始まった | タイマーを始めたときと、休憩が明けたとき |
| 休憩が始まった | 25分の作業が終わったとき |

文言には `{round}`（何本目か）と `{minutes}`（始まった区間の長さ。分）が使えます。区切りには相手がいないので `{user}` は使えません（書いても置き換わりません）。

- 例: 作業が始まった →「{round}本目の作業を始めます。{minutes}分がんばりましょう」
- 例: 休憩が始まった →「{round}本目おつかれさまでした。{minutes}分休憩です。進捗どうでした？」

## 配信していないとき

- タイマーは配信の前に始めておけます。ただし始めたときのトリガーは、配信していなければ動きません
- 配信していないときに区切りを迎えると、トリガーは動かさずに**タイマーを止めます**（休憩の前の曲へは戻します）。配信のあとに止め忘れたタイマーが、次の配信に持ち越されないようにするためです

## 失敗の出方

配信画面への押し出し・BGM の切り替え・トリガーの実行に失敗しても、タイマーは進み続けます。失敗はダッシュボードの失敗の記録に `pomodoro-push-failed`・`pomodoro-bgm-failed`・`pomodoro-trigger-failed` として残ります（[配信の記録](./stats.md)）。
