# 字幕

配信者が話していることを、配信画面の下端に字幕として出す素材です（素材の種類「字幕」）。文字にするのは、アプリのページで動かす Chrome の音声認識（[配信中の文字起こし](./transcript.md)の Web Speech API）です。PCに常駐させるものは要りません。

## 使い方

1. アプリの「コネクター」のページ（`/connectors/`）の **Web Speech API** の区画で「文字起こしする」をオンにします（[配信中の文字起こし](./transcript.md#アプリのページで認識するweb-speech-api)）
2. `/overlay/` を開き、映したいオーバーレイに素材「字幕」を置きます。大きさは配信画面と同じ（初期値のまま）にしてください。字幕は箱の下端に中央寄せで出ます
3. そのオーバーレイのURLを、いつもどおりOBSのブラウザソースに貼ります

話し始めると、認識している途中の文が書き換わりながら出て、確定すると確定した文に置き換わります。

## 英語の字幕を添える

確定した文を英語に訳し、原文のすぐ下に小さめの文字で添えられます。`/llm/` の **字幕の翻訳** の区画で提供元を選んで「翻訳の設定を保存」を押してください。既定は「訳さない」です。

| 提供元 | 用意するもの | 料金の目安（月89時間・約39万字） | 備考 |
|---|---|---|---|
| LLM | なし（Workers AI のとき）・`OPENROUTER_API_KEY`（OpenRouter のとき） | 約 $1.4 | 提供元とモデルは「AIを使う箇所」の表の「字幕の翻訳（LLM）」の行で選びます。直前の2件の発話を手がかりに訳します |
| Workers AI の翻訳専用モデル（m2m100） | なし | 約 $0.25 | 1件ずつ訳します |
| DeepL API Free | シークレット `DEEPL_API_KEY` | $0（月50万字まで） | 直前の2件の発話を手がかりに訳します（その分は文字数に数えられません）。今月の使用量と残りは `/llm/` に出ます |

```bash
# https://www.deepl.com/your-account/keys で発行した DeepL API Free の鍵（末尾が :fx）を設定する
npx wrangler secret put DEEPL_API_KEY
# ローカル（npm run dev）では .dev.vars に DEEPL_API_KEY=... と書く
```

- 訳すのは確定した文だけです。話している途中の文は何度も書き換わるので訳しません
- 訳は原文より少し遅れて届きます。訳が届いた行は、そこから6秒映します
- 訳せなかったとき（鍵が無い・無料枠を使い切った・提供元が失敗した）は原文の字幕だけを出し、理由をコネクターのページの Web Speech API の区画に赤で出します。ダッシュボードの失敗の記録にも `translation-failed` として残ります。黙って別の提供元へ切り替えることはしません
- 訳した回数は `/llm/` の「字幕の翻訳（LLM）」の行に数えます（m2m100・DeepL で訳した回数も含みます）

## 出し方

字幕の見た目は設定項目を持たず、次のとおりに決めてあります（変えたいときはコードを直します。経緯は下のリンク先にあります）。

- **出すのは2行まで**です。新しいものが下に来て、3行目が来たら古いものから消えます。1行が長いときは折り返し、箱からはみ出した分は上から隠れます
- **確定した文は6秒で消えます**（英語の訳を添えた文は、訳が届いてから6秒）。話している途中の文は、確定した文より少しだけ薄く出ます
- 話している途中の文が10秒書き換わらなければ消えます（認識していたタブを閉じたときに、話しかけの文が残り続けないためです）
- 白い太字に黒い縁取りを付けます。板を敷かないので、ゲームの画面の上でも隠す面積が小さく済みます

## 気を付けること

- **字幕を出すのは、認識しているタブ（HDAD を開いている Chrome のタブ）が開いているあいだだけです**。タブを閉じると字幕も止まります
- 字幕は流れていくものなので保存しません。OBSのブラウザソースを開く前に話したことは出ません
- 字幕の中継先とつながらないときは、コネクターのページの Web Speech API の区画に理由が赤で出ます。つなぎ直しは自動で続けます
- 配信画面の字幕の箱には、つながらない理由を出しません（箱は配信画面全体に置くので、失敗の表示が配信画面全体を覆ってしまうためです）。出すのは一度もつながらないとき（オーバーレイ用キーの誤りなど）と、届いた字幕が読めないときだけです
- `/overlay/` のプレビューでは、サンプルの発話が順に流れます
