# ワイプ（素材の種類「ワイプ」）

バラエティ番組のワイプのように、チャットの発言を**1件ずつ**、発言した人の **Twitch のアイコンを映した枠**と、その左の**吹き出し**で配信画面に出します。読み上げがオン（ミュートしていない）なら、ワイプがその発言を [VOICEVOX](./speech.md) で読み上げ、**読み上げているあいだだけ**吹き出しを出します。利用には[デプロイ](./deploy.md)の Twitchログインの設定と、[チャットの読み上げ](./speech.md)の VOICEVOX（またはさくらのAI Engine）の設定が必要です。

配信画面に出すには、[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「ワイプ」を追加します（配信画面の右上に置かれた状態で追加されます）。パラメータはありません。

## 出し方

- **チャットの発言をすべて、届いた順に1件ずつ出します。** 前の発言を読み終えたら、少し（0.8秒）残してから次の人へ替わります。次が無ければすぐには引っ込まず、6秒残してから引っ込みます（そのあいだに次の発言が届けば、すぐ次の人へ替わります）
- 出す発言は**読み上げる発言と同じ**です。読み上げない人（bot）・コマンド（`!` で始まる発言）・エモートだけの発言は出しません
- 読み上げが追いつかないほどチャットが速いときは、待っている発言が10件を超えた分から古いほうを捨てます（読み上げと同じです）
- **ミュート中は読み上げず**、文の長さに応じた時間（3〜8秒）だけ出して次へ進みます。画面下端のバーでミュートすると、読んでいる途中の1件はその場で止まります
- 吹き出しの本文はエモートも絵で出します。長い発言は4行で打ち切り、末尾に「…」を出します（読み上げも「読み上げる長さの上限」で打ち切ります）
- **モデレーターに消された発言は、出している途中でもすぐ引っ込めます**（発言の削除・BAN・タイムアウト・チャットの全消去）
- アイコンは発言した人ごとに一度だけ Twitch から読み込みます。読み込めなかった人の発言は出さずに飛ばし、理由を素材の枠に出します（次にその人が発言したときに読み込み直します）

## 読み上げとの関係

- 読み上げの設定（話者・速度・音量・長さ・名前を読むか・読み上げない人）とミュートは、[チャットの読み上げ](./speech.md)と同じものを使います。変えるのはアプリの「コネクター」のページの「VOICEVOX」です
- **ワイプを置いたら、裏方の読み上げは使えません。** ワイプと裏方の両方が同じ発言を読むと二重に聞こえるため、構成にワイプがあると、裏方の読み上げは始まらずに理由を画面に出します。裏方を開いたままワイプを置いたときも、裏方が次に構成を読み直せたとき（30秒おき）に読み上げが止まって理由が出ます（それまでの間は二重に聞こえます。通信の失敗で読み直せなかった回は、その次の読み直しまで止まりません）。[裏方](./backstage.md)のURLは「VOICEVOX」のチェックを外したもの（`?speech=false`）に貼り替えてください
- **ワイプは構成全体で1つまで**です（2つ置くと同じ発言を2つのワイプが読むため、保存のときに断ります）
- 音は**合成オーバーレイのブラウザソース**から出ます。OBSでそのブラウザソースの音声が配信に乗るようにしてください（市町村紹介の音と同じです）
- VOICEVOX が動いていないなど、読み上げの準備ができないときは、ワイプは何も出さずに理由を素材の枠に出します

## 置き方

- 追加したときは、配信画面の右上に480×460pxの大きさで置かれます。アイコンの小さな枠は素材の枠の右上に、吹き出しはその下に出ます（吹き出しの尾が上のアイコンを指します）
- 以前に追加したワイプは、位置と大きさが変わりません。`/overlay/` の配置用の枠で右上へ動かしてください
- 見栄えと配置は `/overlay/` のプレビューで確かめられます（サンプルの発言が順に出ます。プレビューでは読み上げません）
