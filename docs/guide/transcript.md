# 配信中の文字起こし

配信者が喋った内容を Worker に取り込みます。取り込み自体は映すものを持たず（素材「[字幕](./caption.md)」で配信画面に出せます）、[これまでのあらすじ](./bot.md#これまでのあらすじ)と[サイドスーパー](./side-super.md)の材料になります（どちらも、取り込んでいなければ視聴者の発言とカテゴリ・タイトルだけを材料に作られます）。

認識は HDAD のアプリのページが Chrome の音声認識（Web Speech API）で行います。Chrome で HDAD を開いておくだけで、PCに常駐させるものは要りません（以前の ゆかコネNEO からの中継 `transcript/relay/` は issue #192 で消しました）。

## 使い方

アプリの「コネクター」のページ（`/connectors/`）の **Web Speech API** の区画で「文字起こしする」をオンにします。Chrome の音声認識が配信者の声を文字にし、確定した発話を Worker へ送ります。

- **認識するのは HDAD を開いている Chrome のタブです**。ほかのページに移っても認識は続きます。画面下部のバーの「文字起こし」ボタンでどのページからでもオン・オフでき、オンのあいだはその横に「聞いています」などの状態が出ます（押すとコネクターのページの詳しい様子へ移ります）。タブを閉じると止まるので、**配信中は HDAD を別のウィンドウで開いたままにしてください**。OBS のブラウザソースでは Chrome の音声認識が使えないため、OBS には置けません
- オン・オフは**このブラウザに覚えます**。オンのまま開き直せば、開いただけで始め直します（別の端末で HDAD を開いても、そこでは始めません）
- HDAD を2つ以上のタブで開いていても、**認識するのは1つのタブだけです**（同じ発話を二重に記録しないため）。ほかのタブには「別のタブで認識中」と出て、認識しているタブを閉じると代わりに始めます
- Chrome は黙っているときなどに認識を勝手に終えるので、**終わったらすぐつなぎ直します**。マイクも開いたままにします（Chrome が裏に回ったタブを止めないようにするためです）。つなぎ直しが5秒を超えて戻らないときは「途切れています」と黄色で出します
- マイクが許可されていない・外れた、つなぎ直しが1分に30回を超えたなど、続けられないときは**止めて理由を赤で出します**。コネクターのページの「もう一度始める」で始め直します（マイクの許可を求め直すには、ボタンを押すことが要る場合があります）
- コネクターのページには、話している途中の文・つなぎ直した回数と途切れた時間の合計・直近50件の発話と記録できたかどうか（`記録`・`配信外`・`送れませんでした`）が出ます。通信の失敗なら、同じ発話を少し待って3回まで送り直します
- 裏に回したタブが止められないよう、Chrome の設定の「パフォーマンス」で、HDAD のサイトを「常にアクティブにするサイト」に追加してください
- **配信していないあいだの発話は Worker が捨てます**（区画に「配信外」と出ます）。配信の前後にオンのままにして構いません。1件は1000文字までです
- 取り込んだ発話はD1（`transcripts`）に貯まりますが、**配信が終わって1日で cron が消します**（あらすじの材料にするための一時的な記録で、配信後に残す意味がないためです。配信の直後に読み返せるよう1日だけ残します）
- 話している途中の文と確定した文は、オーバーレイの素材「[字幕](./caption.md)」にも送ります（配信していないあいだも送ります）。字幕の中継先とつながらないときは、この区画に理由が赤で出ます

## OBS のマイクのミュートと連動する

電話に出るときなどに OBS でマイクをミュートしても、Chrome の音声認識は別にマイクを開いているので止まりません。そのままだと通話の声が字幕と記録に出てしまうので、**OBS のマイクのミュートに合わせて文字起こしを止める**ことができます。

1. コネクターのページの **Gyazo** の区画で、OBS のポートとパスワードを保存します（[配信画面の取り込み](./screen.md)と同じ設定を使います。Gyazo のトークンが無くても、つなぎ先とパスワードの保存だけで足ります）
2. **Web Speech API** の区画の「ミュートを見張るOBSの入力」に、OBS の音声ミキサーに出ているマイクの名前（例: `マイク`）を入れて保存します。空にすると見張りません

- 見張るのは、文字起こしをしているタブです。そのタブが OBS（`ws://localhost:<ポート>`）へつなぎます。はじめてつなぐとき、Chrome が「ローカルネットワークへのアクセス」の許可を求めることがあるので、許可してください
- OBS でマイクをミュートすると、**話している途中の文を確定させずに捨てて**文字起こしを止め、字幕からも消します。下部のバーには「OBSでミュート中」と出ます。ミュートを解除すると始め直します
- OBS につながらない・入力の名前が OBS に無いときは、**文字起こしを続けたまま**、下部のバーに「OBSのミュートを見張れていません」と黄色で出し、区画に理由を出します。10秒ごとにつなぎ直すので、OBS をあとから起動しても構いません
- **ミュートしたまま OBS とつながらなくなったときは、ミュートの解除が分かるまで止めたままにします**（通話中に OBS が落ちても、通話の声を出さないためです）。下部のバーには「OBSでミュート中（OBSを見張れていません）」と出ます
- 入力の名前はこのブラウザに覚えます。名前を変えて保存すると、文字起こしを始め直します
