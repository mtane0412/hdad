# サイドスーパー（素材の種類「サイドスーパー」）

配信画面の隅（左上・右上）に、いま何をしているかを**2行のテロップ**で出し続けます。テレビ番組のサイドスーパーと同じく上下の役割が分かれていて、上の段は**コーナー名**（14文字まで。いまの配信が何の時間かを表す名前で、話題が少し動いても変わりません）、下の段は**いまの話題**（20文字まで）です。文言は配信中の文字起こし・視聴者の発言・[配信画面から読み取った文字](./screen.md)（直近に現れたぶん）・配信のカテゴリとタイトルを材料に、Worker が cron（5分おき）で作って貯め、この素材が読み出して映します。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

配信画面に出すには、[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「サイドスーパー」を追加します。

| パラメータ | 内容 |
| --- | --- |
| `position` | `left`（既定。左上）か `right`（右上）。素材の枠のどちら側に寄せるかが変わる |

- **作るのは cron（5分おき）**です。素材は30秒ごとに読みに行くだけで、LLMを呼びません（配信中ずっと開いていても Workers AI の無料枠を消費しません）
- **材料は直近のぶんだけ**で、あらすじ（[これまでのあらすじ](./bot.md#これまでのあらすじ)）と違って前回の文言に積み上げません。話題が移ったときに古い文言を引きずらないためです
- [文字起こし](./transcript.md)の中継をOBSに置いていると、いまの話題をより正しく言い当てられます。置いていない場合でも、[配信画面の取り込み](./screen.md)を使っていれば画面から読み取った文字が材料になります（どちらも使っていない場合の材料は、視聴者の発言とカテゴリ・タイトルだけです）
- **前回作ったあとに新しい材料が1件も無ければ作り直しません**。喋りも発言もない時間帯に無駄にLLMを呼ばないためです。[配信画面の取り込み](./screen.md)を使っていると、黙って資料を切り替えただけでも作り直します
- 文言が作られるのを待たずに見栄えを確かめるには、`/overlay/` のプレビューを開きます（サンプルの文言を順に流します。上限いっぱいの文字数のサンプルも入っているので、テロップがいちばん幅を取る場合も見られます）
- LLMが失敗したとき（無料枠を使い切った日など）や、**ちょうど2行でない・見出しが14文字を超える・本文が20文字を超える文言が返ってきたとき**は、行を補ったり切り詰めたりせず捨てて、前の文言をそのまま出し続けます（枠からはみ出させず、見出しの無い片肺のテロップも出さないためです）。失敗は収集の記録（`/api/admin/stats/failures` の `side-super-failed`）に残ります
- **配信していないあいだは何も映しません**（透過の枠だけが残ります）。配信の前後にOBSのソースを開いたままにして構いません
- 起動できない失敗（キーの誤りなど）は素材の枠にエラーを出します。いっぽう2回目以降の読み出しの失敗は出さず、前の文言を映したままにします（一時的な通信の失敗で配信画面を汚さないためです）
- 文言は**素材の枠**の、`position` で指定した側の上隅に出ます。枠は追加したときオーバーレイいっぱいなので、そのままで配信画面の隅に出ます
