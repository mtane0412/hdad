# チャットで推理

視聴者がチャンネルポイントで「質問」を送って答え（人物・場所・出来事・もの）を絞り込み、「解答」で当てるゲームです。ページは `/chat-deduction/` です。

> いまは段階2（ゲームの開始と終了・報酬の切り替え・質問への AI の回答）までです。解答の判定（#377）、配信画面に映す素材（#378）はこれから追加します。いまは答えを配信画面にもチャットにも出さないので、`/rewards/` の待ち行列ではなく D1 の `chat_deduction_questions` で確かめてください。

## はじめに: 報酬を作る

`/chat-deduction/` の「報酬を作る」を押すと、HDAD が次の2つのチャンネルポイント報酬を作ります。どちらも交換するときにメッセージの入力を求め、ゲームのあいだだけ交換できます。

| 報酬 | 必要ポイント（作ったとき） | 視聴者が書くもの |
| --- | --- | --- |
| チャットで推理: 質問 | 100 | 「はい」か「いいえ」で答えられる質問（例: 生き物ですか？） |
| チャットで推理: 解答 | 300 | 答えだと思うもの（例: 富士山） |

必要ポイントや説明は[チャンネルポイント報酬](./rewards.md)のページで変えられます。この2つの報酬はゲームの開始と終了で使うので、`/rewards/` からは削除できません。

Twitch のダッシュボードで作った報酬は使えません（Twitch は、HDAD が作った報酬でないと交換できるかどうかを切り替えさせないためです）。

## ゲームを始める・終える

1. 「問題」の欄で問題を選びます。欄には区分と正解が出ます（例: 【場所】富士山）。**このページは配信に映さないでください**
2. 「ゲームを始める」を押すと、2つの報酬が交換できるようになります
3. 終えるときは「終える」を押して確かめます。2つの報酬は交換できなくなります

報酬の切り替えに失敗したときは、ゲームを始めません（終えるときは、ゲームを開催中のまま残します）。表示された理由を確かめて、もう一度押してください。

## 質問への答え

ゲームのあいだに「質問」の報酬が交換されると、AI が問題の事実メモだけを材料にして「はい」「いいえ」「分からない」のどれかと、理由の1文（60文字まで）で答えます。事実メモに書いていないことには「分からない」と答えます。答えは D1 の `chat_deduction_questions` に残ります。

次の質問は受け付けず、**交換を取り消して視聴者にポイントを返します**。AI は呼びません。

| 理由 | 内容 |
| --- | --- |
| ゲームをしていない | ゲームを始める前・終えたあとに届いた交換 |
| 質問の数の上限 | 1問あたり30件まで。受け付けなかった質問・答えられなかった質問は数えません |
| 同じ人の待ち時間 | 同じ人は、前の質問から60秒のあいだ質問できません |

AI が答えられなかったとき（無料枠切れ・返事の形が違う・返事に正解の名前が入っていた）も、交換を取り消してポイントを返し、[配信の記録](./stats.md)の収集の失敗に `chat-deduction-answer-failed` を残します。答えた質問の交換は完了にします。交換を完了・取り消しにできなかったときは `chat-deduction-redemption-failed` を残し、交換は Twitch の待ち行列に未処理のまま残ります（Twitch の画面で処理してください）。

答えを作る AI のモデルは [LLM の設定](./llm.md)の「チャットで推理の質問への答え」で選べます。

## 問題を足す

問題は `src/chat-deduction/problems.json` に書きます。1問は次の項目を持ちます。

| 項目 | 内容 |
| --- | --- |
| `id` | 英小文字・数字・ハイフンだけの識別子（例: `mount-fuji`） |
| `category` | 区分。`person`（人物）・`place`（場所）・`event`（出来事）・`thing`（もの） |
| `answer` | 画面に出す正解の表記 |
| `aliases` | 正解として受け付ける表記の一覧。これと完全に一致した解答だけを正解にします。読み（ひらがな・カタカナ）や略称も書いておきます |
| `facts` | 質問に答える AI の材料。ここに書いていないことは「分からない」と答えさせます |

形の誤り（区分の打ち間違い・別名や事実メモが空・同じ `id`）は `npm test` で見つかります。

## 導入

この機能を入れたあとは、マイグレーション `0039_chat_deduction_games.sql` と `0040_chat_deduction_questions.sql` を適用してください（適用方法は[配信の記録](./stats.md)を参照）。`0039` を適用していないと、ゲームを始められず、`/chat-deduction/` の読み込みも失敗します。`0040` を適用していないと、質問を受け付けられず、Twitch が同じ交換を送り直し続けます。

報酬を作るにも、質問の交換を完了・取り消しにするにも、配信者のトークンに `channel:manage:redemptions` が要ります。足りないと言われたら、ログインし直してください。
