# チャットで推理

視聴者がチャンネルポイントで「質問」を送って答え（人物・場所・出来事・もの）を絞り込み、「解答」で当てるゲームです。ページは `/chat-deduction/` です。

質問への答えと解答の正誤は、[合成オーバーレイ](./overlay.md)の素材「チャットで推理」で配信画面にカードとして映します（[配信画面に映す](#配信画面に映す)）。チャットには書き込みません。

## はじめに: 報酬を作る

`/chat-deduction/` の「報酬を作る」を押すと、HDAD が次の2つのチャンネルポイント報酬を作ります。どちらも交換するときにメッセージの入力を求め、ゲームのあいだだけ交換できます。

| 報酬 | 必要ポイント（作ったとき） | 視聴者が書くもの |
| --- | --- | --- |
| チャットで推理: 質問 | 100 | 「はい」か「いいえ」で答えられる質問（例: 生き物ですか？） |
| チャットで推理: 解答 | 300 | 答えだと思うもの（例: 富士山） |

必要ポイントや説明は[チャンネルポイント報酬](./rewards.md)のページで変えられます。この2つの報酬はゲームの開始と終了で使うので、`/rewards/` からは削除できません。

Twitch のダッシュボードで作った報酬は使えません（Twitch は、HDAD が作った報酬でないと交換できるかどうかを切り替えさせないためです）。

## ゲームを始める・終える

1. 「問題」の欄で問題を選びます。欄には区分と正解が出ます（例: 【場所】富士山）。**このページは配信に映さないでください**
2. 「ゲームを始める」を押すと、2つの報酬が交換できるようになります
3. 終えるときは「終える」を押して確かめます。2つの報酬は交換できなくなります

報酬の切り替えに失敗したときは、ゲームを始めません（終えるときは、ゲームを開催中のまま残します）。表示された理由を確かめて、もう一度押してください。

## 質問への答え

ゲームのあいだに「質問」の報酬が交換されると、AI が問題の事実メモだけを材料にして「はい」「いいえ」「分からない」のどれかと、理由の1文（60文字まで）で答えます。事実メモに書いていないことには「分からない」と答えます。答えは D1 の `chat_deduction_questions` に残ります。

次の質問は受け付けず、**交換を取り消して視聴者にポイントを返します**。AI は呼びません。

| 理由 | 内容 |
| --- | --- |
| ゲームをしていない | ゲームを始める前・終えたあとに届いた交換 |
| 質問の数の上限 | 1問あたり30件まで。受け付けなかった質問・答えられなかった質問は数えません |
| 同じ人の待ち時間 | 同じ人は、前の質問から60秒のあいだ質問できません |

AI が答えられなかったとき（無料枠切れ・返事の形が違う・返事に正解の名前が入っていた）も、交換を取り消してポイントを返し、[配信の記録](./stats.md)の収集の失敗に `chat-deduction-answer-failed` を残します。答えた質問の交換は完了にします。交換を完了・取り消しにできなかったときは `chat-deduction-redemption-failed` を残し、交換は Twitch の待ち行列に未処理のまま残ります（Twitch の画面で処理してください）。

答えを作る AI のモデルは [LLM の設定](./llm.md)の「チャットで推理の質問への答え」で選べます。

## 解答の判定

ゲームのあいだに「解答」の報酬が交換されると、問題の `aliases`（別名の一覧）と照らして正誤を決めます。AI は使いません。照らす前に、解答と別名の両方の表記を次のように揃えます。

- 前後と途中の空白、中黒（・）や句読点・感嘆符などの記号を除く
- 全角の英数字を半角に、半角のカタカナを全角にする。英字は小文字にする
- カタカナをひらがなに直す（長音符「ー」は残す）

揃えたあとで別名のどれかと完全に一致したときだけ正解にします。別名を含むだけの解答（例: 「富士山の頂上」）は不正解です。

- **最初の正解者が出たら、ゲームを終えて2つの報酬を交換できなくします**。正解者の交換は完了にします
- 不正解の解答も D1 の `chat_deduction_guesses` に残し、交換は完了にします（ポイントは返しません）
- ゲームを始める前・終えたあと（正解者が出たあとを含む）に届いた解答は、**交換を取り消してポイントを返します**

正解者が出てゲームを終えても、`/chat-deduction/` は開いたままでは変わりません。再読み込みすると終えたゲームとして表示されます。報酬を交換できなくできなかったときは、[配信の記録](./stats.md)の収集の失敗に `chat-deduction-rewards-failed` を残します（ゲームは終えたままです。`/rewards/` で2つの報酬を確かめてください）。

## 配信画面に映す

`/overlay/` で素材「チャットで推理」をオーバーレイに置きます（追加したときの大きさはオーバーレイいっぱいで、カードの板を画面の中央に大きく出します。以前に置いた素材は大きさが変わらないので、表示領域でオーバーレイいっぱいに広げてください）。映すのは最後に始めたゲームで、次のゲームを始めるまで終えたゲームを映し続けます。一度もゲームを始めていなければ何も映しません。

- 見出しに区分（例: お題: 場所）を出します。正解はゲームのあいだは配信画面に出ません（合成ページにも届きません）
- 答えた質問と、正誤を決めた解答を、新しいものを上にして6枚まで並べます
  - 質問のカードは「はい」（緑）・「いいえ」（赤）・「分からない」（灰）の印と、AI の1文・送った人の名前を出します
  - 解答のカードは「正解」（金色の枠）・「不正解」（取り消し線）の印と、送った人の名前を出します
  - ポイントを返した質問と解答（ゲームの外・待ち時間の内・上限・AI が答えられなかった）は映しません
- ゲームのあいだは下に参加のしかたを出し、終えたら「正解は○○でした」を出します（正解者が出て終えたときは「○○さんが正解！」も添えます）

カードはゲームを始めた・終えた・質問に答えた・解答の正誤を決めたたびに配信画面へ届きます。開始・終了のときに届けられなかったときは、ゲームを始めた・終えたことはそのままにして、ページに理由を出します。質問と解答のときに届けられなかったときは、交換の処理は続け、[配信の記録](./stats.md)の収集の失敗に `chat-deduction-push-failed` を残します。どちらの場合も、合成ページはつなぎ直したときと5分おきに読み直して追いつきます。

## 問題を足す

問題は `src/chat-deduction/problems.json` に書きます。1問は次の項目を持ちます。

| 項目 | 内容 |
| --- | --- |
| `id` | 英小文字・数字・ハイフンだけの識別子（例: `mount-fuji`） |
| `category` | 区分。`person`（人物）・`place`（場所）・`event`（出来事）・`thing`（もの） |
| `answer` | 画面に出す正解の表記 |
| `aliases` | 正解として受け付ける表記の一覧。表記を揃えたうえで完全に一致した解答だけを正解にします（[解答の判定](#解答の判定)）。カタカナとひらがな・全角と半角・中黒の有無は揃えるので書き分けなくてよく、別の読みや略称（例: 漱石）を書いておきます |
| `facts` | 質問に答える AI の材料。ここに書いていないことは「分からない」と答えさせます |

形の誤り（区分の打ち間違い・別名や事実メモが空・同じ `id`）は `npm test` で見つかります。

## 導入

この機能を入れたあとは、マイグレーション `0039_chat_deduction_games.sql`・`0040_chat_deduction_questions.sql`・`0041_chat_deduction_guesses.sql` を適用してください（適用方法は[配信の記録](./stats.md)を参照）。`0039` を適用していないと、ゲームを始められず、`/chat-deduction/` の読み込みも失敗します。`0040` を適用していないと質問を、`0041` を適用していないと解答を受け付けられず、Twitch が同じ交換を送り直し続けます。

報酬を作るにも、質問の交換を完了・取り消しにするにも、配信者のトークンに `channel:manage:redemptions` が要ります。足りないと言われたら、ログインし直してください。
