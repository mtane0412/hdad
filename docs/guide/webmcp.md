# エージェントから操作する（WebMCP）

HDAD のアプリのページ（ダッシュボードなど）は、[WebMCP](https://webmachinelearning.github.io/webmcp/) の仕組みでページの操作を「ツール」としてブラウザに登録します。WebMCP に対応したブラウザのエージェントに「BGMを次の曲にして」「ポモドーロを始めて」と頼むと、エージェントがこのツールを呼んで操作します。

## 使いはじめ方

1. Chrome（149以降）で `chrome://flags/#enable-webmcp-testing` を有効にし、Chrome を再起動します
2. HDAD にログインし、アプリのページをどれか1つ開いておきます（ログインしているあいだだけツールが登録されます）
3. WebMCP に対応したエージェントから操作します。登録されたツールを確かめて試しに呼ぶには、Chrome 拡張の [Model Context Tool Inspector](https://github.com/GoogleChromeLabs/webmcp-extension/) を使います

ツールの登録を断られたときは、画面下部のバーの右端に理由が出ます。WebMCP に対応していないブラウザでは何も出ません。

## ツールの一覧

| ツール | できること |
| --- | --- |
| `list_pages` | ページの一覧と、いま開いているページを返す |
| `open_page` | ページへ移る。保存していない変更があるページからは、確認が出て配信者の選択を待つ |
| `get_bgm` | 流している曲・音量・繰り返し・シャッフルと、登録した曲名の一覧を返す |
| `skip_bgm` | 次の曲・前の曲へ切り替える（止めているときに次の曲を選ぶと再生を始める） |
| `stop_bgm` | BGMを止める |
| `set_bgm_volume` | BGMの音量を 0〜100 で変える |
| `get_pomodoro` | ポモドーロのタイマーの状態（作業か休憩か・何本目か・残り時間）を返す |
| `control_pomodoro` | ポモドーロを開始・一時停止・再開・停止する |
| `get_speech_mute` | チャットの読み上げをミュートしているかを返す |
| `set_speech_mute` | チャットの読み上げをミュートする・解除する |
| `get_transcription` | 文字起こしがオンかどうかと、認識の様子を返す |
| `set_transcription` | 文字起こしをオン・オフにする |
| `send_chat_message` | 配信者本人として、またはチャットボットとしてチャットへ1通送る |
| `clear_focus` | 注目コメントで取り上げている発言を外す |
| `play_town_tour_demo` | 市町村紹介を試しに流す（レイド元のログイン名と人数を渡すと共通点も作る） |
| `play_twister_demo` | ツイスターの対戦を試しに流す |
| `list_streams` | 記録している配信の一覧（タイトル・平均と最大の視聴者数など）を返す |
| `get_stream` | 配信1回ぶんの章・タイトルの候補・あらすじ・作業時間の合計を返す |
| `search_viewers` | 視聴者の記録（メモ・人物像を含む）をログイン名で探す |
| `save_viewer_note` | 視聴者のメモを保存する（まるごと置き換える） |
| `get_llm_usage` | LLM を呼んだ回数・トークン数・実費を、今日と直近7日でまとめて返す |
| `get_llm_credits` | OpenRouter の残高を返す |

チャットへの送信・注目コメント・試し再生は配信を見ている人の目に入り、取り消せません。これらのツールには「結果が重い操作」の印（`consequentialHint`）を付けていますが、印は目安で、実行の前に確認を求めるかどうかはエージェント次第です（HDAD の側では確認を出しません）。エージェントに頼むときは、送る文や流すものを確かめてから実行するよう頼んでください。

## 注意

- ツールの操作は、画面のボタンを押したのと同じように下部バーやページにも映ります。ただし読み上げのミュートは下部バーのボタンの見た目が、注目コメントの取り上げをやめたときは開いているコメントビューアーの印が、視聴者のメモを保存したときは開いている視聴者のページの表示が、ページを開き直すまで変わりません。視聴者のページを開いたままメモを保存し直すと、ツールで保存したメモを上書きします
- 文字起こしをオンにしたとき、マイクの許可を求められることがあります。その場合は下部バーの文字起こしのボタンを押してください（ブラウザは、配信者がボタンを押したときでないと許可を求められないことがあります）
- 発言を選んで注目コメントに取り上げる操作は、まだツールにしていません
- 設定の変更は、まだツールにしていません（[#282](https://github.com/mtane0412/hdad/issues/282)）
