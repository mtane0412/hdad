# チャットの読み上げ（`speech/reader/`）

Twitchのチャットを、配信に使うPCで動かした [VOICEVOX](https://voicevox.hiroshiba.jp/) に読み上げさせるページです。映すものは持たず、音だけを出します。チャットはチャットボックスと同じ匿名IRCで受け取るのでTwitchのトークンは要りませんが、**読み上げの設定を Worker から読むのでオーバーレイ用キーが要ります**。読み上げに Workers AI を使わないのは、発言のたびに無料枠を消費させないためです。

配信PCで VOICEVOX を動かさずに済ませたいときは、合成先に**さくらのAI Engine**（従量課金）を選べます（下の「さくらのAI Engine で合成する」）。

```text
https://hdad.<サブドメイン>.workers.dev/speech/reader/?key=<オーバーレイ用キー>
```

**設定はURLではなく、アプリの「コネクター」のページ（`/connectors/`）の「VOICEVOX」で保存します。** 読み上げのページが30秒おきに読み直すので、配信中に変えても**OBSの再読み込みなしで次に読む1件から効きます**（ホストとポートを除く）。

| 設定 | 内容 |
| --- | --- |
| 合成先 | 「このPCの VOICEVOX（無料）」（既定）か「さくらのAI Engine（従量課金）」 |
| ホスト | VOICEVOX が動いているホスト。`localhost`（既定）か `127.0.0.1` のみ |
| ポート番号 | VOICEVOX ENGINE のポート番号（既定 `50021`） |
| 話者ID | 既定 `3` = ずんだもんのノーマル。VOICEVOX のキャラクターとスタイルの組み合わせ |
| 読み上げ速度 | `0.5`〜`2`（既定 `1`） |
| 音量 | `0`〜`1`（既定 `1`） |
| 読み上げる長さの上限 | 文字数。`1`〜`200`（既定 `60`） |
| 発言者の名前も読む | 有効にすると本文の前に表示名を読む（既定は無効） |
| 読み上げない人 | ログイン名をカンマ区切り。接続しているbotは、ボタン1つで追加できます |

- **合成先・ホスト・ポートだけは、変えたらOBSでブラウザソースを再読み込みしてください**。つなぎ先が変わるのでつなぎ直しが要ります（画面にもその案内が出ます）
- 値の範囲の確認は Worker が行い、外れていれば保存せずに理由を返します
- **VOICEVOX を起動していないと動きません**。つながらないまま開くと、考えられる原因（起動していない・ポート番号が違う・CORSで拒まれている）と直し方を画面に出して止まります
- **VOICEVOX 側でこのサイトのオリジンを許可する必要があります**。ENGINE は既定（`--cors_policy_mode localapps`）では localhost・`app://`・ブラウザ拡張からの通信しか受け付けず、`https://hdad.<サブドメイン>.workers.dev` からの読み出しを拒みます。設定は次の手順です（この文書の「OBSでの設定」の手順4も参照）
  1. 配信に使うPCのブラウザで `http://127.0.0.1:50021/setting` を開く
  2. CORSの許可するオリジンに `https://hdad.<サブドメイン>.workers.dev` を追加して保存する
  3. **VOICEVOX を再起動する**（設定の適用に再起動が必要です）

  コマンドラインから ENGINE を起動している場合は `--allow_origin https://hdad.<サブドメイン>.workers.dev` でも同じです
- 読まないもの: コマンド（`!` で始まる発言）・エモートやCheermoteだけの発言・「読み上げない人」に挙げた人の発言
- 読み替えるもの: URLは「URL」と読み、同じ文字が3つ以上続くところ（`wwwwww` など）は2つに縮めます。聞いても分からないものを読ませないためです
- **1件ずつ順に読みます**。チャットが速くて待ちが10件を超えたときは、古いほうから捨てて新しい発言を読みます（数分前の発言を読み続けても配信の役に立たないためです）
- 1件の読み上げに失敗しても止まりません（その1件を飛ばして次を読みます）。原因はブラウザソースのコンソールに残ります

## その場で黙らせる（ミュート）

**どのページを見ていても、画面の下端のバー（配信中の操作）の吹き出しのボタンで、読み上げをミュート・解除できます。** 押すとすぐに効き、読んでいる途中の1件もその場で止まります（OBSの再読み込みは要りません）。

- **ミュート中に届いたコメントは、解除したあとも読みません**（溜まった分を一気に読み上げないためです）。待っていた発言もミュートした時点で捨てます
- ミュートは保存されるので、OBSでブラウザソースを読み込み直してもミュートのまま始まります
- ボタンはアイコンだけで、名前はマウスを重ねると出ます。ミュート中はボタンが押された状態になります。切り替えられなかったときは、ボタンの横に理由が出ます
- バーは開いたときの状態を映します。別の窓でも切り替えたときは、ページを読み込み直してください

## さくらのAI Engine で合成する

さくらのAI Engine の音声合成（VOICEVOX）で読み上げます。配信PCで VOICEVOX を起動したり、CORS を許可したりする必要がなくなります。

- **料金**: 合成したモーラ数（音の数）の合計に対して 3円/1万モーラの従量課金です。1件ごとの切り上げはなく、1配信で500件読んでも数円です。無料枠は月50回までで、チャットの読み上げにはすぐ足りなくなります。読み方の問い合わせと失敗した呼び出しは数えられません
- **Cloudflare 側の消費**: 発言1件につき、Worker のリクエスト1回と KV の読み出し2回です

手順:

1. さくらのクラウドのコントロールパネルで AI Engine を使えるようにし、APIキーを発行する
2. 使うキャラクターの**利用規約にコントロールパネルで同意する**（同意していないと `This model is not available.` で断られます）
3. Worker のシークレットに APIキーを設定する

   ```bash
   npx wrangler secret put SAKURA_AI_API_KEY
   # ローカル（npm run dev）では .dev.vars に SAKURA_AI_API_KEY=... と書く
   ```

4. コネクターのページの「VOICEVOX」で、合成先を「さくらのAI Engine（従量課金）」にして話者IDを入れ、保存する
5. OBSでブラウザソースを再読み込みする

- **話者ID**: VOICEVOX と同じ番号です（ずんだもん（ノーマル）は `3`）。利用規約に同意したキャラクターの番号だけが使えます（利用申請には審査があるので、同意した直後は `This speaker is not available.` で断られることがあります）
- 起動のときに、保存した話者が使えるかを（課金されない呼び出しで）確かめます。APIキーが無い・規約に同意していない話者を選んでいる、といった失敗は画面に出して止まります
- 合成先がさくらになっていなければ、Worker はさくらを呼びません（オーバーレイ用キーだけでは、さくらを選んでいない配信者に料金は発生しません）
- 配信で使うときは、キャラクターごとの利用規約に従ってクレジット（「VOICEVOX:ずんだもん」など）を表記してください。ローカルの VOICEVOX を使うときと同じです

## OBSでの設定

1. ソースの追加 > ブラウザ
2. URLに、コネクターのページの「OBS用のURL」で **VOICEVOX** に印を付けてコピーした[裏方](./backstage.md)のURLを貼る。アプリは読み上げだけのURL（`speech/reader/`）を出さなくなりました（すでに貼ってあるものはそのまま動きます）
3. ソースのプロパティで**「OBSで音声を制御する」を有効にする**（配信に音を載せるため）
4. 配信に使うPCで VOICEVOX を起動し、`http://127.0.0.1:50021/setting` でこのサイトのオリジンをCORSの許可に追加して、VOICEVOX を再起動しておく（上の箇条書きを参照）
