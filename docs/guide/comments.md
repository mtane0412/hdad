# コメントビューアー（`/comments/`）

配信中に横に開いておくための画面です。チャットの発言と、サブスク・ギフト・レイド・ビッツ・チャンネルポイントの引き換え・フォローといった出来事を、届いた順に1本の流れで並べます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

- 発言は、**アイコン・バッジ・名前（本人が決めた色）・本文**で並びます。エモートは画像で出ます。ビッツを贈った発言には贈った数が、返信には返信先が添えられます
- 出来事は、色の付いた帯の**1行の文**で並びます（「〇〇 さんがサブスクしました（Tier 1）」「〇〇 さんが「質問する」を引き換えました（500pt）」など）。継続サブスクやアナウンスの本文、引き換えで視聴者が書いた文も一緒に出ます
- **モデレーターに消された発言は、並びから消えずに薄くなり「削除済み」と出ます**（発言の削除・BAN・タイムアウト・チャットの全消去）
- 画面を開き直しても、**直近の200件**から並べ直します
- いちばん下を見ているあいだは新しい1件に合わせて送られます。上へ遡って読んでいるあいだは動かず、「最新へ」を押すと戻ります
- 接続が切れたときは画面に出したうえで、自動でつなぎ直します
- 発言の行の右端にある引用符のボタンを押すと、その発言を[注目コメント](./focus.md)として配信画面に大きく映せます。取り上げている発言には「注目中」と出て、同じボタンをもう一度押すとやめます（モデレーターに消された発言は取り上げられません）
- 発言の行の右端のボタンから、**発言の削除・その人の10分のタイムアウト・BAN**ができます。行うのは[チャットボット](./bot.md)のbotアカウントなので、botを接続し、このチャンネルのモデレーターにしておく必要があります（そうでなければ理由が画面に出ます）。BANだけは押したあとに確認が出ます。処分した発言は、Twitch から消えた知らせが届いた時点で「削除済み」になります

## はじめて使うとき

この画面のために、Twitch の通知（チャットのお知らせ・発言の削除など）を新しく受け取ります。受け取りの登録は配信者がログインしたときに行われるので、**更新したあとに一度ログインし直してください**（Twitch への許可を取り直す必要はありません）。
