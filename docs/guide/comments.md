# コメントビューアー（`/comments/`）

配信中に横に開いておくための画面です。チャットの発言と、サブスク・ギフト・レイド・ビッツ・チャンネルポイントの引き換え・フォローといった出来事を、届いた順に1本の流れで並べます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

- 発言は、**アイコン・バッジ・名前（本人が決めた色）・本文**で並びます。エモートは画像で出ます。ビッツを贈った発言には贈った数が、返信には返信先が添えられます
- 出来事は、色の付いた帯の**1行の文**で並びます（「〇〇 さんがサブスクしました（Tier 1）」「〇〇 さんが「質問する」を引き換えました（500pt）」など）。継続サブスクやアナウンスの本文、引き換えで視聴者が書いた文も一緒に出ます
- **モデレーターに消された発言は、並びから消えずに薄くなり「削除済み」と出ます**（発言の削除・BAN・タイムアウト・チャットの全消去）
- 画面を開き直しても、**直近の400件**（既読・未読の付け替えを含む）から並べ直します
- いちばん下を見ているあいだは新しい1件に合わせて送られます。上へ遡って読んでいるあいだは動かず、「最新へ」を押すと戻ります
- 接続が切れたときは画面に出したうえで、自動でつなぎ直します
- 発言の行の右端にある引用符のボタンを押すと、その発言を[注目コメント](./focus.md)として配信画面に大きく映せます。取り上げている発言には「注目中」と出て、同じボタンをもう一度押すとやめます（モデレーターに消された発言は取り上げられません）
- 発言の行の右端のボタンから、**発言の削除・その人の10分のタイムアウト・BAN**ができます。行うのは[チャットボット](./bot.md)のbotアカウントなので、botを接続し、このチャンネルのモデレーターにしておく必要があります（そうでなければ理由が画面に出ます）。BANだけは押したあとに確認が出ます。処分した発言は、Twitch から消えた知らせが届いた時点で「削除済み」になります
- 視聴者の発言の行の右端にある**チェックのボタンで、その発言を既読にできます**（反応したら押す、という使い方です）。既読にするとボタンが色付きになり、もう一度押すと未読に戻ります。既読の状態は、開き直しても、ほかのウィンドウで開いても同じです。配信者自身の発言と、モデレーターに消された発言にはボタンが出ません
- **届いてから3分たっても未読の発言は、黄色い帯と「しばらく未読」の印で目立ちます**。流れの上の「しばらく未読の発言を目立たせる」のチェックを外すと目立たせなくなります（最初はオンです）
- 流れの上の「**配信者の発話から自動で既読にする（Jev）**」を入れると、[文字起こし](./transcript.md)で確定した発話を受け取るたびに、その発話が直近10分の未読の発言のどれへの反応かを判定し、反応した発言を自動で既読にします。自動で既読にした発言には「発話から既読」と出ます。間違っていたら、チェックのボタンを押せば未読に戻せます（手で未読に戻した発言は、自動では既読にし直しません）。最初はオフです
  - 判定には TypeSafe の Jev を [OpenRouter](./llm.md) 経由で使うので、シークレット `OPENROUTER_API_KEY` と OpenRouter の残高が要ります。1回はおよそ $0.00004 で、1時間に600文話しても $0.03 ほどです。使った回数は `/llm/` の「判定に使う箇所」に出ます
  - 反応していない発言を既読にしてしまうほうが困るので、確信が高いものだけを既読にします。そのぶん、名前を音声認識が聞き取れなかった場合などは見逃します
  - 判定に失敗しても文字起こしは止まりません。失敗は[配信の記録](./stats.md)の失敗の一覧に `comment-reaction-failed` として出ます
- 流れの下の入力欄から、**配信者本人としてチャットを送れます**（Enter か「送信」で送ります。日本語入力の変換を確定する Enter では送りません）。送った発言は、Twitch から届いた時点で流れに並びます

## はじめて使うとき

既読・未読を記録するテーブルを足したので、更新したあとにデータベースのマイグレーション（[配信の記録](./stats.md)の手順）を適用してください（`npm run deploy` は適用も行います）。

「配信者の発話から自動で既読にする」を足す前の版で「しばらく未読の発言を目立たせる」を切り替えたことがあると、保存された設定が古い形のまま残り、画面に「保存されているコメントビューアーの設定が古い形か、壊れています」と出て設定を切り替えられなくなります（黙って読み替えず、止めて知らせる作りです）。そのときは保存された設定を消してから、画面を開き直して設定し直してください。

```bash
npx wrangler kv key delete comment-settings --binding STORE --remote
```

この画面のために、Twitch の通知（チャットのお知らせ・発言の削除など）を新しく受け取り、配信者としてチャットを送る許可（`user:write:chat`）を新しく求めます。**更新したあとに一度ログアウトしてログインし直し、Twitch の許可の画面で許可してください。** 許可する前にチャットを送ろうとすると、ログインし直すよう画面に出ます（botで代わりに送ることはしません）。
