# VRM

自分で用意した VRM のキャラクターを、配信中ずっと画面に立たせておくマスコットです。ふだんは呼吸・瞬き・視線のゆらぎだけで静かに立ち、トリガーが来るとその場で手を振ってお辞儀をします。フォロー・レイド・チャンネルポイントなど、どの出来事でも反応させられます。

## 使い方

1. [素材のページ](./alerts.md)（`/media/`）で、VRM のファイル（`.vrm`。1つ50MBまで）をアップロードします。VRM はリポジトリに含めていません。使ってよいモデル（自分で作ったもの・配布元の利用条件で配信に使えるもの）を用意してください
2. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「VRM」を置きます。大きさは縦長の480×720pxから始まります。キャラクターの背の高さは箱の高さの8割ほどになり、足もとは箱の下端の近くに立ちます。大きさと置き場所は箱で決めてください
3. [トリガーの管理画面](./alerts.md)（`/triggers/`）の「VRM」のカードで、出す VRM を選んで「VRM を保存」を押します。マスコットもどのトリガーも試し再生も、ここで選んだ1つを出します。選び直した VRM は、合成ページが配送先につなぎ直したとき（OBS でソースを再読み込みしたときなど）か、次のトリガーが届いたときに替わります
4. トリガーの管理画面で、反応させたい出来事の行を開き、「VRMを出す」に印を付けて保存します。どの出来事の行にも出ます
5. 「VRM」のカードにある「VRMを試しに流す」で、トリガーを待たずに1回反応させられます。保存した VRM が出るので、未保存の変更があるあいだと、VRM を選んでいないあいだは押せません

オーバーレイの構成画面のプレビューでは、保存してある VRM を立たせ、決まった反応をくり返し流します（VRM を選んでいなければ、素材の箱に理由を出します）。

## 流れ

ふだんは待機の動きを続けます。

- 呼吸に合わせて胸がわずかに動き、体が少し左右に揺れます
- 3〜4秒に1回ほど瞬きします
- 首と頭がゆっくり左右・上下にゆらぎます

トリガーが届くと、その場で反応します（およそ4〜5秒）。

1. 片手を上げて、2〜4回手を振ります（にっこりします）
2. お辞儀をして、待機の動きに戻ります

振る手・振る回数・お辞儀の深さは Worker が引いた種（乱数）だけから決まり、毎回変わります。続けて届いたときは、届いた順に1件ずつ反応します。髪や服の揺れはありません。

## 失敗したとき

- VRM を選んでいないときは、マスコットは立たず、素材の箱に理由を出します
- VRM を選んでいない・オーバーレイ用キーが未発行のときは、トリガーでも反応させずにダッシュボードの失敗の記録に `vrm-push-failed` として残ります（試し再生では画面に理由を出します）
- 合成ページで VRM を読み込めなかった（VRM でないファイルなど）ときは、その1回は反応させずに素材の箱に理由を出します
- 「VRM」のカードで選ばれている VRM は、素材のページで削除できません。先にカードで選び直してください

## 重さを測る

読み込みにかかった時間は、ブラウザの User Timing に `vrm-load` という名前で残ります。OBS のブラウザソースの開発者ツール（Performance）で読めます。
