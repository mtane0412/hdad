# VRM

自分で用意した VRM のキャラクターが、トリガーで画面の端から歩いて出てきて、手を振り、お辞儀をして帰る演出です。フォロー・レイド・チャンネルポイントなど、どの出来事でも流せます。

## 使い方

1. [素材のページ](./alerts.md)（`/media/`）で、VRM のファイル（`.vrm`。1つ50MBまで）をアップロードします。VRM はリポジトリに含めていません。使ってよいモデル（自分で作ったもの・配布元の利用条件で配信に使えるもの）を用意してください
2. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「VRM」を置きます。大きさはオーバーレイいっぱい（1920×1080）から始まります。キャラクターの背の高さは箱の高さの8割ほどになり、足もとは箱の下端の近くに立ちます。小さく出したいときや画面の片側に出したいときは、箱を小さくして置き場所を動かしてください
3. [トリガーの管理画面](./alerts.md)（`/triggers/`）の「VRM」のカードで、出す VRM を選んで「VRM を保存」を押します。どのトリガーも試し再生も、ここで選んだ1つを出します
4. トリガーの管理画面で、流したい出来事の行を開き、「VRMを出す」に印を付けて保存します。どの出来事の行にも出ます
5. 「VRM」のカードにある「VRMを試しに流す」で、トリガーを待たずに1回流せます。保存した VRM が出るので、未保存の変更があるあいだと、VRM を選んでいないあいだは押せません

オーバーレイの構成画面のプレビューでは、保存してある VRM で決まった動き方をくり返し流します（VRM を選んでいなければ、素材の箱に理由を出します）。

## 流れ

1回はおよそ8〜9秒です。

1. 画面の左か右の外から、進む向きを向いて歩いて出てきて、立つ位置で正面を向きます
2. 片手を上げて、2〜4回手を振ります（にっこりします）
3. お辞儀をします
4. 左か右を向いて、画面の外へ歩いて帰ります

出てくる側・帰る側・振る手・振る回数・お辞儀の深さは Worker が引いた種（乱数）だけから決まり、毎回変わります。続けて届いたときは、届いた順に1件ずつ流します。髪や服の揺れはありません。

## 失敗したとき

- VRM を選んでいない・オーバーレイ用キーが未発行のときは、流さずにダッシュボードの失敗の記録に `vrm-push-failed` として残ります（試し再生では画面に理由を出します）
- 合成ページで VRM を読み込めなかった（VRM でないファイルなど）ときは、その1回は流さずに素材の箱に理由を出します
- 「VRM」のカードで選ばれている VRM は、素材のページで削除できません。先にカードで選び直してください

## 重さを測る

読み込みにかかった時間は、ブラウザの User Timing に `vrm-load` という名前で残ります。OBS のブラウザソースの開発者ツール（Performance）で読めます。
