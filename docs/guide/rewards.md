# チャンネルポイント報酬（`/rewards/`）

`/rewards/`（サイドバーの「チャンネルポイント」）で、チャンネルポイント報酬を追加・編集・削除できます。チャンネルポイントはアフィリエイト・パートナーのチャンネルでだけ使えます。

## できること

- **追加する**: 名前（45文字まで）・必要ポイント（1以上）・説明（200文字まで）を入れ、＋のボタンを押します。「交換できる」を外して作ると、視聴者にはまだ見えません。「メッセージの入力を求める」を付けると、交換するときに視聴者が一言を書く欄が出ます
- **編集する**: 一覧の欄を書き換えて「保存する」を押します
- **削除する**: ごみ箱のボタンを押し、確認してから削除します。トリガーに使われている報酬は削除できません（先に `/triggers/` で外してください）

待機時間・上限回数・背景色などは扱わず、Twitchの既定のままです。

一覧には報酬の画像も出ます。画像は Twitch の API では登録・変更できないため、HDADでは表示だけです（アップロードした画像が無い報酬は Twitch の既定の画像で出ます）。

## Twitchで作った報酬は変更できません

Twitchは、**HDADから作った報酬しか**HDADからの変更を受け付けません。Twitchのクリエイターダッシュボードで作った報酬は一覧に出ますが、「ここでは変更できません」と表示され、編集も削除もできません。HDADで管理したい報酬は、HDADで作り直してください。

交換されたときに何をするか（アラートやチャット）は、[トリガー](./alerts.md)で決めます。交換の完了・返金はTwitchの画面で行います。

## 更新したあとはログインし直してください

報酬を変更するために、配信者のログインで `channel:manage:redemptions` の許可を新しく求めます。**更新したあとに一度ログアウトしてログインし直し、Twitch の許可の画面で許可してください。** 許可する前に報酬を追加・編集・削除しようとすると、ログインし直すよう画面に出ます（一覧を見ることはできます）。
