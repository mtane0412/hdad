# チャンネルポイント報酬（`/rewards/`）

`/rewards/`（サイドバーの「チャンネルポイント」）で、チャンネルポイント報酬を追加・編集・削除できます。チャンネルポイントはアフィリエイト・パートナーのチャンネルでだけ使えます。

## できること

- **追加する**: 名前（45文字まで）・必要ポイント（1以上）・説明（200文字まで）を入れ、＋のボタンを押します。「交換できる」を外して作ると、視聴者にはまだ見えません。「メッセージの入力を求める」を付けると、交換するときに視聴者が一言を書く欄が出ます。背景色・待機時間・上限回数・待ち行列の扱いも決められます（下の「細かい設定」）
- **編集する**: 一覧の行を押すと、その場で下に編集欄が開きます。書き換えて「保存する」を押します（開くのは1件ずつです）
- **削除する**: ごみ箱のボタンを押し、確認してから削除します。トリガーに使われている報酬は削除できません（先に `/triggers/` で外してください）

## 細かい設定

| 欄 | 意味 |
|---|---|
| 背景色 | Twitchの報酬の一覧で出る色です。新しく作るときはTwitchの紫から始まります |
| 交換したらすぐ完了にする（待ち行列に入れない） | 付けると、交換はTwitchの「報酬リクエストのキュー」に入らず、すぐ完了になります |
| 待機時間（秒） | 誰かが交換したあと、次に交換できるまでの時間です。60秒〜604800秒（7日）。空欄なら待機なし |
| 1配信あたりの上限回数 | 1回の配信で交換できる回数です。空欄なら制限なし |
| 1人あたりの上限回数 | 1回の配信で1人が交換できる回数です。空欄なら制限なし |

一覧には報酬の画像も出ます。画像は Twitch の API では登録・変更できないため、HDADでは表示だけです（アップロードした画像が無い報酬は Twitch の既定の画像で出ます）。画像は一覧の上の「Twitchで報酬を開く」から Twitch のページで設定してください。

## Twitchで作った報酬は変更できません

Twitchは、**HDADから作った報酬しか**HDADからの変更を受け付けません。Twitchのクリエイターダッシュボードで作った報酬は一覧に出ますが、名前の横に「Twitch」と出て、行を押しても開きません（編集も削除もできません）。HDADで管理したい報酬は、HDADで作り直してください。

交換されたときに何をするか（アラートやチャット）は、[トリガー](./alerts.md)で決めます。交換の完了・返金はTwitchの画面で行います。

## 更新したあとはログインし直してください

報酬を変更するために、配信者のログインで `channel:manage:redemptions` の許可を新しく求めます。**更新したあとに一度ログアウトしてログインし直し、Twitch の許可の画面で許可してください。** 許可する前に報酬を追加・編集・削除しようとすると、ログインし直すよう画面に出ます（一覧を見ることはできます）。
