# HDAD のドキュメント

HDAD の使い方を、画面・素材ごとに分けて置いてあります。全体の紹介は[リポジトリの README](../../README.md) にあります。

## 画面の動かし方

アプリのページは、サイドバーで「配信中」（配信しながら開いておく画面）・「配信画面」（OBSに載せるものの設定）・「自動化」（botやAIが動くもの）・「素材」に分けて並べています。どのページにいても **Cmd+K**（Windows は **Ctrl+K**）かサイドバーの上部の「ページを探す」で、名前の一部や言い換え（「OBS」「アラート」など）を打って Enter で移れます。画面下部には、どのページからでも配信中の操作ができるバーがあります（いまは文字起こしのオン・オフ）。サイドバーはその上部のボタンで開閉でき、狭い画面では下部のバーの左端のボタンから開けます。保存などの結果は画面の右下に数秒だけ出ます。トリガー・オーバーレイ・チャットボットのページで保存していない変更があるまま移ろうとすると、「保存せずに移る / 留まる」の確認が出ます。読み込みに失敗したページには「もう一度読み込む」が出ます。初めて使うときに要る説明（外部サービス側の設定・入力値の目安など）は、見出しの右の **？**（ヘルプボタン）を押すと出ます。

## 画面とページの一覧

| パス | 内容 |
| --- | --- |
| `/` | ダッシュボード（アプリ） |
| `/overlay/` | 合成オーバーレイの構成（アプリ）。オーバーレイ（OBSのブラウザソース1つぶん）に素材を積み、パラメータを調整して、そのOBS用URLをコピーする。**配信画面に映すものは、すべてここから出します** |
| `/triggers/` | トリガーの管理画面（アプリ）。既定メニューからきっかけを選んで何をするかを決める。オーバーレイ用キーの再発行もここ |
| `/media/` | アップロードの画面（アプリ）。アラートで流す画像・動画・音声を置く |
| `/rewards/` | チャンネルポイント報酬（アプリ）。報酬の追加・編集・削除 |
| `/comments/` | コメントビューアー（アプリ）。配信中のチャットの発言と出来事（サブスク・レイド・ビッツ・ポイントの引き換え・フォロー）を届いた順に並べ、初めてチャットした人への挨拶漏れを知らせる |
| `/bot/` | チャットボットの管理画面（アプリ）。botアカウントの接続・切断、テスト送信、コマンドと自動モデレーションの設定 |
| `/viewers/` | 視聴者の記録（アプリ）。チャットで発言した人の一覧と、配信者が書くメモ |
| `/draw/` | 手書き（アプリ）。配信画面に出す線をその場で描く |
| `/bgm/` | BGM（アプリ）。曲とクレジットを管理し、流す曲と音量をその場で切り替える |
| `/connectors/` | コネクター（アプリ）。外部のサービスとつなぐものをまとめたページ。裏方（VOICEVOX による読み上げ・Gyazo への画面の取り込み・BGM）を1つのブラウザソースにまとめるOBS用URLをコピーし、VOICEVOX・Gyazo の設定を保存し、タブの映像の Chrome 拡張（HDAD-tab）をダウンロードし、Chrome の音声認識（Web Speech API）による文字起こしをオン・オフする |
| `overlay/stage/` | 素材を重ねる合成オーバーレイ。オーバーレイ（`?overlay=`）1つにつきブラウザソース1つで済ませる |
| `overlay/backstage/` | 映すものを持たない裏方（読み上げ・画面の取り込み・BGM）を1枚にまとめたページ |
| `speech/reader/` | チャットを VOICEVOX に読み上げさせるページ。映すものを持たず音だけを出す |

配信画面に**映すもの**（壁紙・時計・チャットボックス・アラート・サイドスーパー・注目コメント・手書き・再生中の曲・タブの映像・字幕・作業ログ・作業机・ポモドーロ・テキスト）は、素材ごとのページを持ちません。`/overlay/` でオーバーレイに素材として置き、`overlay/stage/` のURLを1本だけOBSに貼ります（[合成オーバーレイ](./overlay.md)）。**映すものを持たない裏方**（読み上げ・画面の取り込み・BGM）だけは、`overlay/backstage/` にまとめた1枚を別に貼ります（[裏方](./backstage.md)）。

## OBSに載せるもの

まず[合成オーバーレイ](./overlay.md)を読んでください。オーバーレイの作り方と、素材の置き方・OBSへの貼り方がここにあります。素材ごとの説明は次のとおりです。

| 文書 | 内容 |
| --- | --- |
| [合成オーバーレイ](./overlay.md) | 素材を1枚に重ねてブラウザソースの数を減らす（`overlay/stage/`） |
| [壁紙](./wallpaper.md) | 配信画面の背景（素材の種類「壁紙」） |
| [時計](./clock.md) | 配信画面に重ねる時計（素材の種類「時計」） |
| [チャットボックス](./chat.md) | チャット欄を配信画面に重ねる（素材の種類「チャット」） |
| [アラート](./alerts.md) | イベント（GitHub のコミット・PRのマージを含む）で画像・動画・音声と文言を出す（素材の種類「アラート」）。トリガーの決め方と素材のアップロードもここ |
| [サイドスーパー](./side-super.md) | 画面の隅に2行のテロップを出し続ける（素材の種類「サイドスーパー」） |
| [注目コメント](./focus.md) | 発言1件を大きく映す（素材の種類「注目コメント」） |
| [手書き](./draw.md) | 配信中に描いた線を配信画面へ出す（素材の種類「手書き」） |
| [タブの映像](./tab.md) | Chrome のタブ1枚の映像と音を配信画面へ出す（素材の種類「タブの映像」）。映すタブは拡張のショートカットで切り替え、映しているタブでもう一度押すと止める。登録したサイトのページでは送るのを止める。右クリックで映す範囲をタブの一部分に絞れる |
| [字幕](./caption.md) | 話していることを配信画面の下端に字幕として出す（素材の種類「字幕」）。文字にするのはアプリのページの Web Speech API。英語の訳も添えられる |
| [作業ログ](./work-log.md) | その配信のコミット・PRのマージと、AIがまとめた章の見出しを、時刻つきで新しい順に並べる（素材の種類「作業ログ」） |
| [作業机](./task-desk.md) | 視聴者が `!task` で宣言した作業を1人1行で並べ、`!done` で完了したら祝う（素材の種類「作業机」）。みんなの作業時間の合計を素材・ダッシュボード・チャットの `{worktime}` で見せる |
| [テキスト](./text.md) | 「目標」「今やってること」など、自分で書いた文字をそのまま出す（`/texts/`・素材の種類「テキスト」）。画面下端のバーからも本文を書き換えられる |
| [ポモドーロ](./pomodoro.md) | 25分の作業と5分の休憩のタイマーを出し、区切りでトリガーを動かし、休憩中は BGM を切り替える。画面下端のバーからも操作できる（`/pomodoro/`・素材の種類「ポモドーロ」） |
| [市町村紹介](./town-tour.md) | レイドや `!darts` のようなキーワードで、ランダムな市区町村の都道府県当てクイズをチャットに出してから、日本地図からズームし、記事の代表画像と Wikipedia を材料にした紹介を流す。締めに全国制覇マップと、レイド元を名誉町民に任命する認定証を出す。場面ごとのBGMと効果音を選べ、VOICEVOX のナレーションで読み上げられる |
| [ワイプ](./wipe.md) | バラエティ番組のワイプのように、チャットの発言を1件ずつ、発言した人のアイコンの枠と吹き出しで出し、読み上げているあいだだけ吹き出しを出す（素材の種類「ワイプ」） |
| [漢字クイズ](./kanji-quiz.md) | チャンネルポイントが交換されたら、熟語の読みを問う漢字クイズを流す。級を選び、制限時間が過ぎたら正解の読みと解説を出す（素材の種類「漢字クイズ」） |
| [ツイスター](./twister.md) | レイドしてきた配信者と自分が、Twitch のアイコンを顔に貼った3Dの人形でツイスターゲームをする。スピナーで絡み合わせてから倒れ込ませ、勝者を出す（素材の種類「ツイスター」） |
| [チャットの読み上げ](./speech.md) | チャットを VOICEVOX に読ませる（`speech/reader/`。映すものを持たない裏方）。画面下端のバーからミュートできる |
| [配信中の文字起こし](./transcript.md) | 喋った内容を Worker へ取り込み、あらすじとサイドスーパーの材料にする（アプリのページで Chrome の音声認識（Web Speech API）を動かす） |
| [配信画面の取り込み](./screen.md) | 画面に出ている文字を取り込み、あらすじとサイドスーパーの材料にする（`overlay/backstage/`。映すものを持たない裏方） |
| [BGM](./bgm.md) | 曲とクレジットを管理し、流す曲を切り替える（`/bgm/`。鳴らすのは裏方のページ）。クレジットは素材「再生中の曲」とチャットの `{bgm}` で見せる |
| [裏方](./backstage.md) | 映すものを持たないページを1枚にまとめる（`overlay/backstage/`） |
