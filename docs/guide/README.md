# HDAD のドキュメント

HDAD の使い方を、画面・素材ごとに分けて置いてあります。全体の紹介は[リポジトリの README](../../README.md) にあります。

## 画面とページの一覧

| パス | 内容 |
| --- | --- |
| `/` | ダッシュボード（アプリ） |
| `/wallpaper/`・`/clock/`・`/chat/` | 各カテゴリのギャラリー（アプリ）。素材を選び、パラメータを調整して、OBS用のURLをコピーする |
| `/triggers/` | トリガーの管理画面（アプリ）。既定メニューからきっかけを選んで何をするかを決め、アラート用オーバーレイのOBS用URLをコピーする |
| `/media/` | アップロードの画面（アプリ）。アラートで流す画像・動画・音声を置く |
| `/bot/` | チャットボットの管理画面（アプリ）。botアカウントの接続・切断、テスト送信、コマンドと自動モデレーションの設定 |
| `/viewers/` | 視聴者の記録（アプリ）。チャットで発言した人の一覧と、配信者が書くメモ |
| `/speech/` | チャットの読み上げの設定（アプリ）。設定を保存し、VOICEVOX に読ませるOBS用URLをコピーする |
| `/transcript/` | 配信中の文字起こしの取り込み（アプリ）。ゆかコネNEO とつなぐ中継ページのOBS用URLをコピーする |
| `/side-super/` | サイドスーパーの設定（アプリ）。出す位置（左上・右上）を選び、OBS用URLとデモへのリンクを出す |
| `/focus/` | 注目コメントの指定（アプリ）。誰の発言に追従するか、どの発言を取り上げるかを決め、OBS用URLをコピーする |
| `/overlay/` | 合成オーバーレイの構成（アプリ）。オーバーレイ（OBSのブラウザソース1つぶん）に素材を積み、そのOBS用URLをコピーする |
| `wallpaper/<id>/` | 配信画面の背景（壁紙）の各ページ |
| `clock/<id>/` | 配信画面に重ねる時計の各ページ |
| `chat/<id>/` | Twitchのチャット欄を配信画面に重ねるチャットボックスの各デザインのページ |
| `alerts/` | Twitchのイベント（チャンネルポイント交換）で画像・動画・音声を流すアラート用オーバーレイ。単独のページ |
| `speech/reader/` | チャットを VOICEVOX に読み上げさせるページ。映すものを持たず音だけを出す。単独のページ |
| `transcript/relay/` | 配信者が喋った内容を Worker へ送る中継ページ。映すものを持たない。単独のページ |
| `focus/overlay/` | 取り上げた1件のコメントを大きく映す注目コメントのオーバーレイ。単独のページ |
| `overlay/stage/` | 素材を重ねる合成オーバーレイ。オーバーレイ（`?overlay=`）1つにつきブラウザソース1つで済ませる |
| `/backstage/` | 裏方のOBS用URL（アプリ）。読み上げと文字起こしの中継を1つのブラウザソースにまとめるURLをコピーする |
| `overlay/backstage/` | 映すものを持たない裏方（読み上げ・文字起こしの中継）を1枚にまとめたページ |

## OBSに載せる素材とオーバーレイ

| 文書 | 内容 |
| --- | --- |
| [壁紙](./wallpaper.md) | 配信画面の背景（`wallpaper/<id>/`） |
| [時計](./clock.md) | 配信画面に重ねる時計（`clock/<id>/`） |
| [チャットボックス](./chat.md) | チャット欄を配信画面に重ねる（`chat/<id>/`） |
| [アラート](./alerts.md) | イベントで画像・動画・音声と文言を出す（`alerts/`）。トリガーの決め方と素材のアップロードもここ |
| [チャットの読み上げ](./speech.md) | チャットを VOICEVOX に読ませる（`speech/reader/`） |
| [配信中の文字起こし](./transcript.md) | 喋った内容を Worker へ取り込み、あらすじとサイドスーパーの材料にする（`transcript/relay/`） |
| [サイドスーパー](./side-super.md) | 画面の隅に2行のテロップを出し続ける（`side-super/overlay/`） |
| [注目コメント](./focus.md) | 発言1件を大きく映す（`focus/overlay/`） |
| [合成オーバーレイ](./overlay.md) | 素材を1枚に重ねてブラウザソースの数を減らす（`overlay/stage/`） |
| [裏方](./backstage.md) | 映すものを持たないページを1枚にまとめる（`overlay/backstage/`） |
