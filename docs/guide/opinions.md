# 意見ボード（`/opinions/`・素材の種類「意見ボード」）

配信でテーマを出し、視聴者がチャットに書いた意見を観点（論点）ごとに並べて配信画面に映します。dd2030 の「いどばたビジョン」にならった機能で、配信中の議論で拾いきれない・流れていってしまうコメントを、LLM が意見として取り出して整理します。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

**多数決には見せません。** 配信画面には人数を出さず、論点の大きさや並びも人数で変えません。意見は賛成・反対ではなく、札の種類（課題・解決策・問い・気づき）で分けます。人数は管理画面（`/opinions/`）でだけ確かめられます。

## テーマを出す

サイドバーの「意見ボード」（`/opinions/`）で、テーマを入力して「テーマを出す」を押します。

- テーマは40文字までです。**超えたら切り詰めずに断ります**
- 同時に出せるテーマは1つです。次のテーマを出すときは、いまのテーマを「締め切る」で締め切ってください
- 締め切ると、それ以降のコメントは意見にしません。配信画面には、次のテーマを出すまで締め切ったテーマの意見ボードが残ります（見出しが「締め切ったテーマ」に変わります）
- 入力しかけのテーマがあるあいだにページを離れようとすると、確認が出ます

## コメントが意見になるまで

テーマを出しているあいだのコメントは、次の順に意見になります。

1. **決まった規則で落とす。** コマンド（`!` で始まる）・エモートだけのコメント・「草」「www」「888」のような短い反応は、LLM に渡さずに落とします。ただし**返信は短くても落としません**（「それな」は返信先の意見への賛同として扱えるため）。botのコメントと、自動モデレーションで処分したコメントも使いません
2. **続けて書いたコメントをつなげる。** 同じ人が20秒以内に続けて書いたコメントは、1つの発言としてつなげます（「AIのコメ返しは」「ちょっと寂しいかも」）。続きが来るかもしれないあいだ（最後のコメントから20秒）は待ちます
3. **Jev で絞り込む。** OpenRouter の鍵（`OPENROUTER_API_KEY`）があれば、振り分けの前に、発言ごとに「テーマについての意見・課題・提案・問いか」を判定用のモデル Jev にまとめて尋ね、確率をコメントに残します（返信は返信先の発言も添えて尋ねます）。確率が低い発言は LLM に渡さずに落とす仕組みですが、**いまはしきい値を 0 にしていて、確率を記録するだけで1件も落としません**（実際の配信で落としすぎないかを確かめてから決めます）。Jev が失敗したときは、黙って全部を通さず、その回の発言を**失敗**として残し `opinion-filter-failed` を記録します。鍵が無ければ Jev を呼ばずに次へ進みます
4. **LLM が振り分ける。** 45秒ごとに、新しい発言をまとめて LLM に渡し、発言ごとに「関係ない」「既にある意見と同じ」「新しい意見」に振り分けさせます。新しい意見には、40文字までの1文と札の種類を付け、既にある論点か新しい論点（12文字まで・6つまで）に入れます。返信には返信先の発言を添えて渡すので、「それな」が何への賛同かも分かります。新しい発言が無ければ LLM を呼びません
5. **振り分けを確かめる。** LLM の返事は信用せず、渡した発言がすべて1回ずつ振り分けられているか、知らない意見や論点を指していないか、文字数や論点の数が上限に収まっているかを確かめます。1つでも外れていれば、その回の発言は**失敗**として残し、`opinion-sort-failed` として記録します（[配信の記録](./stats.md)）。同じ発言で何度も失敗し続けないよう、失敗した発言は次の回に渡しません

一度振り分けた意見は作り直しません。過去の意見を書き換えずに積み上げていくので、配信画面の論点が急に入れ替わることはありません。

使うモデルは[LLMの設定](./llm.md)（`/llm/`）の「意見ボードの振り分け」で選びます。決まった形の JSON を守らせるので、既定は大きいモデル（あらすじと同じ）です。

## 視聴者への問いかけ

配信画面の中央下に、「こんな観点からも聞いてみたい」として視聴者への問いかけを1つ出します（例:「AIの使用料、配信者はどこまで払っていいと思う？」）。まだ誰も触れていない切り口を、テーマといまの論点・意見から LLM が見つけて1文にします。候補を並べるのではなく、1つだけ提案します。

- 最初の意見ができたときに作ります。テーマを出した直後は出ません
- 問いかけに答える意見が届いたら（振り分けの LLM が「この発言は問いかけへの答え」と返したら）、次の問いかけに切り替えます。新しい意見が届かないあいだは作り直しません
- 問いかけは40文字までです。**超えたら切り詰めずに断り、前の問いかけを残します**（`opinion-prompt-failed` として記録します）
- `/opinions/` の「テーマ」に、いまの問いかけが出ます。「別の問いかけにする」で、いまとは違う切り口の問いかけに替えられます（作れなければ理由を出し、前の問いかけを残します）
- 隠した意見は問いかけの材料にしません
- テーマを締め切ると、配信画面の問いかけは消えます

使うモデルは[LLMの設定](./llm.md)の「意見ボードの問いかけ」で選びます（既定は振り分けと同じ大きいモデル）。

## 意見を確かめる・隠す

`/opinions/` の「意見」に、論点ごとの意見が出ます（15秒おきに読み直します）。

- 意見ごとに札の種類・人数・もとのコメント（書いた人と本文）が出ます
- 荒らしや取り違えの意見は「隠す」を押すと、すぐ配信画面から消えます。「戻す」でまた出ます
- 隠した意見も、同じ意見のコメントが来たときの振り分け先として残ります（隠した意見と同じことを書いたコメントが、新しい意見として出直さないため）

## 意見にならなかったコメントを救い出す

`/opinions/` の「意見にならなかったコメント」に、テーマを出しているあいだに受け取ったコメントの内訳と、意見にならなかったコメントの一覧（新しい順）が出ます。テーマを締め切ったあとも、次のテーマを出すまで使えます。

- 内訳は「受け取った・意見にした・振り分け待ち・規則で落とした（コマンド・エモートだけ・短い反応ごと）・Jev が意見ではないとみた・LLM が無関係とした・振り分けに失敗」の件数です
- 一覧には、規則で落としたもの・Jev が落としたもの・LLM が無関係としたもの・振り分けに失敗したものが、なぜ落ちたかを添えて出ます。テーマを締め切ったときに振り分け待ちだったコメントも、締め切ったあとはここに出ます
- **新しい意見にする**: LLM がそのコメントから意見の下書き（札の種類・40文字までの1文・入れる論点）を作ります。下書きはまだ保存されていないので、直してから「意見にする」を押します。新しい論点も作れます（12文字まで・6つまで。既にある論点と同じ名前は断ります）。下書きを作れなかったときは理由を出します
- **既にある意見に統合する**: 意見を選んで「統合する」を押すと、そのコメントが意見のもとのコメントに加わります（人数にも数えます）
- 救い出した意見は、すぐ配信画面に出ます
- 下書きを直している・統合先を選んでいるあいだにページを離れようとすると、確認が出ます

下書きを作るモデルは、[LLMの設定](./llm.md)の「意見ボードの振り分け」で選んだものを使います。

## 論点を整える

LLM が論点を細かく分けすぎたときは、`/opinions/` の「意見」で配信者が整えます。**LLM に論点をまとめ直させることはしません。**

- **名前を変える**: 論点の名前を書き換えます（12文字まで。ほかの論点と同じ名前は断ります）
- **ほかの論点とまとめる**: まとめ先を選んで「まとめる」を押し、確認で「論点をまとめる」を押すと、その論点の意見をまとめ先へ移し、その論点を消します。まとめ先の名前が残ります。元には戻せません（論点が1つのときは出ません）
- どちらも、すぐ配信画面に出ます。テーマを締め切ったあとも使えます

## 配信画面に出す

[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「意見ボード」を追加して、構成を保存します。追加したときの大きさは配信画面と同じ（オーバーレイいっぱい）です。

- 中央にテーマと「いま紹介している意見」と視聴者への問いかけ、左右に論点を3つずつ並べます。論点の中は新しい意見を3件まで出します
- 「いま紹介している意見」は、**人数ではなく意見を作った順に8秒ずつ**回します。論点の中に出しきれない古い意見も、ここで順に回ってきます。少数の意見にも同じだけ出番が回ります
- 新しく入った意見は10秒のあいだ緑の縁で光ります
- 札の種類は色だけでなく文字（課題・解決策・問い・気づき）でも出します
- テーマを一度も出していないあいだは何も出しません

## 入れたあとにすること

この機能を入れたあとは、マイグレーション `0033_opinions.sql` と `0034_opinion_prompts.sql` を適用してください（適用方法は[配信の記録](./stats.md)を参照）。`0033` を適用していないと、テーマを出せず、チャットの発言が届くたびに `opinion-record-failed` として記録されます。`0034` を適用していないと、テーマを出せず（問いかけの列が無いため）、振り分けのたびに失敗が記録されます。

## できないこと（これからの予定）

- 配信のあとの振り返り（ダッシュボードで全部の意見を読む・まとめを作る）は、issue #309 で足します
