# 作業ログ（素材の種類「作業ログ」）

作業配信に途中から来た人にも「今日ここまでに何をやったか」が分かるよう、その配信で起きたことを**時刻つきで新しい順に**配信画面へ並べます。並べるのは次の3種類で、それぞれ印が付きます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

| 印 | 何か | どこから来るか |
| --- | --- | --- |
| **コミット**（緑の塗り） | コミットを push した。本文は最後のコミットのメッセージの1行目 | GitHub の Webhook（[設定](./deploy.md#github-の-webhook-の設定任意)） |
| **マージ**（紫の塗り） | PR をマージした。本文は「#番号 タイトル」 | GitHub の Webhook |
| **AIのまとめ**（枠線だけの印・斜体の淡い文字） | 約30分ごとの区間に何が話されたかの見出し（[章](./stats.md#配信で何が話されたか章)） | cron（5分おき）が LLM に作らせたもの |

**コミット・マージは実際に起きた出来事、「AIのまとめ」は機械が発話をまとめたもの**です。見出しが外れていることもあるので、出来事と同じ見た目にはせず、印の言葉と見た目の両方で区別しています。

配信画面に出すには、[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「作業ログ」を追加します。配信者が決めるパラメータはありません。

- **コミット・マージは、トリガーの設定と関係なく並びます**（[アラート](./alerts.md#開発の項目github)の「開発」の項目に効果を付けていなくても並びます）。GitHub の Webhook を設定していなければ、並ぶのは「AIのまとめ」だけです
- **配信していないときに届いたコミット・マージは並びません**（記録もしません）。配信外の作業は今日のログに含めません
- 増えた1行は**すぐに**画面へ出ます（アラートと同じ接続で押し出します）。「AIのまとめ」は区間が閉じてから作られるので、30分ほど遅れて出て、その区間の始まりの時刻の位置に入ります
- 開き直したとき・接続が切れてつなぎ直したときは、その配信のログを Worker から読み直して取り戻します。5分おきにも読み直すので、配信が切り替わると前の配信の行は消えます
- 持っておくのは新しいほうから**20行まで**です。そのうち何行が映るかは素材の枠の大きさで決まり、枠からあふれた古い行は見えません（追加したときの大きさは 560×640px で、10行ほど収まります）
- 同じ通知が GitHub から再送されても（Recent Deliveries の Redeliver）、行は増えません
- 起動できない失敗（キーの誤りなど）や、Worker とつながらないときは素材の枠にエラーを出します。いっぽう5分おきの読み直しの失敗は出さず、映している行をそのまま残します
- 行が届くのを待たずに見栄えを確かめるには、`/overlay/` のプレビューを開きます（サンプルの行が1行ずつ増えていく場面を流します。3種類の印がすべて入っています）
