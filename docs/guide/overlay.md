# 合成オーバーレイ（`overlay/stage/`）

壁紙・時計・チャットボックス・アラート・サイドスーパー・注目コメントを1枚のページに重ね、OBSのブラウザソースの数を減らします。ブラウザソースはその数だけ Chromium のレンダラを立ち上げるため、素材ごとにページを分けると配信中のメモリを食います。構成（どのオーバーレイにどの素材をどこへ置くか）は `/overlay/` の画面で決めます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

**配信画面に映すものは、すべてこのページから出します。** 素材ごとの単独ページ（`wallpaper/<id>/`・`alerts/` など）はありません。映すものを持たない裏方（読み上げ・文字起こしの中継）だけは別の1枚です（[裏方](./backstage.md)）。

**用語**: ここで言う**オーバーレイ**は、**OBSのブラウザソース1つ＝重なりの1枚**です。その中に**素材**（壁紙・時計・チャットなど）を積みます。

**1枚にはまとめられません。** アバターやゲーム画面というWebでないソースが間に挟まり、Web側の素材をその前と後ろの両方に置きたいためです。そこでブラウザソースの数を「素材の数」ではなく「**Webでないソースを挟んで何枚に分かれるか**」で決めます。既定では背面（`back`）と前面（`front`）の2つを用意し、画面から増やせます。

```text
https://hdad.<サブドメイン>.workers.dev/overlay/stage/?key=<オーバーレイ用キー>&overlay=<オーバーレイの名前>
```

| パラメータ | 内容 |
| --- | --- |
| `key` | オーバーレイ用キー（必須）。キーを含むURLはオーバーレイの画面（`/overlay/`）でコピーできる（裏方のページと同じキーです。再発行は[トリガーの画面](./alerts.md)から） |
| `overlay` | 描くオーバーレイの名前（既定は `front`）。このオーバーレイに積んだ素材だけを重ねる |

- **URLに入るのはキーとオーバーレイの名前だけです。** 「時計を背面から前面へ移す」「位置を変える」「パラメータを変える」はすべて `/overlay/` の編集だけで済み、**名前を変えないかぎりOBSのURLは貼り替えません**
- 位置と大きさはオーバーレイに対する**割合（％）**で持ちます（配信解像度が変わっても崩れません）。数値で入れてもドラッグで置いても、保存されるのはこの割合です
- **1つの素材が失敗しても、同じオーバーレイのほかの素材は動き続けます**（失敗はその素材の枠の中に表示します）。配信中に片方が壊れたときの被害を、配信画面の全損から1素材の欠落に留めるためです
- 素材を1つも積んでいないオーバーレイは保存できません（貼っても何も映らないURLを作らないためです）

## `/overlay/` の画面でできること

| できること | 内容 |
| --- | --- |
| オーバーレイの追加・削除 | オーバーレイ1つがOBSのブラウザソース1つです。名前は英小文字・数字・ハイフン（20文字まで）で付けます |
| 素材の一覧と並べ替え | **一覧は前に出るものから並びます**（OBSのソース一覧と同じで、上にあるものが前です）。「前面へ」「背面へ」で動かします |
| 素材を別のオーバーレイへ移す | 素材を開いて「置くオーバーレイ」を選びます（移した先のいちばん前に入ります） |
| 位置と大きさ | オーバーレイに対する割合（％）を数値で入れるか、**配置用の枠でドラッグして決めます**（下記） |
| 素材のパラメータ | 素材を開くと、その素材が持つパラメータの入力欄が並びます（既定値のままのパラメータは保存しません） |
| プレビュー | カードの中で重なりと見た目を確かめます（下記） |
| オーバーレイごとのOBS用URL | それぞれのカードからコピーできます |

- 値の検証はWorkerだけが持ちます。空欄は 0 に丸めず、Workerが返した理由をオーバーレイと素材の名前を添えて並べます
- 保存済みの値が読めない素材（レジストリから消えたデザインなど）も**黙って捨てません**。理由をその行に出すので、デザインを選び直すか、その素材を外してください
- **素材を足したときの大きさは、種類ごとの推奨の大きさから始まります**（時計は600×240px、チャットボックスは480×800px、配信画面と同じ大きさで使う素材（壁紙・アラート・サイドスーパー・注目コメント）はオーバーレイいっぱい）。置き場所は左上から始まるので、配置用の枠で動かしてください

### 配置用の枠（ドラッグで置く）

オーバーレイのカードの中に、配信画面と同じ縦横比の枠が出ます。素材は四角として描かれ、つかんで動かす・端と角のつまみで大きさを変えられます。

- ドラッグで決めた値はそのまま数値欄にも出ます（保存するのは割合（％）のままです）
- 四角をつかむとその素材の設定が開くので、どの四角がどの素材かを数値欄と見比べられます
- 枠に描くのは四角と名前だけで、素材の中身は映しません（中身はプレビューで見ます）
- 数値欄を空にした直後など、位置を数として読めない素材は四角にせず理由を添えます
- グリッドや他の素材の端への吸着はまだありません

### プレビュー

カードの中でプレビューを開くと、**そのオーバーレイの重なりと見た目を、配信画面に出す前に確かめられます**。中身は合成ページそのもの（実寸1920×1080で描いて枠の幅に縮小）なので、本番と同じ描画です。

- **映すのは編集中の構成で、保存は要りません。** 保存した時点でOBSに貼った合成ページへ反映されるため、「保存してから確かめる」では配信画面に出してから確かめることになってしまいます
- **素材の中身はすべてサンプルです**（チャットボックスはサンプルの書き込み、アラート・サイドスーパー・注目コメントはサンプルを順に流します）。匿名IRCやアラートのWebSocketが配信中のものに加えてもう1組動くことはなく、URLにオーバーレイ用キーも載りません
- 開くのは一度に1つだけで、畳むと止まります（重なりの1枚を丸ごと動かすためです）
- 編集が進むと少し待ってから作り直します。位置と大きさを数として読めない素材は映さず、理由を添えます

## OBSでの設定

1. オーバーレイごとに ソースの追加 > ブラウザ を1つずつ置く
2. URLにそのオーバーレイのURLを貼り、幅と高さを配信のキャンバスと同じ大きさ（1920×1080 など）にする
3. ソースの重なりは、オーバーレイのブラウザソースのあいだにアバターやゲーム画面を挟む形で並べる（背面のオーバーレイ → ゲーム画面・アバター → 前面のオーバーレイ）
