# 合成オーバーレイ（`overlay/stage/`）

壁紙・時計・チャットボックス・アラート・サイドスーパー・注目コメントを1枚のページに重ね、OBSのブラウザソースの数を減らします。ブラウザソースはその数だけ Chromium のレンダラを立ち上げるため、素材ごとにページを分けると配信中のメモリを食います。構成（どのオーバーレイにどの素材をどこへ置くか）は `/overlay/` の画面で決めます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

**用語**: ここで言う**オーバーレイ**は、**OBSのブラウザソース1つ＝重なりの1枚**です。その中に**素材**（壁紙・時計・チャットなど）を積みます。

**1枚にはまとめられません。** アバターやゲーム画面というWebでないソースが間に挟まり、Web側の素材をその前と後ろの両方に置きたいためです。そこでブラウザソースの数を「素材の数」ではなく「**Webでないソースを挟んで何枚に分かれるか**」で決めます。既定では背面（`back`）と前面（`front`）の2つを用意し、画面から増やせます。

```text
https://hdad.<サブドメイン>.workers.dev/overlay/stage/?key=<オーバーレイ用キー>&overlay=<オーバーレイの名前>
```

| パラメータ | 内容 |
| --- | --- |
| `key` | オーバーレイ用キー（必須）。キーを含むURLはオーバーレイの画面（`/overlay/`）でコピーできる（アラート・文字起こし・サイドスーパー・注目コメントと同じキーです） |
| `overlay` | 描くオーバーレイの名前（既定は `front`）。このオーバーレイに積んだ素材だけを重ねる |

- **URLに入るのはキーとオーバーレイの名前だけです。** 「時計を背面から前面へ移す」「位置を変える」「パラメータを変える」はすべて `/overlay/` の編集だけで済み、**名前を変えないかぎりOBSのURLは貼り替えません**
- 位置と大きさはオーバーレイに対する**割合（％）**で持ちます（配信解像度が変わっても崩れません）
- **1つの素材が失敗しても、同じオーバーレイのほかの素材は動き続けます**（失敗はその素材の枠の中に表示します）。配信中に片方が壊れたときの被害を、配信画面の全損から1素材の欠落に留めるためです
- 素材を1つも積んでいないオーバーレイは保存できません（貼っても何も映らないURLを作らないためです）
- **既存の単独ページ（`alerts/`・`side-super/overlay/`・`focus/overlay/` と素材ページ）はそのまま使えます**。合成ページが実際の配信で安定したことを確かめてから、どちらを使うかを決められます

## `/overlay/` の画面でできること

| できること | 内容 |
| --- | --- |
| オーバーレイの追加・削除 | オーバーレイ1つがOBSのブラウザソース1つです。名前は英小文字・数字・ハイフンで付けます |
| 素材の一覧と並べ替え | オーバーレイのカードの中で、上から下へ重ねます（下にあるものが前に出ます）。「背面へ」「前面へ」で動かします |
| 素材を別のオーバーレイへ移す | 素材を開いて「置くオーバーレイ」を選びます（移した先のいちばん前に入ります） |
| 位置と大きさ | オーバーレイに対する割合（％）を数値で入れます（ドラッグでの配置はまだありません） |
| 素材のパラメータ | ギャラリーと同じ入力欄で調整します（既定値のままのパラメータは保存しません） |
| オーバーレイごとのOBS用URL | それぞれのカードからコピーできます |

- 値の検証はWorkerだけが持ちます。空欄は 0 に丸めず、Workerが返した理由をオーバーレイと素材の名前を添えて並べます
- 保存済みの値が読めない素材（レジストリから消えたデザインなど）も**黙って捨てません**。理由をその行に出すので、デザインを選び直すか、その素材を外してください

## OBSでの設定

1. オーバーレイごとに ソースの追加 > ブラウザ を1つずつ置く
2. URLにそのオーバーレイのURLを貼り、幅と高さを配信のキャンバスと同じ大きさ（1920×1080 など）にする
3. ソースの重なりは、オーバーレイのブラウザソースのあいだにアバターやゲーム画面を挟む形で並べる（背面のオーバーレイ → ゲーム画面・アバター → 前面のオーバーレイ）
