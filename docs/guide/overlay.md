# 合成オーバーレイ（`overlay/stage/`）

壁紙・時計・チャットボックス・アラート・サイドスーパー・注目コメント・手書き・再生中の曲（[BGM](./bgm.md)のクレジット）・[タブの映像](./tab.md)・[字幕](./caption.md)・[作業ログ](./work-log.md)・[作業机](./task-desk.md)・[ポモドーロ](./pomodoro.md)・[市町村紹介](./town-tour.md)・[ツイスター](./twister.md)・[ワイプ](./wipe.md)・[テキスト](./text.md)・[漢字クイズ](./kanji-quiz.md)・[意見ボード](./opinions.md)・[ペロペロ](./lick.md)・[VRM](./vrm.md)・[チャットで推理](./chat-deduction.md)を1枚のページに重ね、OBSのブラウザソースの数を減らします。ブラウザソースはその数だけ Chromium のレンダラを立ち上げるため、素材ごとにページを分けると配信中のメモリを食います。構成（どのオーバーレイにどの素材をどこへ置くか）は `/overlay/` の画面で決めます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

**配信画面に映すものは、すべてこのページから出します。** 素材ごとの単独ページ（`wallpaper/<id>/`・`alerts/` など）はありません。映すものを持たない裏方（読み上げ・画面の取り込み・BGM）だけは別の1枚です（[裏方](./backstage.md)）。

**用語**: ここで言う**オーバーレイ**は、**OBSのブラウザソース1つ＝重なりの1枚**です。その中に**素材**（壁紙・時計・チャットなど）を積みます。

**1枚にはまとめられません。** アバターやゲーム画面というWebでないソースが間に挟まり、Web側の素材をその前と後ろの両方に置きたいためです。そこでブラウザソースの数を「素材の数」ではなく「**Webでないソースを挟んで何枚に分かれるか**」で決めます。既定では背面（`back`）と前面（`front`）の2つを用意し、画面から増やせます。

```text
https://hdad.<サブドメイン>.workers.dev/overlay/stage/?key=<オーバーレイ用キー>&overlay=<オーバーレイの名前>
```

| パラメータ | 内容 |
| --- | --- |
| `key` | オーバーレイ用キー（必須）。キーを含むURLはオーバーレイの画面（`/overlay/`）でコピーできる（裏方のページと同じキーです。再発行は[トリガーの画面](./alerts.md)から） |
| `overlay` | 描くオーバーレイの名前（既定は `front`）。このオーバーレイに積んだ素材だけを重ねる |

- **URLに入るのはキーとオーバーレイの名前だけです。** 「時計を背面から前面へ移す」「位置を変える」「パラメータを変える」はすべて `/overlay/` の編集だけで済み、**名前を変えないかぎりOBSのURLは貼り替えません**
- 位置と大きさはオーバーレイに対する**割合（％）**で持ちます（配信解像度が変わっても崩れません）。数値で入れてもドラッグで置いても、保存されるのはこの割合です
- **1つの素材が失敗しても、同じオーバーレイのほかの素材は動き続けます**（失敗はその素材の枠の中に表示します）。配信中に片方が壊れたときの被害を、配信画面の全損から1素材の欠落に留めるためです
- 素材を1つも積んでいないオーバーレイは保存できません（貼っても何も映らないURLを作らないためです）
- **保存すると、OBSを触らなくても配信画面に反映されます。** 中身が変わったオーバーレイのブラウザソースが自動で読み込み直されます（素材を隠す・表示したときも同じです）。そのとき同じオーバーレイで流れていたアラートなどは途切れます。中身が変わっていないオーバーレイは読み込み直しません

## `/overlay/` の画面でできること

| できること | 内容 |
| --- | --- |
| オーバーレイの追加・削除 | オーバーレイ1つがOBSのブラウザソース1つです。名前は英小文字・数字・ハイフン（20文字まで）で付けます。オーバーレイは画面上部の**タブで1つずつ開いて**編集します（矢印のボタンでタブの並びを入れ替えられます）。追加はタブの並びの横の**＋**から名前を打って行います |
| 素材の一覧と並べ替え | 左の**レイヤー**に素材が並びます。**一覧は前に出るものから並びます**（OBSのソース一覧と同じで、上にあるものが前です）。「前面へ」「背面へ」で動かすほか、行の左端のつまみ（⋮⋮）をドラッグして別の行へ落としても並べ替えられます（落とせるのは同じオーバーレイの中だけです） |
| 素材を隠す・表示する | 行の**目のアイコン**で切り替えます（OBSのソース一覧の目と同じです）。保存済みの素材は**押した瞬間に配信画面へ反映**され、保存ボタンは要りません（ほかの未保存の編集は巻き込みません）。隠した素材は表示領域に点線の枠と名前だけで残り、合成ページでは起動しません（音や読み上げも止まります）。追加したばかりでまだ保存していない素材は、保存したときに反映されます |
| 位置と大きさ | オーバーレイに対する割合（％）を数値で入れるか、**表示領域でドラッグして決めます**（下記） |
| 素材のパラメータ | 素材を開くと、その素材が持つパラメータの入力欄が並びます（既定値のままのパラメータは保存しません） |
| オーバーレイごとのOBS用URL | タブのすぐ下に出ているURLをコピーします |

- 値の検証はWorkerだけが持ちます。空欄は 0 に丸めず、Workerが返した理由をオーバーレイと素材の名前を添えて並べます
- 保存済みの値が読めない素材（レジストリから消えたデザインなど）も**黙って捨てません**。理由をその行に出すので、デザインを選び直すか、その素材を外してください
- **素材を追加したときの大きさは、種類ごとの推奨の大きさから始まります**（時計は600×240px、チャットボックスは480×800px、作業ログと作業机は560×640px、ポモドーロは420×200px、ワイプは480×460px、テキストは720×220px、VRMは480×720px、配信画面と同じ大きさで使う素材（壁紙・アラート・サイドスーパー・注目コメント・再生中の曲・タブの映像・字幕・市町村紹介・ツイスター・漢字クイズ・意見ボード・ペロペロ・チャットで推理）はオーバーレイいっぱい）。置き場所は左上から始まるので（ワイプだけは右上から）、表示領域で動かしてください

### 表示領域（プレビューを見ながら置く）

開いているオーバーレイの右側に、**そのオーバーレイの重なりと見た目そのもの**（プレビュー）が出ます。中身は合成ページそのもの（実寸1920×1080で描いて枠の幅に縮小）なので、本番と同じ描画です。その上で素材を選び、動かし、大きさを変えます。

- 素材を押すと選ばれ、左のレイヤーでその素材の設定が開きます。逆に、レイヤーで素材を選ぶと表示領域でも選ばれます。何もないところを押すと選択が外れます
- 選んだ素材はつかんで動かせ、角と辺のつまみで大きさを変えられます。**動かしているあいだもプレビューの中身がついてきます**
- 選んだ素材は、ほかの素材の後ろにあっても前に出して動かせます（重なりの順は変わりません）。前の素材に隠れて押せない素材は、レイヤーで選んでください
- **矢印キーで0.1％ずつ、Shift を押しながらなら1％ずつ動かせます**
- ドラッグで決めた値はそのまま数値欄にも出ます（保存するのは割合（％）のままです）
- 数値欄を空にした直後など、位置を数として読めない素材は表示領域にもプレビューにも出さず、理由を添えます
- グリッドや他の素材の端への吸着はまだありません

プレビューについて:

- **映すのは編集中の構成で、保存は要りません。** 保存した時点でOBSに貼った合成ページへ反映されるため、「保存してから確かめる」では配信画面に出してから確かめることになってしまいます
- **素材の中身はすべてサンプルです**（チャットボックスはサンプルの書き込み、アラート・サイドスーパー・注目コメント・再生中の曲・字幕・作業ログ・作業机・ポモドーロ・テキスト・意見ボード・チャットで推理はサンプルを順に流し、市町村紹介は千代田区の紹介をくり返し流し、ツイスターは決まった種の対戦を順にくり返し流し、漢字クイズは決まった2問を順にくり返し流し、ペロペロは決まった種の舐め方を順にくり返し流し、VRM は保存してある VRM を立たせて決まった反応をくり返し流し（VRM を読むときだけ配信者のログインを使います）、ワイプはサンプルの発言を読み上げずに順に出し、タブの映像は置いた場所を示す見本を出します）。匿名IRCやアラートのWebSocketが配信中のものに加えてもう1組動くことはなく、URLにオーバーレイ用キーも載りません
- 動かすのは開いているタブのオーバーレイ1つだけです（重なりの1枚を丸ごと動かすためです）
- 位置と大きさだけを変えたときは素材を起動し直さずに箱だけを動かし、それ以外（デザイン・パラメータ・並び・隠す）を変えたときは少し待ってから読み込み直します

## 演出を早めに消す（下部バーの「演出を消す」）

アプリの下部バーの消しゴムのボタン（「演出を消す」）を押すと、合成ページに出ている演出を、決まった時間を待たずにまとめて消します。確かめのダイアログは出ません。

- **消すもの**: 再生中のアラート・市町村紹介・ツイスター・ペロペロ、正解の読みと解説に入った漢字クイズ、終えたチャットで推理、締め切った意見ボード
- **待っている演出はそのまま流します。** 続けて届いたアラートなどは、消したあとに順に出ます
- **消さないもの**: 出題中（級と熟語を出しているあいだ）の漢字クイズ・開催中のチャットで推理・意見を受け付けている意見ボード（視聴者が参加している最中のためです。漢字クイズは時間切れで配信を止める判断が続くので、問題が見えないまま止まらないよう消しません）。VRM の反応・ワイプ・チャットボックスなど出しっぱなしの素材も消しません
- 締め切った意見ボードは、OBS で読み込み直しても戻りません。次のテーマを出すとまた映ります
- 終えたチャットで推理は、OBS で読み込み直すと、終えてから1分たつまではまた映ります
- 合成ページへ送れなかったときは、ボタンの横に理由を出します。もう一度押してください

## OBSでの設定

1. オーバーレイごとに ソースの追加 > ブラウザ を1つずつ置く
2. URLにそのオーバーレイのURLを貼り、幅と高さを配信のキャンバスと同じ大きさ（1920×1080 など）にする
3. ソースの重なりは、オーバーレイのブラウザソースのあいだにアバターやゲーム画面を挟む形で並べる（背面のオーバーレイ → ゲーム画面・アバター → 前面のオーバーレイ）
4. 素材「タブの映像」を置いたオーバーレイは、タブの音も鳴らします。そのブラウザソースでは「OBSで音声を制御する」を有効にしてください（[タブの映像](./tab.md)）
