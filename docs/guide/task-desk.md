# 作業机（素材の種類「作業机」）

作業配信で、視聴者も「一緒に作業している側」として配信画面に出られるようにします。視聴者がチャットで自分の作業を宣言すると、配信画面の「作業机」に**名前と作業が1人1行で**並び、終えたらその行にチェックが付いて小さく祝われます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

## 視聴者が打つコマンド

配信者がコマンドを登録しなくても動く、組み込みのコマンドです（[チャットボット](./bot.md)で同じ名前のコマンドは登録できません）。大文字小文字は区別しません。

| コマンド | すること |
| --- | --- |
| `!task 作業の内容` | 作業を宣言します（例: `!task 英単語を50個覚える`）。打ち直すと作業を差し替えます（1人1件）。完了したあとに打てば、次の作業として未完了に戻ります |
| `!done` | 宣言した作業を完了にします。作業机のその行にチェックが付き、🎉が浮かんで祝われます |

うまくいったときは bot は何も返しません（作業机に出るのが返事です）。受け付けないときだけ、bot が理由を返します。

| こんなとき | bot の返事 |
| --- | --- |
| `!task` のあとに何も書いていない | 作業の内容を書いてください（例: !task 資料を読む） |
| 作業が40文字を超えた | 作業は40文字以内で書いてください（いまは◯文字です）。**切り詰めずに受け付けません** |
| 配信していない | 作業机は配信中だけ使えます |
| 宣言せずに `!done` を打った | 完了にする作業がありません。!task 作業の内容 で宣言してください |

- bot を接続していなくても、宣言は作業机に並びます（受け付けない理由だけは返せません）
- もう完了しているのに `!done` を打っても、何も起きません（祝い直しません）
- 自動モデレーションで処分された発言は、宣言として扱いません

## 配信画面に出す

[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「作業机」を追加します。配信者が決めるパラメータはありません。

- 並び順は、**作業中の人を宣言の新しい順**に並べ、そのあとに**完了した人を完了の新しい順**に並べます
- 並べるのは**12人まで**です。あふれたときは完了した人から外れ、作業中の人は押し出されません。そのうち何人が映るかは素材の枠の大きさで決まります（追加したときの大きさは 560×640px）
- 完了した行は、その人が次の作業を宣言するか配信が終わるまで、チェック付きで残ります
- 行の下には、その配信で**みんなが作業した時間の合計と人数**（例: `みんなの作業時間 14時間32分（5人）`）を出します。詳しくは下の「[みんなの作業時間](#みんなの作業時間)」を見てください
- その下には、いつも参加のしかた（`!task 作業の内容 で宣言・!done で完了`）を出しています。誰も宣言していないあいだは、この1行だけが出ます
- 宣言・完了は**すぐに**画面へ出ます（アラートと同じ接続で押し出します）。開き直したとき・つなぎ直したとき・5分おきに Worker から読み直して取り戻します
- 起動できない失敗（キーの誤りなど）や、Worker とつながらないときは素材の枠にエラーを出します。いっぽう5分おきの読み直しの失敗は出さず、映している行をそのまま残します
- 宣言が届くのを待たずに見栄えを確かめるには、`/overlay/` のプレビューを開きます（3人が順に宣言し、1人が完了して祝われる場面を流します。40文字ちょうどの作業も1件入っています。みんなの作業時間も場面ごとに出ます）

## みんなの作業時間

「今日この配信でみんな合わせて 14時間32分 作業しました」と数字で見せ、ひとりで作業しているのではないと感じてもらうためのものです。

- 1件の宣言の時間は、**`!task` で宣言してから `!done` で完了するまで**です。完了していない宣言は、いまの時刻までを数えます（作業机の合計は、読み直しを待たずに作業中の人数ぶん進みます）
- `!task` を打ち直しても、**前の作業の時間は合計に残ります**（完了していれば完了まで、していなければ打ち直すまで）
- 完了しないまま配信が終わった宣言は、**配信の終わりで打ち切って**数えます
- 人数は、その配信で宣言した人の数です（完了した人も含みます）
- 配信者のポモドーロの作業時間は含めません。配信者も `!task` すれば、視聴者と同じく数えられます
- モデレーションで消された宣言は、その時間も合計から外れます
- 誰も宣言していないあいだは、合計の行を出しません（0分とは出しません）
- 配信が終わったあとも、[ダッシュボード](./stats.md#配信で何が話されたか章)の配信の詳細に、配信ごとの合計が残ります。誰も宣言しなかった配信は「—」と出ます
- [チャットボット](./bot.md)のコマンドの応答文に `{worktime}` を書くと、いまの配信の合計（例: `14時間32分（5人）`）に置き換わります（例: `!worktime` に「今日はみんなで {worktime} 作業しています」）。誰も宣言していない・配信していないときは「まだ作業の記録がありません」に置き換わります

## 配信の区切りとモデレーション

- 宣言は**配信ごと**に持ちます。次の配信の作業机は空から始まります。前の配信の宣言は、配信が切り替わったあとの読み直し（5分おき）で画面から消えます
- モデレーターが `!task` の発言を削除すると、その宣言は作業机から消えます。BAN・タイムアウトでその人の発言が消されたときはその人の行を、チャットのクリアでは全員の行を消します（荒らしの書いた作業を配信画面に残さないためです）。作業を打ち直したあとに前の `!task` の発言が削除されても、いまの宣言は消えません
- 宣言は D1 の `task_declarations` に残り、配信が終わっても消えません（[配信の記録](./stats.md)）。みんなの作業時間は、この記録から読むたびに数えます
