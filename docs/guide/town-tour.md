# 市町村紹介

レイドを受けたときに、レイド元の紹介の代わりに「ランダムな市区町村の詳しい紹介」を流すネタ機能です。冒頭で市町村の形だけを出して「どこの都道府県でしょう？」とチャットに問い、正解を明かしたら日本地図からその市町村へズームし、「この町、実は○○」という大見出しを立てて、それを支える事実と配信者への振りを流します。締めには、レイド元の配信者とその市町村の「意外な共通点」を言い切り、これまでに紹介した市町村を塗った全国制覇マップを出して、レイド元をその市町村の名誉町民に任命する認定証を出します。配信者本人がチャットに `!darts` のようなキーワードを書いて、動作を確かめることもできます。

## 使い方

1. [オーバーレイの構成](./overlay.md)（`/overlay/`）で、どれかのオーバーレイに素材「市町村紹介」を置きます。日本地図を画面いっぱいに映すので、大きさはオーバーレイいっぱい（1920×1080）から始まります
2. [トリガーの管理画面](./alerts.md)（`/triggers/`）で、「レイドされた」か「キーワード」の行を開き、「市町村紹介を流す」に印を付けて保存します
   - レイドでは冒頭に「○○さんのレイドを記念して、本日は△△町をご紹介します」と出ます（クイズのあいだは都道府県を伏せ、正解を明かしたら「北海道石狩郡当別町」のように都道府県から出します）
   - キーワード（たとえば `!darts`）は配信者本人の動作確認用で、配信者本人が書いたときだけ流れます（視聴者が書いても流れません）。冒頭は「○○さんのダーツが刺さったのは、△△町でした」と出て、配信者本人をレイド元とみなして共通点と認定証まで流します。全国制覇の記録には数えません
   - ほかの出来事の行には出ません（冒頭で名前を出す相手が決まらないため）
3. トリガー画面の「市町村紹介」のカードにある「市町村紹介を試しに流す」で、トリガーを待たずに1件流せます（冒頭は「試し再生: 本日は…」）。横の「レイド元とみなすユーザー名（任意）」に Twitch のログイン名を入れると、その配信者がレイドしてきたものとみなして共通点と認定証まで流します（いないログイン名なら流さずに知らせます）。「レイドの人数（任意）」も入れると、連れてきた人数として共通点の材料にします

流れは次のとおりで、1件はおよそ40〜70秒です（クイズで正解が早く出るほど短くなり、ナレーションで読み上げると長い文の場面が延びます）。

1. 市町村の形だけをシルエットで出し、都道府県当てクイズを出す（最長15秒。下の「都道府県当てクイズ」）
2. 正解（と最初の正解者）を出しながら、日本全体を映す（正解の表示は3秒、日本全体は1.5秒）
3. 引いた市町村へズームしながら、形を塗る（3秒）。着地に合わせて、冒頭の一文の下に人口と面積を出し、最後まで残します（下の「人口と面積」）
4. 記事に代表画像があれば、町の写真を作者とライセンスと一緒に出す（6秒。下の「代表画像」）。出せる画像が無い記事では飛ばします
5. 大見出しを出す（7秒。はじめの1.5秒は「この町、実は…」だけを出して溜め、そのあと大見出しの文を出します）
6. 大見出しを支える項目を流す（1〜3項目。最後の項目は「オチ」として5秒、それより前の項目は6秒ずつ）
7. 「○○さんとこの町、実は…」と、レイド元の配信者とこの市町村の意外な共通点を出す（12秒。下の「レイド元との共通点」）。ここで配信者がツッコみます。共通点を出せない回は、代わりに配信者への振り（「サンショウウオ入りの山人料理、ひと口いけます？」など、項目のいちばん意外な事実を名指しした問いかけ）を出します（6秒）
8. 日本全体へ引き、全国制覇マップと「制覇 35 / 1,747（2.0%）」を出す（6秒。下の「全国制覇マップ」）
9. レイド元を名誉町民に任命する認定証を出して終わる（8秒。下の「名誉町民の認定証」）

紹介文の出典（「紹介文: Wikipedia「記事名」（CC BY-SA 4.0）」）は、紹介を流しはじめてから終わりまで右下に出し続けます。

### 代表画像

ズームの着地のあと、Wikipedia の記事の代表画像（記事の冒頭の写真）を6秒出します。画像を出しているあいだは、紹介文の出典の上の行に「写真: 作者（ライセンス）」を出します（パブリック・ドメインと CC0 で作者が無い画像は「写真: Public domain」のようにライセンスだけ）。

画像の下端には、何が写っているかの短い説明（「国会議事堂」など）を帯で重ねます。説明は紹介と一緒に LLM が、画像のファイル名と Wikimedia Commons に書かれた説明だけを材料に書きます（LLM は画像そのものを見ていません）。何の写真か分からなかった画像は説明を出しません。

次の画像は出さず、画像の場面ごと飛ばします。別の画像で埋めることはしません。

- 地図・位置図・市町村章・旗（SVG の画像と、ファイル名に「位置」「Location」「map」「章」「Flag」などを含む画像）
- ライセンスがクリエイティブ・コモンズでもパブリック・ドメインでもない・分からない画像（GFDL など）
- 作者の表記が要るのに作者が分からない・作者の表記が100文字を超える画像（組み写真で撮影者が並ぶものなど）

画像を合成ページで読み込めなかったとき（10秒以内に読み込めなかったときも含む）は、素材の箱に理由を出し、画像の場面を飛ばして紹介を続けます。画像の情報を Wikipedia から取れなかったときは、記事が取れなかったときと同じく紹介を作れなかった扱い（`town-tour-failed`）になります。

記事の材料が少なく大見出しを立てられない市町村では、大見出しを出さずに項目から流します。

紹介は流しはじめてから作るので（2〜5秒）、クイズとズームのあいだに間に合わなければ「紹介を準備しています…」と出して待ちます。流している最中に次のレイドが来たら、いまの1件を流し終えてから順に流します。アラートとは別に流すので、アラートと重なって出ることがあります。

紹介を作れなかったとき（記事が取れない・LLM が失敗した）は、何も出さずに済ませるのではなく、素材の箱に失敗の理由を出し、ダッシュボードの失敗の記録にも `town-tour-failed` として残ります。合成ページへ届けられなかったときは `town-tour-push-failed` として残ります。

シャウトアウト（Twitch の組み込みの紹介）とは別の効果なので、両方に印を付ければ両方行われます。

## 都道府県当てクイズ

レイドで来た人が最初の数秒からチャットで参加できるよう、紹介の冒頭はクイズにしています。レイドでもキーワードでも、試し再生でも同じです。

- 画面には市町村の形だけをシルエットで出し、「△△町はどこの都道府県でしょう？ チャットで答えてね」と問います。市町村の名前は出し、都道府県だけを伏せます（「青森市」のように名前で分かる町もあります）
- 4秒ごとにヒントを1つ足します。順に「その都道府県の市町村の数」「どの地方にあるか（八地方区分）」「隣り合う都道府県」で、どれも答えの都道府県についてのヒントです。同梱の日本地図から求めます（市町村の数は区を市にまとめ、北海道は北方領土の6村を含めて数えます）
- 回答はチャットの発言で受け付けます。発言に都道府県の名前が1つだけ入っていれば回答とみなします（「北海道」「京都」「京都府」「東京都」はどれも通じます。「岩手か宮城」のように2つ以上を挙げた発言は回答とみなしません）
- 「都・府・県」を省いた書き方（「大分」「山形」など）は、そのすぐ後が発言の終わり・記号（「！」「？」など）・答える言い方（「かな」「だ」「です」など）のときだけ回答とみなします。「大分むずかしい」「山形に見える」のような普通の文が、偶然の正解にならないようにするためです
- 最初に正解した人の名前を「最初の正解: ○○さん」と出し、その時点でクイズを終えて正解を明かします。15秒のうちに誰も正解しなければ「時間切れ！」として正解を明かし、先へ進みます
- 正解者には名前を出すだけで、チャンネルポイントなどは渡しません。bot の発言と、自動モデレーションで処分した発言は回答になりません。配信者自身の発言は回答として数えます
- 管理画面のプレビュー（`/overlay/`）ではクイズを出しますが、回答は受け付けず、いつも時間切れになります。試し再生では回答を受け付けるので、配信していないときでもチャットに書き込んで確かめられます

クイズの回答の記録はデータベースのテーブル `town_tour_quizzes` に残します（1日で消えます）。この機能を入れたあとは、マイグレーション `0026_town_tour_quizzes.sql` を適用してください（適用方法は [配信の記録](./stats.md)）。適用していないと、合成ページの素材の箱に出題を開けなかった失敗が出て、クイズはその場で「クイズを受け付けられませんでした」として正解を明かし、紹介へ進みます（答えても届かない問いを出し続けないため）。チャットの回答を照らせなかったときは、ダッシュボードの失敗の記録に `town-tour-quiz-failed` として残ります（チャットのほかの処理は止めません）。

## 全国制覇マップ

紹介した市町村を記録し、締めで「全国の市町村のうち、いくつ紹介したか」を見せます。

- 共通点（または配信者への振り）まで流しきったレイドの紹介を、相手の名前と一緒に記録します。キーワード（配信者本人の動作確認）・試し再生・管理画面のプレビュー・紹介を作れなかった再生は記録しません
- 市町村を引くときは、紹介済みの市町村を除きます（試し再生でも除きます）。全国のすべてを紹介し終えたら、全体から引き直します（2周目の紹介では制覇数は増えません）
- 締めでは日本全体へ引き、これまでに紹介した市町村を緑系の色で塗ります。少しおいて今回の市町村に印が付き、制覇数が1つ増えます（試し再生では増えません）
- 節目には一文を添えます。「○○県に初上陸！」（その都道府県で初めて）・「離島の○○に上陸！」（地図の上で隣り合う市町村が無い市町村）・「○○県を完全制覇！」（その都道府県をすべて紹介した）・「祝・20市町村制覇！」（10件ごと）の4つで、重なればすべて出ます

記録はデータベースのテーブル `town_tour_visits` に残します（1市町村1行で、消えません）。この機能を入れたあとは、マイグレーション `0027_town_tour_visits.sql` を適用してください（適用方法は [配信の記録](./stats.md)）。適用していないと、トリガーで市町村を引くときに記録を読めずに失敗します。流しきった紹介を記録できなかったときは、制覇マップはそのまま流しきり、素材の箱に失敗を出して、ダッシュボードの失敗の記録にも `town-tour-visit-failed` として残します。

## レイド元との共通点

締めで、レイドしてきた配信者とこの市町村の「意外な共通点」を、自信満々に言い切ります（「7人をお連れしたあなたと七ツ池を持つこの市は、ラッキーセブンを冠する同志なのです。」など）。見当違いでもかまいません。配信者がツッコむ余地になります。

- 見出しは「○○さんとこの町、実は…」です。その下の左右の枠に、レイド元のアイコンと配信者側の語句、町側の語句を並べ、その下に共通点の文を出します
- 材料は、レイド元の Twitch の公開情報（表示名・ログイン名・自己紹介・配信カテゴリ・配信タイトル・タグ・連れてきた人数）と、紹介と同じ Wikipedia の材料だけです。タグの「日本語」「日本」は使わず、「日本」でつないだ共通点は作り直させます。視聴者の記録の人物像やメモは使いません
- 結び方はこじつけでかまいませんが、結ぶ2つの語句は、材料に書かれている文字をそのまま抜き出させ、本当に書かれているかを確かめます。書かれていない語句を使った共通点は出しません（町についての嘘の事実を、視聴者に本当だと受け取られないため）
- 配信者をけなす内容（見た目・配信の規模・腕前のいじり）は書かせません
- 同じ共通点を、認定証の任命理由にも使います
- 共通点は紹介と一緒に作り、揃ってから流しはじめます
- 共通点を出せない回は、代わりに配信者への振りを出します。OpenRouter の鍵（`OPENROUTER_API_KEY`）が無いときは、共通点を作りません（失敗ではありません）。作れなかったとき（Twitch にその配信者がいない・決まりに合う共通点が返らなかった）は、素材の箱に理由を出し、ダッシュボードの失敗の記録に `town-tour-bond-failed` として残ります

使うモデルは [LLMの管理画面](./llm.md)（`/llm/`）の「市町村紹介の共通点」の行で選べます。既定は OpenRouter の `google/gemini-3.8-flash` です（1回あたり約2.5秒・約0.3円）。

## 名誉町民の認定証

レイドした側が持ち帰れるお土産として、締めにレイド元をその市町村の名誉町民に任命する認定証を出します。スクリーンショットを撮れるよう、8秒出しておきます。

- 文面は「名誉町民証　○○ 様　あなたを△△県□□町の名誉町民に任命します　（任命理由）　令和8年10月5日　HDAD 市町村紹介」の形です。市・村・区では「名誉市民」「名誉村民」「名誉区民」になります。日付は日本時間の和暦で、紹介を流しはじめた日です
- 任命理由（「本市の七ツ池と同じく7人を率いて来訪された功績顕著につき」など）は、共通点と一緒に LLM が書きます。共通点を出せない回は任命理由を出しません
- 賞状風の枠の紙に、引いた市町村の形を入れます
- 任命理由のほかの文面は決まった形で組み立て、LLM には作らせません。町の公式なものと誤解されないよう、自治体の名義や町章は使わず、発行者はこの配信（「HDAD 市町村紹介」）にしています
- レイドではレイド元、キーワード（`!darts` など）では配信者本人を名誉町民にします。試し再生ではユーザー名を入れればその配信者を、入れなければ見た目を確かめられるよう「レイド元の配信者 様」として出します（管理画面のプレビューでは「視聴者 様」）

## BGMと効果音

トリガー画面の「市町村紹介」のカードで、演出の場面ごとに鳴らす音を選べます。場面（枠）は次の6つで決まっており、増やしたり時刻を変えたりはできません。

| 枠 | 鳴るとき |
|---|---|
| BGM | 紹介のあいだ（冒頭のクイズからループで流し、終わりに画面が薄くなるのに合わせて下げて止める） |
| 始まり | クイズを終えて正解を明かし、日本全体を映したとき |
| ズーム | 市町村へ寄り始めたとき |
| 着地 | ズームが終わり、形を塗り終えたとき |
| 項目ごと | 大見出しと、各項目が出るたび（最大4回。大見出しを出さない市町村では大見出しのぶんは鳴らない） |
| 締め | 共通点（出せない回は配信者への振り）が出たとき |

- 音声は先に[アップロード](./alerts.md)（`/media/`）のページで追加し、枠ごとに選びます。「鳴らさない」にした枠では何も鳴りません
- 音量は BGM と効果音（BGM 以外の枠すべて）の2つです
- 設定は1つだけで、レイド・キーワードのトリガーと試し再生のどれで流しても同じ音が鳴ります
- 枠に選んでいる音声は、アップロードのページから削除できません（先にこのカードで外します）

音は合成ページの市町村紹介の素材が鳴らします。OBS でブラウザソースの音を拾うには、ソースのプロパティで「OBSで音声を制御する」を入れておきます。

- 紹介を作れなかったとき（Wikipedia や LLM の失敗）は、その場で紹介を終え、それ以降の音を鳴らしません（鳴りはじめていた BGM も止めます）
- 音を再生できなかったとき（音声を読めなかった・ブラウザが自動再生を拒んだ）は、素材の箱に失敗を出します。普通のブラウザのタブで合成ページを開くと、ページを操作するまで自動再生を拒まれることがあります
- 管理画面のプレビューでは音を鳴らしません（試し再生で確かめます）
- BGM の枠に音声を選んでいると、紹介の BGM が鳴るあいだは[配信の BGM](./bgm.md#市町村紹介とツイスターのあいだは下がる)が自動で下がり、終わると戻ります。BGM の枠が「鳴らさない」なら下げません

音声はリポジトリに入っていません（配布元が再配布を禁じているため）。次の素材を配布元からダウンロードして使うことを想定しています。どれも説明文から選んだもので、試聴して差し替えてかまいません。

効果音ラボの素材は、どれも[演出・アニメ](https://soundeffect-lab.info/sound/anime/)のページにあります。

### クレジット

魔王魂の素材は著作表記が必須です（[利用規約](https://maou.audio/rule/)）。表記の場所は自由なので、Twitch のチャンネルのパネルに書きます。効果音ラボは表記が任意ですが（[利用規約](https://soundeffect-lab.info/agreement/)）、あわせて書いておくと次のようになります。

```
音楽：魔王魂
効果音：効果音ラボ
```

## ナレーション

トリガー画面の「市町村紹介」のカードの「ナレーション」で「ナレーションで読み上げる」に印を付けて保存すると、紹介を VOICEVOX のナレーターの声で読み上げます。配信者が画面を見ずにリアクションできるようにするためのものです。

- 読み上げるのは、冒頭の一文（ズームの着地で読みます）・大見出し（「この町、実は…」から読みます）・各項目（見出しは読まず文だけ）・共通点（「○○さんとこの町、実は…」から読みます）か配信者への振り（「ところで…」から読みます）です。クイズの問いと人口と面積の文は読みません
- 場面の長さは読み上げに合わせます。読み上げが場面の決まった長さ（項目なら6秒）に収まれば決まった長さのまま、収まらなければ読み終えてから0.8秒置いて次の場面へ進みます。冒頭の一文を読み終えるまでは大見出しへ進みません（代表画像があれば、画像を出しながら読みます）
- 読み上げているあいだは、紹介の BGM を設定の音量の4割まで下げ、読み終えたら戻します
- 話者IDと読み上げ速度は、チャットの[読み上げ](./speech.md)とは別に選べます（別の声にできます）。話者IDは VOICEVOX の番号です（3 はずんだもん（ノーマル））
- 合成はさくらのAI Engine で行います。Worker のシークレット `SAKURA_AI_API_KEY` が要り、さくらのコントロールパネルでその話者の利用規約に同意しておきます（[読み上げ](./speech.md)と同じ）
- 費用は合成したモーラ数の合計に対して 3円/1万モーラです。1件で読み上げるのは最大でおよそ500モーラなので、1件あたり約0.15円です。1件で5〜6回合成するので、月50回の無料枠は8〜10件ほどで使い切ります
- 紹介が届いてから文を合成し、音声を読み込み終えてから流しはじめます（代表画像の読み込みと並べて待ちます）。ある文を合成できなかった・読み込めなかったときは、素材の箱に失敗を出し、その場面だけ文字を決まった長さで流します（紹介は止めません）
- 試し再生でも保存した声で読み上げます。ナレーションの設定に未保存の変更があるあいだは、試し再生を押せません。管理画面のプレビューでは読み上げません

## 引く対象

令和8年1月1日時点の全国の市区町村 1,747件です。

- 政令市は区ではなく市として1件に数えます（札幌市中央区〜清田区は「札幌市」1件）
- 東京23区は1区ずつ数えます
- 北方領土の6村（色丹村・泊村・留夜別村・留別村・紗那村・蘂取村）も入れます。北海道の泊村は古宇郡（積丹半島）と国後郡の2つがあり、郡で見分けます
- どの市町村にも属さない「所属未定地」（埋立地など）は入れません

## 人口と面積

ズームが着地すると、冒頭の一文の下に次の2行を出します。

```
人口 3,329人 ・ 面積は山手線の内側の約0.06個分
レイドを合わせた50人で挑むと、ひとり67人倒せばこの村を制圧
```

- 人口は総務省の住民基本台帳人口、面積は国土地理院の面積調の値です（下の「出典」）。LLM には数字を作らせません
- 面積は「山手線の内側（約63km²）の何個分か」で出します
- 2行目は、いま見ている人数でその市町村の住民全員に挑んだら、ひとり何人倒せばよいか（端数は切り上げ）です。人数の割合で比べると、レイドや同接が少ないときに「0.001%」のように小ささが目立つので、どの人数でも遊びとして読める言い方にしています
  - レイドでは、最後に記録した同接にレイドの人数を足した人数で挑みます
  - キーワードと試し再生では、最後に記録した同接で挑みます。配信中でないときは2行目を出しません
  - 同接は[配信の記録](./stats.md)が5分おきに残す値なので、いまの値より少し古いことがあります
- 北方領土の6村は住民の記録が無いので、「人口の記録なし（北方領土）」と出し、2行目を出しません

## 紹介の中身

紹介は、その市町村の日本語版 Wikipedia の記事を材料に、LLM がその都度作ります（貯めておきません）。中身は次の3つです。

- 大見出し: その市町村ならではの一本の切り口（「紙風船の町」「日本一人口密度の低い村」など）。項目に書いた事実だけから作ります。記事の材料が少なければ空にします
- 項目: 大見出しを支える事実を1〜3つ。それぞれに短い見出し（「名物」「名前の由来」など）が付きます
- 配信者への振り: 大見出しか項目の中身に触れた、短い問いかけ（レイド元との共通点を出せない回に出します）

どれも記事に書かれていることだけで作らせます。人口・面積の数字は「ふーん」で終わるので使わせません（「日本一」のような順位は使います）。人口と面積は、着地で公的な統計の値を別に出します（上の「人口と面積」）。

使うモデルは [LLMの管理画面](./llm.md)（`/llm/`）の「市町村紹介」の行で選べます。記事が取れない・LLM が失敗したときは紹介を出さず、ダッシュボードの失敗の記録に `town-tour-failed` として残ります。

## 出典

市町村の一覧と地図の形は、次のデータを加工して作成しています。

- 出典：「国土数値情報（行政区域データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html）を加工して作成。令和8年（2026年）1月1日時点。[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)

加工の内容は、政令市の区を市にまとめたこと・所属未定地を除いたこと・形を簡略化して TopoJSON にしたことです。

人口と面積は、次のデータを加工して作成しています。加工の内容は、市町村ごとに一覧のコードへ対応させたこと（政令市は市の行を使い、区の行は使いません）です。

- 出典：「住民基本台帳に基づく人口、人口動態及び世帯数（令和8年1月1日現在）」（総務省）（https://www.soumu.go.jp/menu_news/s-news/01gyosei02_02000428.html）を加工して作成
- 出典：「全国都道府県市区町村別面積調（令和8年7月1日時点）」（国土地理院）（https://www.gsi.go.jp/KOKUJYOHO/MENCHO-title.htm）を加工して作成

境界の確定していない市町村の面積は、面積調でも「参考値」（便宜上の概算）です。山手線の内側の面積（約63km²）は一般に言われる概算で、公的な資料の値ではありません。

紹介の文は、Wikipedia の記事（[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)）を材料にしています。配信画面には紹介を流しているあいだ、右下に「紹介文: Wikipedia「記事名」（CC BY-SA 4.0）」を出します。

代表画像は Wikimedia Commons（または日本語版 Wikipedia）にある画像で、ライセンスは画像ごとに違います。配信画面には画像を出しているあいだ、紹介文の出典の上の行に作者とライセンスを出します。

## データの作り直し（開発者向け）

市町村の合併などで作り直すときは、国土数値情報の行政区域（N03）の「全国」の版をダウンロードして展開し、shp のパスを渡して次を実行します。

```bash
node scripts/town-tour/build-data.ts <展開した先>/N03-YYYYMMDD.shp
```

`src/town-tour/towns.json`（一覧）と `public/town-tour/japan.topo.json`（地図）が書き換わります。新しい政令市ができていると、市のコードを知らないというエラーで止まるので、`scripts/town-tour/build-data.ts` の `DESIGNATED_CITY_CODES` に足してください。2つのファイルを手で直さないでください（一覧と地図の食い違いは `npm test` が検出します）。

一覧を作り直したら、続けて各市町村の Wikipedia の記事名の表も作り直します。

```bash
node scripts/town-tour/build-articles.ts
```

`src/town-tour/articles.json` が書き換わります。Wikidata で同じコードを持つ項目が複数ある市町村があると、候補を並べたエラーで止まります。正しい項目を確かめて、`scripts/town-tour/build-articles.ts` の `PREFERRED_ITEMS` に足してください。

人口と面積の表も作り直します。総務省の[住民基本台帳人口](https://www.soumu.go.jp/menu_news/s-news/01gyosei02_02000428.html)の「【総計】市区町村別」の xlsx と、国土地理院の[面積調](https://www.gsi.go.jp/KOKUJYOHO/MENCHO-title.htm)の CSV をダウンロードし、この順にパスを渡して次を実行します。人口は毎年1月1日現在の値が夏に、面積は四半期ごとに公表されます。

```bash
node scripts/town-tour/build-stats.ts <住民基本台帳人口.xlsx> <面積調.csv>
```

`src/town-tour/stats.json` が書き換わります。一覧の市町村が人口か面積の表に無い・コードが同じでも名前が違うときは、エラーで止まります。表の字が一覧と違うだけ（須恵町を「須惠町」と書くなど）と確かめたら、`scripts/town-tour/build-stats.ts` の `POPULATION_NAME_VARIANTS` に足してください。
