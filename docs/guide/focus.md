# 注目コメント（素材の種類「注目コメント」）

視聴者の発言**1件**を、配信画面に大きく出しっぱなしにします。「今から怖い話をする」と言い出した人の語りをそのまま映したり、ある人の発言を題に雑談したりするためのものです。取り上げ方は2通りあり、どちらも `/focus/` の画面で決めます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

| 取り上げ方 | ふるまい |
| --- | --- |
| 人に追従する | その人が発言するたびに、映すものが**最新の1件へ差し替わります**（語りを追いかけるとき） |
| 発言1件を取り上げる | 直近の発言から選んだ1件を**固定します**（本人の次の発言でも差し替わりません。題にして雑談するとき） |

**2つは別の操作なので、画面でも選ぶ場所が分かれています。** 追従は「誰を追うか」を決めるので相手を指定します（その配信で発言した人は選択欄から選べます。まだ発言していない人はログイン名を手で入れます）。取り上げは「どの発言を出すか」を決めるので、誰の発言かによらず一覧から1件を選びます。

配信画面に出すには、[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「注目コメント」を足します。パラメータはありません（何を映すかは `/focus/` で決めます）。

- **取り上げる相手は素材の設定に入れません。** Worker が持つので、配信中に相手を変えてもOBSのURLを貼り替える必要はありません（`/focus/` で変えると10秒以内に切り替わります）
- 「人に追従する」に切り替えた直後は何も映さず、**その人の次の発言から映します**（IRCは過去の発言を送ってこないので、切り替える前の発言は手元にありません）
- 「発言1件を取り上げる」で選べるのは、**いま進んでいる配信の直近の発言**だけです（本文を貯めているのは配信中のあいだだけのため。配信していないときは一覧が空になります）
- **モデレーターに消された発言は映しません。** 発言の削除・BAN・タイムアウト・チャットの全消去を受け取ったら、その時点で映すのをやめます
- 公式エモートと Cheermote は絵で出ます（7TV・BTTV・FFZ のエモートは文字のままです）
- 起動できない失敗（キーの誤りなど）は素材の枠にエラーを出します。いっぽう2回目以降の読み出しの失敗は出さず、前に読んだ指定のまま映し続けます（一時的な通信の失敗で配信画面を汚さないためです）
- コメントは**素材の枠の左下**に出ます。位置と大きさは `/overlay/` の配置用の枠で決めてください（足したときの大きさはオーバーレイいっぱいです）
- 見栄えと配置は `/overlay/` のプレビューで確かめられます（サンプルのコメントが順に流れます）
