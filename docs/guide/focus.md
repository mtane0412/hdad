# 注目コメント（素材の種類「注目コメント」）

視聴者の発言**1件**を、その人の**アイコン・名前と一緒に1つの箱にまとめて**、配信画面の中央に大きく出しっぱなしにします。ある人の発言を題に雑談したり、質問を画面に出して答えたりするためのものです。どの発言を出すかは `/focus/` の画面で決めます。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

`/focus/` の「直近の発言から選ぶ」に、いま進んでいる配信の発言が新しい順に並びます。「この発言を取り上げる」を押すと、その1件が配信画面に映ります。本人がそのあと発言しても差し替わりません（別の発言を選び直すか、「取り上げをやめる」を押すまで映り続けます）。

配信画面に出すには、[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「注目コメント」を足します。パラメータはありません（何を映すかは `/focus/` で決めます）。

- **取り上げる発言は素材の設定に入れません。** Worker が持つので、配信中に選び直してもOBSのURLを貼り替える必要はありません（`/focus/` で変えると10秒以内に切り替わります）
- 選べるのは、**いま進んでいる配信の直近の発言**だけです（本文を貯めているのは配信中のあいだだけのため。配信していないときは一覧が空になります）
- アイコンは、取り上げたときに Twitch から読み込みます。名前を変えた人・アカウントが消えた人の発言はアイコンを読み込めないので、取り上げられずに理由が画面に出ます
- **モデレーターに消された発言は映しません。** 発言の削除・BAN・タイムアウト・チャットの全消去を受け取ったら、その時点で映すのをやめます
- 本文は文字だけを出します（エモートは名前の文字のままです）。長い発言ほど字を小さくして、500文字まで全文を収めます
- 起動できない失敗（キーの誤りなど）は素材の枠にエラーを出します。いっぽう2回目以降の読み出しの失敗は出さず、前に読んだ発言のまま映し続けます（一時的な通信の失敗で配信画面を汚さないためです）
- コメントの箱は**素材の枠の中央**に出ます。位置と大きさは `/overlay/` の配置用の枠で決めてください（足したときの大きさはオーバーレイいっぱいです）
- 見栄えと配置は `/overlay/` のプレビューで確かめられます（サンプルのコメントが順に流れます）

開発者向け: この作りにした理由は [注目コメント](../decisions/focus.md) にあります。
