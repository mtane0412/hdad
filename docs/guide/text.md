# テキスト（素材の種類「テキスト」）

配信画面に、自分で書いた文字をそのまま出します。「目標」「今やってること」のように名前を付けたテキストをいくつでも（20件まで）持て、配信中に本文を書き換えるとすぐ配信画面に映ります。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

## テキストを書く

サイドバーの「テキスト」（`/texts/`）で、テキストの追加・名前の変更・本文の書き換え・削除をします。

- テキストは1件ずつ「保存する」で保存します。保存するとすぐ配信画面へ送られます
- 名前は[合成オーバーレイ](./overlay.md)で映すテキストを選ぶときに使います。ほかのテキストと同じ名前にはできません（20文字まで）
- 本文は100文字・4行までです。**超えたら切り詰めずに保存を断ります**（文字数は見た目の1文字ずつ数え、絵文字も1文字です）
- 本文を空にすると、そのテキストの札は配信画面から消えます（素材は残したままでかまいません）
- 保存していない変更があるあいだにページを離れようとすると、確認が出ます

## 配信中に本文だけ書き換える

画面下端のバーのノートのボタン（「テキストを書き換える」）を押すと、どのページを見ていても本文を書き換えられます。書き換えるテキストを名前で選び、本文を直して「保存する」を押すと、窓が閉じて配信画面に映ります。名前の変更・追加・削除はテキストのページで行います。

- 窓を開くたびに、保存されている本文を読み直します
- 書きかけのまま窓を閉じると、書きかけは消えます

## LLM に自動で書き換えさせる

テキストごとに「自動で書き換える」を入れると、配信中に LLM が本文を書き直します。「今やってること」を喋りながら手で書き換えなくても、話している内容に合わせて変わっていきます。

- 「自動で書き換える」を入れると「指示文」の欄が出ます。何を書かせたいかを100文字までで書きます（例: 「いまやっている作業を20字で」）。指示文が空のままでは保存できません
- 配信中、5分おきの収集のときに、**前回 LLM が書いたあとに喋っていれば**書き直します。喋っていない（文字起こしが届いていない）あいだは、チャットが流れていても書き直しません
- 材料は、直近に喋った内容・チャット・配信画面に映った文字・配信のカテゴリとタイトルと、**手で書いているほかのテキストの本文**です。「目標」を手で書いておくと、目標を踏まえた文になります
- 書き直すとすぐ配信画面へ送られます。テキストのページでは、本文の下に「LLMが書いた本文です（時刻）」か「手で書いた本文です」が出ます
- 自動のあいだに**本文を手で書き換えると、自動は止まり手動に切り替わります**（下部バーから書き換えても同じです）。指示文は残るので、また「自動で書き換える」を入れれば再開します
- LLM が上限（100文字・4行）を超える本文を返したときは、切り詰めずに前の本文のまま残し、`text-auto-failed` として記録します（[配信の記録](./stats.md)）
- 使うモデルは[LLMの設定](./llm.md)（`/llm/`）の「テキストの自動の書き換え」で選びます

## 配信画面に出す

[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「テキスト」を追加し、素材の設定の「映すテキスト」で、映すテキストを名前で選んで構成を保存します。テキストごとに素材を1つ置けば、「目標」と「今やってること」を別々の場所に出せます。

- 追加したときの大きさは720×220pxです。札は箱いっぱいの決まった大きさで描かれ、本文の長さでは大きさが変わりません
- 札には名前を小さな見出しとして、本文をその下に出します。本文の改行はそのまま出ます
- 素材の設定の「枠」で、札の見た目を選べます

  | 枠 | 見た目 |
  |---|---|
  | 板（既定） | 半透明の暗い板。名前は黄色の小さな見出し |
  | メッセージウィンドウ | RPG風の濃紺の窓と白の二重枠。名前は上辺に乗るタブで、右下で▼が点滅します |
  | テロップ帯 | ニュースの下帯風。左に赤い名前の札、右に白い帯の本文を並べます |
  | 付箋 | 少し傾いた黄色の紙をテープで留めた見た目 |

- 素材の設定の「本文が収まらないとき」で、本文が枠に入りきらないときの扱いを選べます

  | 扱い | 動き |
  |---|---|
  | 文字の大きさは固定（既定） | 文字の大きさは変えず、入りきらない行は隠れます |
  | 収まるまで文字を縮める | 枠に収まるまで本文の文字を小さくします（元の4割までで止め、それでも入らない分は隠れます） |
  | 1行にまとめて横に流す | 改行を空白に置き換えて1行にし、枠からあふれるときだけ右から左へ流し続けます（収まるときは止まったままです） |

- 本文を書き換えると、本文がふわっと浮かび上がって切り替わります
- 合成ページは開いたとき・つなぎ直したとき・5分おきにもテキストを読み直します

## うまく映らないとき

| 素材の箱に出る理由 | 直し方 |
| --- | --- |
| 映すテキストが選ばれていません | `/overlay/` でその素材を開き、「映すテキスト」を選んで保存します |
| 映すテキスト（ID ◯）が見つかりません | 選んでいたテキストが消されています。`/overlay/` で別のテキストを選ぶか、素材を外します（選択欄には「消されたテキスト（ID ◯）」と出ています） |

保存したときに「保存しましたが、合成ページへすぐには送れませんでした」と出たときは、保存は済んでいます。合成ページは5分以内に読み直して映します。

## はじめて使うとき

この機能を入れたあとは、マイグレーション `0029_texts.sql` と `0030_texts_auto.sql` を適用してください（適用方法は[配信の記録](./stats.md)を参照）。適用していないと、テキストのページを開いたときに読み込めません。
