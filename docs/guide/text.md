# テキスト（素材の種類「テキスト」）

配信画面に、自分で書いた文字をそのまま出します。「目標」「今やってること」のように名前を付けたテキストをいくつでも（20件まで）持て、配信中に本文を書き換えるとすぐ配信画面に映ります。利用には[デプロイ](./deploy.md)の Twitchログインの設定が必要です。

## テキストを書く

サイドバーの「テキスト」（`/texts/`）で、テキストの追加・名前の変更・本文の書き換え・削除をします。

- テキストは1件ずつ「保存する」で保存します。保存するとすぐ配信画面へ送られます
- 名前は[合成オーバーレイ](./overlay.md)で映すテキストを選ぶときに使います。ほかのテキストと同じ名前にはできません（20文字まで）
- 本文は100文字・4行までです。**超えたら切り詰めずに保存を断ります**（文字数は見た目の1文字ずつ数え、絵文字も1文字です）
- 本文を空にすると、そのテキストの札は配信画面から消えます（素材は残したままでかまいません）
- 保存していない変更があるあいだにページを離れようとすると、確認が出ます

## 配信中に本文だけ書き換える

画面下端のバーのノートのボタン（「テキストを書き換える」）を押すと、どのページを見ていても本文を書き換えられます。書き換えるテキストを名前で選び、本文を直して「保存する」を押すと、窓が閉じて配信画面に映ります。名前の変更・追加・削除はテキストのページで行います。

- 窓を開くたびに、保存されている本文を読み直します
- 書きかけのまま窓を閉じると、書きかけは消えます

## 配信画面に出す

[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「テキスト」を追加し、素材の設定の「映すテキスト」で、映すテキストを名前で選んで構成を保存します。テキストごとに素材を1つ置けば、「目標」と「今やってること」を別々の場所に出せます。

- 追加したときの大きさは720×220pxです。札は箱の左上から置かれ、本文の長さに合わせて縮みます
- 札には名前を小さな見出しとして、本文をその下に出します。本文の改行はそのまま出ます
- 本文を書き換えると、本文がふわっと浮かび上がって切り替わります
- 合成ページは開いたとき・つなぎ直したとき・5分おきにもテキストを読み直します

## うまく映らないとき

| 素材の箱に出る理由 | 直し方 |
| --- | --- |
| 映すテキストが選ばれていません | `/overlay/` でその素材を開き、「映すテキスト」を選んで保存します |
| 映すテキスト（ID ◯）が見つかりません | 選んでいたテキストが消されています。`/overlay/` で別のテキストを選ぶか、素材を外します（選択欄には「消されたテキスト（ID ◯）」と出ています） |

保存したときに「保存しましたが、合成ページへすぐには送れませんでした」と出たときは、保存は済んでいます。合成ページは5分以内に読み直して映します。

## はじめて使うとき

この機能を入れたあとは、マイグレーション `0029_texts.sql` を適用してください（適用方法は[配信の記録](./stats.md)を参照）。適用していないと、テキストのページを開いたときに読み込めません。
