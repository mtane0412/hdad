# チャットボックス（素材の種類「チャット」）

Twitchのチャット欄を配信画面に重ねます。背景は透過です。
[合成オーバーレイ](./overlay.md)の画面（`/overlay/`）でオーバーレイに素材「チャット」を足し、デザイン（下表のデザインID）を選んでパラメータを調整します。`/overlay/` のプレビューは常にサンプルの書き込みです。

- Twitchへは匿名（読み取り専用）で接続するため、ログインやトークンは不要です
- **映すチャンネルは選びません。** 接続先はこのWorkerが扱う配信者（`TWITCH_BROADCASTER_ID`）に固定で、合成ページが Worker の公開API（`/api/chat/channel`）から受け取ります
- 接続先を受け取れなかったときは素材の枠にエラーを表示します（黙ってサンプル表示にはしません）。サンプルを流すのは `demo` を有効にしたときだけです（このときTwitchには接続しません）
- モデレーターによる削除・タイムアウト・BAN・`/clear` は、表示中の書き込みにも反映されます
- 回線やTwitch側の都合で切断された場合は、間隔を延ばしながら自動で再接続し、切断と復帰をチャット欄に1行で知らせます
- バッジは配信者・モデレーター・VIP・サブスクライバーを表示します。画像はTwitchの公式のものを Worker の公開API（`/api/chat/badges`）経由で取得し、取れなかったときはチャット欄に1行で知らせて自前のアイコンで表示を続けます
- ビッツの Cheermote も同じ経路（`/api/chat/cheermotes`）で絵にします。取れなかったときは文字のまま出します
- 7TV・BTTV・FFZ のエモートは各サービスの公開APIから取得します。取得できなかったサービスがあればチャット欄に1行で知らせ、チャットの表示は続けます
- サブスクやレイドなどのお知らせ（USERNOTICE）は表示しません

同じオーバーレイにチャットの素材を2つ以上置いても、Twitchへの接続は1本で共有します。

全デザイン共通のパラメータ: `demo`（サンプルの書き込みを流す）, `max`（同時に表示する件数 1〜50）, `lifetime`（消すまでの秒数 0〜600。0 で消さない）, `badges`, `timestamps`（書き込まれた時刻（時分）を表示する。既定は無効）, `thirdparty`（7TV・BTTV・FFZ のエモート）

| デザインID | 内容 | パラメータ |
| --- | --- | --- |
| `bubble` | 名前色の名札が付いた、角の丸いふきだし | `size`（文字の大きさ px）, `panel`（ふきだしの色、`transparent` で透過）, `opacity`（ふきだしの不透明度 0〜1）, `text`（文字の色） |
| `card` | 左端に名前色のラインが入った、半透明の落ち着いたカード | `size`（文字の大きさ px）, `panel`（カードの色、`transparent` で透過）, `opacity`（カードの不透明度 0〜1）, `text`（文字の色） |
| `plain` | 地を塗らず、フチ取りした文字だけを並べる（ゲーム画面に直接重ねる用途向け） | `size`（文字の大きさ px）, `text`（本文の文字の色）, `outline`（本文の文字のフチの色） |
| `sticker` | 太い白フチのシールに、少し傾いた名札を貼ったかわいいデザイン | `size`（文字の大きさ px）, `panel`（シールの色）, `border`（シールのフチの色）, `text`（文字の色） |
| `terminal` | 等幅の文字が並ぶ、黒い端末風のデザイン（素材の枠全体を画面として塗る） | `size`（文字の大きさ px）, `panel`（画面の色、`transparent` で透過）, `opacity`（画面の不透明度 0〜1）, `text`（文字の色） |

書き込みは素材の枠の下から入り、枠の幅に合わせて折り返します。足したときの大きさは480×800px相当なので、チャット欄を置きたい場所へ枠をドラッグしてください。OBSへの貼り方は[合成オーバーレイ](./overlay.md)の「OBSでの設定」を見てください。
