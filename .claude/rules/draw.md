# 手書き（`/draw/`・素材の種類 `draw`）

手書きは配信者がその場で引いた線を配信画面へ出す素材（素材の種類 `draw`）で、描く画面が `/draw/` である。描く画面と合成ページの両方が中継先（`worker/draw-channel.ts` の `DrawChannel`）へWebSocketでつなぎ、描く画面から届いた線をそのまま他の接続へ配る。アラートの配送（`AlertChannel`）と分けてあるのは、向き（接続から接続へ中継する）も量（1本の線で毎秒20〜30通）も違うためである。→ `docs/decisions/draw.md`。**同じクラスを字幕も名前 `caption` の別のインスタンスとして使う**ので、`DrawChannel` に手書きだけの判断を持ち込まない（`.claude/rules/caption.md`）。

**中継先は中身を読まない**（形の検証は受け取った側の `src/draw/stroke.ts` が持つ）。**描ける接続と見るだけの接続は、受け入れるときの目印（タグ）で分ける**。描く側として受け入れるのは配信者のセッションで守られた経路（`worker/draw-routes.ts`）だけで、合成ページが使うオーバーレイ用キー（`GET /api/overlay/draw`）では描けない（キーは配信画面に映りうるため）。**WebSocketの接続はGETなので `requireAdmin` の送信元の確認が効かない**。`drawSocket` が `Origin` を自分で確かめる（`SameSite=Lax` のクッキーは別サイトからのWebSocketには付かないが、ブラウザの決まりだけに頼らない）。

**選べる色と太さは `src/draw/tools.ts` だけが持つ**（描く画面と合成ページの両方がここを読む。2か所に持つと検証が食い違う）。やりとりに載せるのは名前（`red`・`bold`）だけで、一覧にない名前は黙って既定に戻さずエラーにする。線には縁取り（同じ形を少し太い黒で描いてから本来の色で描く）を付けるので、選べる色に黒は置かない。

**座標も線の太さも、箱の大きさに対する比で持つ**（`src/draw/stroke.ts`）。描く画面のキャンバスと合成ページの箱は大きさが違うので、画素で送ると図が歪む。描く画面のキャンバスは配信画面と同じ縦横比（16:9）で置く。

**描いたものはKVに残す**（`worker/draw-config.ts`。鍵は `draw-strokes`）。**書くのは線を1本引き終えた時点だけ**で、そこから数秒まとめる間引きは描く画面の側（`src/draw/save.ts`）が持ち、Workerは受け取ったものを検証して書くだけにする（`PUT /api/admin/draw/strokes`）。**全消しは待たずに書く**。**保存されているものを読めるまでは書かない**（読む前に書くと前に描いた図を消す。全消しを押したあとは「保存されているのは何も無い状態」と分かるので、読めていなくても書く）。読めるまでのあいだに引いた線は、読めた時点でまとめて書く。**画面を離れるときは待っている書き込みを捨てずに書き切る**。合成ページは開いたときに `GET /api/overlay/draw/strokes` を1度読み、それを初期状態にしてから中継先へつなぐ。**描いた直後に合成ページを読み込み直すと最後の数本が欠けることは受け入れる**（間引きとKVの反映の遅れによる。取り繕わない）。配信をまたいでも残し、消えるのは配信者が全消しを押したときだけである。

**線1本ぶんとして読めるかの判定は `src/draw/strokes.ts` の `isStroke` だけが持つ**（Workerの検証と画面での応答の確かめの両方がこれを呼ぶ）。そのため `worker/draw-config.ts` は例外的に `src/draw/` を読み込む（選べる色と太さの一覧を2か所に持たないため）。線の本数の上限は `MAX_STROKES`、1本の点の数の上限は `MAX_POINTS_PER_STROKE` で、どちらも `src/draw/strokes.ts` だけが持つ。

**消しゴムは触れた線を1本まるごと消す**（範囲を削らない）。当たり判定は `src/draw/erase.ts` だけが持ち、距離は画素に直して「消しゴムが動いた線分」と「線の各区間」で測る。消したことは `{ type: 'erase', id }` で配り、保存は線を引き終えたときと同じくポインタを離してから間引いて書く。

**描く画面の背景は、画面の取り込みが Gyazo へ上げた最後の1枚を使う**（自前で画像を持たない）。`GET /api/admin/draw/background` は D1 の最新の1行（`readLatestScreenCapture`）の画像IDを印（ETag）にし、手元と同じなら Gyazo を呼ばずに304、新しい1枚のときだけ `fetchImageUrl` で画像のURLを引いて返す（画像は中継しない。`Cache-Control: no-store`）。描く画面はスイッチを入れているあいだだけ15秒おきに読み（`src/draw/use-background.ts`）、`https://i.gyazo.com` 以外のURLは背景に読み込まない。取り込みの画像を `anyone` で上げるのはこのためである。配信していないあいだは最後に配信した時点の1枚になり、その1行は古い記録の掃除でも残す。

届いた線は `src/draw/strokes.ts` で積み上げ、毎フレームそこから描き直す（フレーム間の状態を持たない）。描き始め（`start`）を受け取っていない線の続き（`extend`）は捨てる（合成ページを線の途中で開いたときに起こる）。**描く画面は自分のキャンバスにも描く**（中継先は送り主へ返さないため）。

つなぎ直し・生存確認は素材で共通なので `src/core/socket.ts` に置く（アラートの受け取りも同じものを使う）。**合成ページの手書きの箱には切断を出さない**（失敗の表示は箱全体を塗るので、全画面に置いた箱だと配信画面全体が覆われる。issue #174）。箱に出すのは一度もつながらないときと、届いた線を読めないときだけである。

利用者向けの説明は `docs/guide/draw.md`。
